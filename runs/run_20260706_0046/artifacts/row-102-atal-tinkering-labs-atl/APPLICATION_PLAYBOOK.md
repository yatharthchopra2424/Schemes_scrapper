## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The ATL application is form-based and does not mandate a Detailed Project Report (DPR). However, applicants must provide infrastructure details and a commitment undertaking as part of the online form.  
> **Verify with nodal officer** if any additional project justification is sought during evaluation.

### Application Form Filling Protocol
1. Access the portal at **https://aim.gov.in/atl** and register the school using official name, address, contact details, and UDISE code.  
2. Fill all fields in the online form accurately; do not leave any mandatory section blank.  
3. Upload documents in PDF/JPEG format as specified (max 5 MB/file).  
4. Ensure photographs clearly show the proposed lab space with visible infrastructure.  
5. Double-check the undertaking includes: commitment to run lab 3-4 hrs/week beyond school hours, signed by Principal.  
6. Validate UDISE code and PAN details against official records before submission.  
7. Review the entire form for spelling/format errors before final submit.  
8. Do not use special characters or abbreviations in name/address fields unless officially registered.  

### Internal Review Gate
- [ ] All mandatory fields in the application form are completed  
- [ ] School registration certificate uploaded and valid  
- [ ] PAN card of school/trust uploaded and matches registration  
- [ ] UDISE code entered correctly and verifiable  
- [ ] Photographs of lab space uploaded (min 2: interior and exterior)  
- [ ] Infrastructure details (computers, internet, electricity) filled accurately  
- [ ] Undertaking to run lab 3-4 hrs/week beyond school hours uploaded, signed, and on letterhead  
- [ ] Declarations and consent boxes checked  
- [ ] Application reviewed for consistency (name, address, contact details match across docs)  
- [ ] Screenshot of final submission page taken and stored
