# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Beneficiary is an individual, farmer, cooperative, panchayat, or government institution  
- [ ] Project location is in an off-grid or poorly electrified area  
- [ ] System type is one of: solar home light, solar street light, solar pump, or mini-grid  
- [ ] System complies with MNRE technical standards  
- [ ] Installation will be done by an MNRE-authorized channel partner  
- [ ] Beneficiary has not previously availed subsidy for the same purpose under any other government scheme  
- [ ] Priority consideration given if beneficiary belongs to SC/ST, women, or is located in border regions  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Proof of identity (Aadhaar/Voter ID/PAN)  
- Proof of address  
- Bank account details for subsidy transfer  
- Udyam registration (if applicable)  
- GST registration (if applicable)  
- PAN card  
- Latest ITR (Income Tax Return)  

### Scheme-Specific Documents
- Land ownership or consent document (for community/installation site)  
- Technical specification of the proposed system  
- Photographs of installation site (before and after)  

### Document Quality Check
- All documents must be legible and in PDF or JPEG format  
- File size should not exceed 5 MB per document  
- Names on documents must match exactly as per application  
- Self-attested copies required for non-government issued documents  
- Documents in regional languages must be accompanied by self-certified English/Hindi translation

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required for this scheme. However, a technical specification of the proposed system is mandatory. Verify with the State Nodal Agency or nodal officer whether a Detailed Project Report (DPR) is needed for your specific system type and capacity.

### Application Form Filling Protocol
1. Ensure all beneficiary details (name, address, contact) match exactly across all documents  
2. Clearly specify the type of off-grid solar system being applied for (home light, street light, pump, mini-grid)  
3. Attach technical specifications compliant with MNRE standards  
4. Provide accurate bank details for subsidy transfer (name, account number, IFSC, branch)  
5. Declare that no prior subsidy has been availed for the same purpose under any other government scheme  
6. Submit before and after site photographs with clear timestamps and geo-tagging if possible  
7. Ensure land ownership/consent document is valid and covers the installation period  
8. Retain a copy of the submitted application and all enclosures for records  

### Internal Review Gate
- [ ] All sections of the application form are completed  
- [ ] All universal and scheme-specific documents are attached  
- [ ] Documents are legible, properly named, and within size limits  
- [ ] Declarations (e.g., no prior subsidy) are signed and dated  
- [ ] Bank details are verified for accuracy  
- [ ] Technical specifications align with MNRE-approved models under ALMM  
- [ ] Land document confirms rights for installation and operation

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via email or in person to the State Nodal Agency or authorized channel partner  
- Obtain and screenshot the submission acknowledgment (if digital) or collect a signed receipt (if physical)  
- Store the application reference number securely  
- Set follow-up reminders for Day 25 and Day 35

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from State Nodal Agency or MNRE  
- [ ] Confirm sanctioned subsidy amount (30%–90% of benchmark cost based on beneficiary category and region)  
- [ ] Ensure system is installed by an MNRE-authorized channel partner  
- [ ] Coordinate inspection by the concerned authority post-installation  
- [ ] Verify subsidy disbursement to beneficiary or vendor (as per scheme guidelines)  
- [ ] Obtain and file utilization certificate after successful installation and inspection  
- [ ] Document invoice and success fee for internal records  
- [ ] Advise beneficiary on post-installation monitoring and maintenance responsibility
