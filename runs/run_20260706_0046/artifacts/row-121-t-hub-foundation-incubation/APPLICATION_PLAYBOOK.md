# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Startup is a legally incorporated entity developing and commercializing technology-based products, platforms, or IP-led services that drive innovation, scalability, and impact.
- [ ] Recognised as a DPIIT-registered startup or eligible for such recognition.
- [ ] Core offering is technology-based (software, hardware, deep-tech, or IP-led platform).
- [ ] Not a pure service-based entity (e.g., consulting, outsourcing, staffing, training, or agency-type business).
- [ ] Demonstrates proof of traction in at least one of the following forms:
    - MVP or functional prototype
    - Paying customers or revenue
    - External funding (angel, VC, or grant)
    - Active pilots with institutions, corporates, or Government
- [ ] Incorporated ≤ 10 years from the date of registration.

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration
- PAN of the entity
- Latest Income Tax Returns (ITR)
- GST registration certificate (if applicable)
- Bank statements (last 6 months)
- Udyam Registration (MSME certificate)

### Scheme-Specific Documents
- Proof of traction (MVP, prototype, revenue, funding, or pilot details)
- Founder details and team background
- Business model or pitch deck
- Authorization letter from authorized signatory
- Details of funding received (if any)

### Document Quality Check
- All documents must be clear, legible scans or certified copies.
- File names must match the document type (e.g., "Certificate_of_Incorporation.pdf").
- File size should not exceed 5 MB per document.
- Documents must be in English or accompanied by a certified translation.
- Authorization letter must be on company letterhead and signed by an authorized signatory.
- Proof of traction documents must be recent (within last 6 months for revenue/customers, within last 1 year for funding/pilots).

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for this scheme. Flag: **verify with nodal officer** if a detailed project report is needed for specific sub-programs (e.g., AIC Semiconductor, Healthcare).

### Application Form Filling Protocol
1. Identify the relevant program (e.g., Foundation, AIC Semiconductor, SpaceTech, Healthcare, Mobility) based on startup stage and sector via https://t-hub.co/programs.
2. Visit the specific program page (e.g., https://t-hub.co/aic-semiconductors) to confirm eligibility and schedule.
3. Fill the application form completely; leave no mandatory fields blank.
4. Upload all documents in the specified format (PDF/JPEG, <5 MB each).
5. Ensure founder details, traction proof, and business model are clearly articulated.
6. Attach authorization letter from authorized signatory.
7. Double-check contact details and program-specific questions (e.g., MRR for Healthcare program).
8. Submit via the provided form or contact email (e.g., aic@t-hub.co) as indicated on the program page.

### Internal Review Gate
- [ ] All eligibility criteria verified and documented.
- [ ] Universal and scheme-specific documents collected and quality-checked.
- [ ] Application form filled completely with accurate information.
- [ ] All uploaded documents are legible and correctly named.
- [ ] Declarations and authorization letter signed.
- [ ] Program fee awareness communicated (INR 50,000 + GST for sector-specific programs).
- [ ] Submission protocol understood (screenshot, reference number, follow-up).

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the submitted application form or email confirmation.
- Store the application reference number or acknowledgment ID securely.
- Set follow-up reminders for 7 days post-submission if no acknowledgment received.
- Note the expected timeline for selection communication (varies by program).

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and store the approval letter from T-Hub.
- [ ] Verify sanctioned benefits (e.g., access to mentors, value partners, infrastructure; note: T-Hub facilitates access to funding like T-Fund ₹25 lakhs to ₹1 crore, SISFS, SIDBI IDEX but does not provide direct funding in all programs).
- [ ] If applicable, arrange payment of program fee (INR 50,000 + GST for sector-specific programs like Semiconductor, SpaceTech, Healthcare, Mobility).
- [ ] Complete onboarding formalities as communicated by T-Hub team.
- [ ] Track utilization of benefits (mentorship sessions, event access, resource usage) for internal reporting.
- [ ] Prepare for success fee invoicing as per consultancy agreement (if applicable).
