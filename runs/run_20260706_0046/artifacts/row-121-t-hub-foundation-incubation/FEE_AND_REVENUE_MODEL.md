## Pricing Principles
1. Value-based pricing aligned with the actual funding outcomes delivered (e.g., T-Fund provides ₹25 lakhs to ₹1 crore).
2. Transparent fee structures with no hidden charges; all program fees (e.g., INR 50,000 + GST) are disclosed upfront.
3. Success fees contingent on measurable outcomes such as grant approvals or funding disbursement.
4. Scheme-specific note: Moderate risk profile due to rolling application deadlines and variable processing times across programs (e.g., Healthcare program closes 28th Feb 2026, Mobility closes 7th June 2025), requiring active client engagement to meet timelines.
