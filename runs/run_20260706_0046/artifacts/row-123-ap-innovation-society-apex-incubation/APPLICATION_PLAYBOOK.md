## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A formal Detailed Project Report (DPR) is **not explicitly required**, but a comprehensive **business plan or project proposal** is mandatory. This should include:  
- Executive summary  
- Problem statement and proposed solution  
- Description of innovation/technology  
- Market analysis and scalability potential  
- Business model and revenue projections  
- Team qualifications and roles  
- Implementation timeline  
- Fund utilization plan (if seeking financial support)  
- Social impact assessment  

> **Note**: Verify with the nodal officer whether financial projections or IP details are expected at application stage, as financial support is discretionary and based on evaluation.

### Application Form Filling Protocol
1. Access the portal at [https://apinnovation.ap.gov.in](https://apinnovation.ap.gov.in) and navigate to the incubation/startup support section.  
2. Register as a new user using a valid email and mobile number (preferably founder’s).  
3. Fill in all fields in the online application form — **do not leave any section blank**; use “Not Applicable” only if genuinely irrelevant and justified.  
4. Upload documents in the specified order: business plan, incorporation proof (if applicable), PAN, Aadhaar (founders), address proof, innovation details, team profile.  
5. Ensure Aadhaar numbers are masked (last 4 digits visible) in uploaded copies for data privacy.  
6. Double-check that the Andhra Pradesh address proof clearly shows a location within the state.  
7. Save a draft before final submission and review all entries for spelling, consistency, and completeness.  
8. Submit only after internal review gate clearance; note the application reference number immediately upon submission.
