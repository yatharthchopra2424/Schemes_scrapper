# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a State Government, Union Territory, fisheries cooperative, fish farmer, entrepreneur, or other stakeholder involved in fisheries and aquaculture activities.
- [ ] Project proposal is submitted through the respective State Fisheries Department for approval and funding under the Centrally Sponsored Scheme (CSS) framework.
- [ ] Project adheres to scheme guidelines, technical feasibility, and financial viability requirements.
- [ ] Project component falls under Blue Revolution Scheme (e.g., aquaculture development, infrastructure, post-harvest).
- [ ] Detailed Project Report (DPR) prepared as per scheme guidelines.
- [ ] Project is within the scheme period (2015-16 to 2019-20) – **Note: Scheme is closed; verify if exceptions or transitional provisions apply via nodal officer.**
- [ ] Beneficiary has not exceeded funding limits or violated utilization certificate requirements from prior scheme participation.

> **Source**: Scheme Key Facts (Eligibility, Application Process, Key Caveats)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Business registration/incorporation certificate
- PAN card
- Aadhaar of authorized signatory
- Bank statements (last 6 months)
- ITR (last 2 years)
- GST registration certificate (if applicable)
- Udyam Registration (for MSMEs)

### Scheme-Specific Documents
- Detailed Project Report (DPR)
- Land ownership/lease documents
- Project cost estimates
- Technical feasibility report
- Environmental clearance (if applicable)
- No Objection Certificate (NOC) from relevant authorities
- Bank appraisal note (for loan linkage)
- Implementation schedule
- Undertaking from the beneficiary
- Registration/incorporation certificate (for companies, cooperatives, etc.)

### Document Quality Check
- All documents must be legible, scanned in PDF format, and clearly named (e.g., "DPR_BlueRevolution_Aquaculture.pdf").
- File size per document must not exceed 5 MB.
- Names on documents must match exactly with registration and PAN details.
- Certificates must be valid and not expired.
- Undertakings and declarations must be signed and dated.
- Language: English or Hindi; if regional language, provide certified translation.

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
**Yes, a Detailed Project Report (DPR) is required.**  
Standard sections to include:  
- Executive Summary  
- Project Background and Objectives  
- Technical Description (technology, species, systems)  
- Site Selection and Layout Plan  
- Project Cost Estimates (capital and recurring)  
- Implementation Schedule (milestones)  
- Financial Viability Analysis (IRR, NPV, payback period)  
- Environmental and Social Impact Assessment  
- Risk Assessment and Mitigation Plan  
- Monitoring and Evaluation Framework  
- Undertaking and Declarations  

> **Source**: Scheme Key Facts (Required Documents, Application Process); Supporting Evidence (Guidelines for Preparation of DPR)

### Application Form Filling Protocol
1. Access the application via the State Fisheries Department (not a central portal; submissions are made to State Fisheries Department for forwarding to DoF).  
2. Ensure all fields in the DPR and supporting documents are complete and accurate.  
3. Use the exact nomenclature as per scheme guidelines (e.g., "Specific Pathogen Free" where applicable).  
4. Attach all scheme-specific documents in the order listed in the checklist.  
5. Verify that the undertaking from the beneficiary is signed and notarized if required.  
6. Confirm that the Bank appraisal note is on official bank letterhead.  
7. Double-check that land documents clearly show ownership or lease rights for the project duration.  
8. Save a copy of the completed application package before submission.  

> **Source**: Scheme Key Facts (Application Process); Supporting Evidence (State-level submission process)

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] All universal and scheme-specific documents collected and quality-checked  
- [ ] DPR completed with all standard sections  
- [ ] Project cost estimates match bank appraisal and implementation schedule  
- [ ] Environmental clearance and NOC obtained (if applicable)  
- [ ] Undertaking from beneficiary signed and dated  
- [ ] All declarations in DPR and forms are signed  
- [ ] Application package compiled in correct order  
- [ ] Reference number or receipt obtained from State Fisheries Department post-submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the completed application package to the respective State Fisheries Department (as per scheme guidelines).  
- Obtain a receipt or acknowledgment (physical or digital) with date, time, and inward number.  
- Take a screenshot/scan of the acknowledgment and store it in the case file.  
- Note the reference number provided by the State Fisheries Department.  
- Set a follow-up reminder for 15 days post-submission to check status.  
- Monitor for communication from State Fisheries Department regarding forwarding to Department of Fisheries, GoI for appraisal.  

> **Source**: Scheme Key Facts (Application Process: "Submit the DPR to the respective State Fisheries Department")

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the approval letter from the Department of Fisheries, Government of India (via State Fisheries Department).  
- [ ] Confirm the sanctioned amount matches the approved project cost and funding pattern (60:40 Central:State for general States; 90:10 for Himalayan/N-E States; 100% for UTs).  
- [ ] Utilize funds as per approved plan and installment schedule tied to milestone achievement.  
- [ ] Submit periodic progress reports and utilization certificates as required for tranche release.  
- [ ] Ensure project completion within stipulated timeline to avoid fund disbursement delays.  
- [ ] Upon project completion, submit final utilization certificate and completion report.  
- [ ] Claim reimbursement or receive final installment based on milestone achievement.  
- [ ] Retain all records for audit and potential success fee invoicing.  

> **Source**: Scheme Key Facts (Financial Support, Application Process, Key Caveats)  
> **Portal Reference**: https://dof.gov.in/blue-revolution (for scheme details and guidelines)
