# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity is incorporated in India  
- [ ] Net worth of at least INR 25 lakh as per the last audited balance sheet  
- [ ] Demonstrates a genuine need for testing in the sandbox  
- [ ] Has a clear exit strategy  
- [ ] Product or service is innovative and not already widely available in the market  
- [ ] Entity is a fintech startup or financial technology company  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation/Registration  
- PAN Card  
- Latest audited balance sheet  
- ITR (Income Tax Returns) for last 2–3 years  
- GST Registration Certificate (if applicable)  
- Bank statements (last 6 months)  
- Udyam Registration (if applicable)  

### Scheme-Specific Documents
- Detailed description of the innovative product or service  
- Business plan and financial projections  
- Details of the technology to be used  
- Customer protection and data security measures  
- Exit strategy and scalability plan  

### Document Quality Check
- All documents must be legible, scanned in PDF format  
- File size should not exceed 10 MB per document  
- Document names must match the entity’s legal name (as per Certificate of Incorporation)  
- Audited balance sheet must be certified by a Chartered Accountant  
- All documents must be in English or accompanied by a certified translation  
- Declarations and undertakings must be signed and dated

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A formal Detailed Project Report (DPR) is not explicitly required. However, applicants must submit a **business plan and financial projections**, a **detailed description of the innovative product/service**, and an **exit strategy**. If in doubt, verify with the nodal officer.

### Application Form Filling Protocol
1. Access the portal: https://www.rbi.org.in/Scripts/bs_viewcontent.aspx?Id=3854  
2. Ensure all fields are filled accurately; do not leave mandatory sections blank  
3. Upload documents in PDF format, clearly labeled (e.g., “Innovative_Product_Description.pdf”)  
4. Double-check that the net worth in the audited balance sheet meets or exceeds INR 25 lakh  
5. Clearly articulate the **innovative nature** of the product/service and how it differs from existing market offerings  
6. Explicitly state the **genuine need for sandbox testing** and the **exit strategy**  
7. Confirm compliance with all other applicable laws and regulations (as per caveats)  
8. Review the application thoroughly before submission to avoid delays  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] Universal and scheme-specific documents collected and quality-checked  
- [ ] Application form completed with accurate, consistent information  
- [ ] Declarations signed and dated  
- [ ] Documents uploaded in correct format and size  
- [ ] Application reviewed for clarity, completeness, and alignment with sandbox objectives  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the submission confirmation page showing the timestamp  
- Save the application reference number provided by the portal  
- Store all submitted documents in a dedicated case folder (digital and backup)  
- Set a follow-up reminder for 15 days post-submission  
- If no acknowledgment is received within 7 days, initiate follow-up

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and securely store the sandbox approval letter from RBI  
- [ ] Verify the scope, duration, and specific regulatory relaxations granted  
- [ ] Note any reporting or compliance requirements during the testing phase  
- [ ] Prepare for live testing under RBI supervision as per the sandbox agreement  
- [ ] Plan for submission of final report on outcomes and learnings post-testing  
- [ ] Coordinate with RBI for feedback and potential pathway to broader regulatory approval  
- [ ] Track utilization of regulatory facilitation (non-financial support) for internal reporting  
- [ ] Prepare invoice for success fee as per consultancy agreement (if applicable)
