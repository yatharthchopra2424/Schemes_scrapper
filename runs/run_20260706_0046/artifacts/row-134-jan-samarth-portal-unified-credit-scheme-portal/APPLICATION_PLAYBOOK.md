# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is an Indian resident  
- [ ] Applicant has a valid Aadhaar number  
- [ ] Applicant has a valid PAN  
- [ ] Applicant has an active bank account  
- [ ] Applicant meets scheme-specific eligibility criteria (e.g., DPIIT recognition for startups, Udyam registration for micro enterprises, income limits for housing loans, etc.)  
- [ ] Applicant selects the appropriate loan category on the JanSamarth portal based on their financing need  
- [ ] Applicant confirms eligibility by answering the portal’s eligibility questions for the selected scheme  

> **Note**: Eligibility varies by scheme. Applicants must first check eligibility under their required loan category on the portal. General requirements include being an Indian resident, having a valid Aadhaar, PAN, and bank account, and meeting scheme-specific criteria as defined by the respective nodal ministry.  
> **Source**: [JanSamarth Portal](https://www.jansamarth.in)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Aadhaar Number  
- Voter ID  
- PAN  
- Bank Statements  
- Basic details filled on the JanSamarth portal  

### Scheme-Specific Documents
Documents vary by scheme. Examples from evidence include:  
- **For Startup Loans (SCGSS)**: DPIIT Startup certificate, Incorporation documents (MoA, AoA, Partnership deed), Audited Balance Sheet (last 3 years), CMA data, Detailed Project Report (DPR), Udyam Registration Number, Aadhaar/PAN of directors/partners  
- **For PMEGP**: Project report, Caste certificate, Special category certificate, Rural area certificate, Education/skill training/EDP certificate, Authorization letter  
- **For PM SVANidhi**: Certificate of Vending/Identity Card, Aadhaar Card, Voter ID (Assam & Meghalaya), PAN card  
- **For Weavers Mudra Scheme**: Handloom weaver certification, project details, utility certificates, IPR details, statutory approvals (Udyam, GST, Pollution Control)  
- **For Agriculture Infrastructure Fund (AIF)**: Project details for post-harvest management infrastructure, FPO registration (if applicable)  
- **For NAMASTE**: Occupational Photo ID Card, proof of engagement in sanitation work, skill training/rehabilitation documents  

> **Note**: Each scheme has different documentation requirements. Applicants must upload scheme-specific documents as indicated on the portal during application.  
> **Source**: [JanSamarth Portal](https://www.jansamarth.in), [Startup Scheme FAQs](https://jansamarth.in/business-loan-startup-scheme), [PMMY FAQs](https://jansamarth.in/business-loan-pradhan-mantri-mudra-yojana-scheme), [PM SVANidhi FAQs](https://jansamarth.in/prime-minister-svanidhi-scheme)

### Document Quality Check
- [ ] All documents are clear, legible scans or PDFs  
- [ ] File size does not exceed portal limits (typically 5 MB per file)  
- [ ] Names on documents match exactly with applicant details  
- [ ] Documents are self-attested or certified as required (e.g., audited financials, DPIIT certificate)  
- [ ] Documents are in English or Hindi; if in another language, include certified translation  
- [ ] Bank statements are recent (last 3–6 months)  
- [ ] No expired certificates (e.g., Udyam, DPIIT, GST)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
- **Required for**: Startup Loans (SCGSS), PMEGP, NAMASTE, Agriculture Infrastructure Fund (AIF), Agri-Clinic and Agribusiness Centers (ACABC), and other enterprise-focused schemes  
- **Standard Sections**: Executive summary, promoter profile, project description, market analysis, technical details, financial projections (cost, revenue, profitability), employment generation, risk assessment, implementation schedule  
- **If not mentioned in scheme details**: Verify with nodal officer or scheme guidelines whether DPR is mandatory  
> **Source**: [Startup Scheme FAQs](https://jansamarth.in/business-loan-startup-scheme), [PMEGP FAQs](https://jansamarth.in/prime-minister-employment-generation-program-scheme)

### Application Form Filling Protocol
1. Visit [https://www.jansamarth.in](https://www.jansamarth.in) and select the appropriate loan category  
2. Click “Check Eligibility” and answer the scheme-specific questions accurately  
3. If eligible, click “Apply Online” and register/login using mobile number and OTP  
4. Fill in basic details (name, contact, Aadhaar, PAN, bank info) – the portal’s smart analytics will auto-fill where possible  
5. Upload all required documents in the specified format (PDF/JPG, under size limit)  
6. Review the auto-filled and entered details for accuracy before submission  
7. Select a preferred bank from the list of 250+ Member Lending Institutions (MLIs)  
8. Submit the application and note the application reference number  
9. Track status in real time via the portal dashboard  
10. Respond promptly to any bank queries or document requests  
> **Source**: [JanSamarth Portal Process](https://www.jansamarth.in), [Startup Scheme Application Steps](https://jansamarth.in/business-loan-startup-scheme)

### Internal Review Gate
- [ ] All applicant details (name, contact, Aadhaar, PAN) are correctly entered  
- [ ] Scheme and loan category are correctly selected  
- [ ] All universal documents are uploaded and legible  
- [ ] All scheme-specific documents are uploaded and valid  
- [ ] Declarations and consent checkboxes are ticked  
- [ ] Application form is free of spelling or factual errors  
- [ ] Bank selection is appropriate based on client profile and scheme  
- [ ] Reference number is recorded after submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the confirmation page showing application reference number and timestamp  
- Store the reference number securely in the case file  
- Set calendar reminders for follow-up at 7 days, 15 days, and 30 days post-submission  
- Advise client to monitor application status via JanSamarth portal dashboard using login credentials

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify digital approval letter from the selected bank via JanSamarth portal  
- [ ] Confirm sanctioned loan amount, interest rate, repayment tenor, and margin money (if applicable)  
- [ ] Ensure utilization of funds is for the approved end-use only (as per scheme guidelines)  
- [ ] Prepare and submit Utilization Certificate (UC) as required by the scheme and bank  
- [ ] Track timely repayment to avoid NPA classification and maintain eligibility for future benefits  
- [ ] Coordinate with client for success fee invoicing upon successful disbursement and utilization  
- [ ] Maintain records of all correspondence, approvals, and compliance documents for audit purposes  

> **Note**: Post-approval compliance varies by scheme (e.g., interest subvention claims under DAY-NRLM, margin money utilization under PMEGP, guarantee fee reimbursement under CGSS).  
> **Source**: [JanSamarth Portal Benefits](https://www.jansamarth.in), [Scheme-specific FAQs](https://jansamarth.in/)
