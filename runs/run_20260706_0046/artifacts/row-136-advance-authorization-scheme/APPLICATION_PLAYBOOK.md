# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a manufacturer exporter or merchant exporter tied to a supporting manufacturer  
- [ ] Applicant has a valid Importer Exporter Code (IEC)  
- [ ] Applicant is engaged in the manufacture and export of goods  
- [ ] Applicant is exporting under the Foreign Trade Policy, 2023  
- [ ] Export product and its HS code are identified  
- [ ] List of inputs required with their HS codes and quantities is prepared  
- [ ] Export order or self-declaration of export capability is available  
- [ ] Undertaking to fulfill export obligation is ready  
- [ ] IEC holder's digital signature certificate is available (if applicable)  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- PAN card of the applicant  
- Importer Exporter Code (IEC) certificate  
- GST registration certificate  
- Bank certificate or cancelled cheque  
- Udyam Registration (if applicable)  
- Income Tax Returns (ITR) of last 2 years  
- Bank statements of last 6 months  

### Scheme-Specific Documents
- Details of the export product and its HS code  
- List of inputs required with their HS codes and quantities  
- Export order or self-declaration of export capability  
- Undertaking to fulfill export obligation  
- Copy of IEC holder's digital signature certificate (if applicable)  

### Document Quality Check
- All documents must be clear, legible scans (PDF preferred)  
- File size should not exceed 5 MB per document  
- Name on documents must match exactly with IEC and PAN details  
- Documents must be self-attested or certified by a gazetted officer/notary  
- Language: English or Hindi; if in another language, certified translation required  
- Digital signature certificate must be valid and issued by a licensed Certifying Authority

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for Advance Authorization Scheme. However, applicants must provide a detailed description of the export product, inputs, and export obligation as part of the online form. Verify with the nodal officer if additional project details are needed for scrutiny.

### Application Form Filling Protocol
1. Register on the DGFT website using your valid IEC.  
2. Log in and navigate to the **Advance Authorisation** module under Services.  
3. Fill in applicant details (name, address, IEC, PAN, GST) accurately as per documents.  
4. Specify the export product with correct ITC(HS) code and description.  
5. List all inputs with their ITC(HS) codes, quantities, and unit of measurement.  
6. Declare the export obligation quantity and value based on the export order or self-declaration.  
7. Upload all required documents in PDF format, ensuring file names are clear (e.g., PAN.pdf, IEC.pdf).  
8. Review all entries before submission; errors may lead to rejection or delay.  
9. Pay the applicable application fee online via net banking, UPI, or card.  
10. Submit the application and save the acknowledgment with application number.  

### Internal Review Gate
- [ ] All applicant details match PAN, IEC, and GST records  
- [ ] Export product HS code is correct and active  
- [ ] Inputs list includes only those physically incorporated into the export product (no capital goods, fuel, lubricants)  
- [ ] Quantities of inputs are consistent with export obligation and product BOM  
- [ ] Export obligation is clearly stated and matches export order/self-declaration  
- [ ] Undertaking to fulfill export obligation is signed and dated  
- [ ] Digital signature certificate uploaded (if applicable) and valid  
- [ ] All documents are legible, correctly named, and within size limits  
- [ ] Application fee payment confirmation is attached  
- [ ] Declarations and undertakings are electronically signed where required

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the DGFT portal: https://dgft.gov.in/CP/?opt=advance-authorization  
- Take a screenshot of the confirmation page showing the application number and timestamp  
- Store the application reference number in the case file and set a calendar reminder for follow-up in 15 days  
- Save a copy of the submitted application and all uploaded documents

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Download and save the electronically issued Advance Authorization from the DGFT portal  
- [ ] Verify the sanctioned inputs, quantities, validity period (usually 12 months), and export obligation details  
- [ ] Import inputs as per the authorization within the validity period  
- [ ] Fulfill the export obligation (physical export of the final product) within the validity period  
- [ ] Apply for redemption of the authorization after export realization and submission of shipping bills  
- [ ] Maintain records of import, manufacturing, and export for audit verification by DGFT  
- [ ] Ensure utilization certificate is prepared if required for internal or compliance purposes  
- [ ] Invoice success fee as per consultancy agreement upon successful redemption or fulfillment of export obligation
