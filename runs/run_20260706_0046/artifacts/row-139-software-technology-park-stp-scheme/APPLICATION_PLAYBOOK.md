# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID is assigned, the target scheme is selected scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity is engaged in the development and export of computer software, including professional services via communication links or physical media  
- [ ] Entity can set up an STP unit anywhere in India (Pan-India geographic scope)  
- [ ] Jurisdictional STPI authorities can clear projects costing less than Rs.100 million with Indian Investment  
- [ ] 100% foreign equity is permitted (if applicable)  
- [ ] Entity maintains 100% export orientation for software and professional services (key caveat)  
- [ ] Entity understands benefits are contingent on compliance with export performance norms (Positive Net Foreign Exchange Earnings)  
- [ ] Entity is a software exporter, IT/ITES company, or computer software developer (target beneficiary)  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation Certificate  
- PAN Card  
- ITR (last 2-3 years)  
- GST Registration Certificate  
- Bank Statements (last 6 months)  
- Udyam Registration (MSME certificate, if applicable)  

### Scheme-Specific Documents
- Letter of Permission application  
- Legal Undertaking-cum-endorsement of Capital Goods (CG)  
- Green Card application  
- Project details for clearance (if project cost < Rs.100 million with Indian Investment)  
- Rs.100 million with Indian Investment)  
- Details of foreign equity (if applicable)  
- Import/export documentation for hardware and software  
- Proof of donation eligibility for computers after two years (if applicable)  

### Document Quality Check
- All documents must be legible scans or certified copies  
- File names must match document type (e.g., "Incorporation_Certificate.pdf")  
- PDF file size should not exceed 10 MB per document  
- All certificates must be valid and not expired  
- Documents in regional languages must be accompanied by certified English/Hindi translations  
- Undertakings must be on stamp paper and notarized where required

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required for STP Scheme registration. However, project details for clearance are needed if the project cost is less than Rs.100 million with Indian Investment. A detailed project report may be advisable for internal planning. Verify with jurisdictional STPI officer if a formal DPR is mandated for your case.  

### Application Form Filling Protocol
1. Access the application portal: **https://stpi.in/en/stp-scheme** and click "For Online Registration Click Here"  
2. Ensure all entity details (name, address, PAN, GSTIN) match incorporation and tax records exactly  
3. Clearly state the 100% export-oriented nature of the business in the project description  
4. Declare foreign equity percentage accurately if applicable (100% permitted)  
5. Specify proposed project cost and confirm if it falls under Rs.100 million with Indian Investment for faster clearance  
6. List all intended hardware and software imports to avail duty-free benefit  
7. Confirm commitment to Positive Net Foreign Exchange Earnings (simplified export performance norm)  
8. Double-check all declarations before submission; incomplete forms will delay processing  

### Internal Review Gate
- [ ] All application form fields completed accurately  
- [ ] Universal and scheme-specific documents attached and validated  
- [ ] Letter of Permission application duly filled and signed  
- [ ] Legal Undertaking-cum-endorsement of Capital Goods executed on stamp paper  
- [ ] Green Card application completed  
- [ ] Project cost details provided (if < Rs.100 million with Indian Investment)  
- [ ] Foreign equity details disclosed (if applicable)  
- [ ] Import/export plan for hardware and software documented  
- [ ] Declarations signed and dated  
- [ ] Application reviewed for consistency with STP Scheme eligibility and benefits

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the STPI online portal: **https://stpi.in/en/stp-scheme**  
- Take a screenshot of the submission confirmation page showing timestamp and application ID  
- Save the application reference number securely in the case file  
- Set calendar reminders for follow-up at 10 days (Letter of Permission), 13 days (Legal Undertaking), and 15 days (Green Card)  

### Follow-Up Script (to nodal officer or portal helpdesk)

### Escalation Path
- Level 1: Portal helpdesk via the STPI website contact form or email to sachin[at]stpi[dot]in (Chief Finance Officer, STPI HQ)  
- Level 2: Jurisdictional STPI Director (details available at https://stpi.in/en/about-stpi under "STPI Jurisdictional Directors")  
- Level 3: RTI filing if no response within statutory SLA (refer to Citizens Charter timelines: LoP 10 days, Legal Undertaking 3 days, Green Card 2 days)  

---

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and securely store the Letter of Permission from jurisdictional STPI authorities  
- [ ] Verify and execute the Legal Undertaking-cum-endorsement of Capital Goods  
- [ ] Receive and confirm the Green Card issuance  
- [ ] Confirm sanctioned benefits: duty-free import eligibility, GST refund on DTA-purchased capital goods, 100% depreciation on computers/peripherals over five years  
- [ ] Ensure compliance with 100% export orientation and Positive Net Foreign Exchange Earnings norm  
- [ ] Maintain records for utilization certificate and audit purposes  
- [ ] Coordinate with finance team to avail GST refund on capital goods purchased from Domestic Tariff Area (DTA)  
- [ ] Plan for donation of computers and peripherals after two years of import (if applicable)  
- [ ] Track success fee invoice for consulting services upon client realization of benefits
