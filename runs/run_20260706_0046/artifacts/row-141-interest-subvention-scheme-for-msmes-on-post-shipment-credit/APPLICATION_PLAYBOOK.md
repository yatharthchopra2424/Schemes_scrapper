# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] MSME exporter with valid Udyam Registration (UR) Certificate  
- [ ] Has availed post-shipment credit from scheduled commercial banks or other eligible financial institutions for export of goods or services  
- [ ] Export proceeds must be realized within the stipulated time period as per RBI guidelines  
- [ ] Beneficiary must be a valid MSME as per MSMED Act, 2006  
- [ ] Must have a valid Udyam Registration Certificate  
- [ ] Must not have availed similar interest subvention from any other government scheme for the same transaction  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Udyam Registration Certificate (URC)  
- Import Export Code (IEC)  
- PAN Card  
- GST Registration Certificate and Returns  
- Income Tax Returns (ITR) for past 1-3 years  
- Bank Statements (6-12 months)  
- Business address and ownership proof  
- Financial statements (Balance Sheet, P&L statement, cash flow statement)  

### Scheme-Specific Documents
- Proof of export realization (e.g., bank realization certificate, shipping bill)  
- Interest payment certificate from the lending institution  
- Loan sanction letter for post-shipment credit  
- Bank statement showing interest payment  
- Shipping bill and bill of lading  
- Bank realization certificate (BRC) or foreign inward remittance certificate (FIRC)  

### Document Quality Check
- File size: Each document must be under 5 MB  
- File naming: Must follow format `SchemeName_DocumentType_ClientName_Date.pdf` (e.g., `InterestSubventionScheme_InterestPaymentCertificate_ABCExports_20240515.pdf`)  
- All documents must be legible, certified (if applicable), and in English or Hindi  
- Udyam Registration Certificate must be valid and not expired  
- IEC must be active and not older than 3 years (if applicable per scheme context)  
- Bank statements must show clear interest payment transactions  
- Interest payment certificate must be issued by the lending institution on letterhead, signed, and stamped

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not mentioned in evidence. Flag: **verify with nodal officer.**  

### Application Form Filling Protocol
1. Ensure all fields in the application form are filled accurately; leave no blank unless marked optional.  
2. Match all names, addresses, and registration numbers exactly as per Udyam Registration Certificate and IEC.  
3. Attach all scheme-specific and universal documents in the prescribed order and format.  
4. Declare that the beneficiary has not availed similar interest subvention from any other government scheme for the same transaction.  
5. Confirm that export proceeds were realized within the stipulated time as per RBI guidelines.  
6. Validate that the interest payment certificate is issued by the lending institution and corresponds to the post-shipment credit availed.  
7. Double-check that the loan sanction letter is specifically for post-shipment credit (not pre-shipment or working capital).  
8. Ensure the application is submitted through the designated portal or nodal agency as per scheme guidelines.  

### Internal Review Gate
- [ ] All application fields completed  
- [ ] All universal and scheme-specific documents attached  
- [ ] Declarations signed and dated  
- [ ] Udyam Registration Certificate validity verified  
- [ ] IEC validity confirmed (not older than 3 years if applicable)  
- [ ] Export realization proof matches shipping bill and BRC/FIRC  
- [ ] Interest payment certificate matches loan account and bank statement  
- [ ] No duplicate claims for same transaction under other schemes  
- [ ] Application form reviewed for consistency and accuracy
