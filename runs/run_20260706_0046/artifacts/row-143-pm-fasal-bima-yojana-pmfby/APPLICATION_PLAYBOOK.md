# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Farmer is growing notified crops in a notified area during the season  
- [ ] Farmer has insurable interest in the crop  
- [ ] For loanee farmers: Possesses a Crop Loan account/KCC account with credit limit sanctioned/renewed for the notified crop during the crop season  
- [ ] For non-loanee farmers: Not covered under compulsory component but has insurable interest in the insured crop(s)  
- [ ] Farmer is eligible for voluntary coverage if not covered under compulsory component  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Aadhaar card  
- PAN card  
- Bank account details (including IFSC code)  
- Land ownership/tenancy documents  
- Crop sowing declaration  
- Previous year’s ITR (if applicable)  
- Udyam registration (if applicable)  

### Scheme-Specific Documents
- Loan sanction letter (for loanee farmers)  
- Kisan Credit Card (KCC) details (if applicable)  
- Crop details (notified crop, area under cultivation in hectares)  
- Declaration form (as per SLCCCI notification)  
- Premium payment proof (if applicable for voluntary farmers)  

### Document Quality Check
- All documents must be legible and scanned in PDF format  
-FAQC
- File size must not exceed 5 MB per document  
- Name on documents must match exactly with Aadhaar/PAN  
- Land records must be certified by revenue authority  
- Bank account must be active and in the farmer’s name  
- Declaration form must be filled completely and signed

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for PMFBY enrollment. Flag: **verify with nodal officer** if any additional documentation is sought for special cases.

### Application Form Filling Protocol
1. Access the portal at https://pmfby.gov.in and click 'Farmer Corner' → 'Enroll Now'  
2. Select your stakeholder type (Farmer)  
3. Enter Aadhaar-linked mobile number and verify via OTP  
4. Fill in personal details: name, address, bank account, IFSC  
5. Provide crop details: notified crop, area under cultivation (in hectares), season  
6. Upload land ownership/tenancy documents  
7. For loanee farmers: attach loan sanction/KCC details  
8. Use the Insurance Premium Calculator to estimate premium before final submission  
9. Review all entries for accuracy before submission  
10. Submit and note down the Application Reference Number  
11. Use the Application Status feature to track progress  

### Internal Review Gate
- [ ] All personal details match Aadhaar/PAN  
- [ ] Bank account details are correct and active  
- [ ] Crop and area details are accurate and supported by documents  
- [ ] Land documents are certified and legible  
- [ ] Premium amount calculated correctly (if applicable)  
- [ ] Declarations signed and dated  
- [ ] Application reference number saved  
- [ ] Screenshot of submission confirmation taken

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the submission confirmation page showing Application Reference Number  
- Save the reference number in the case file  
- Set follow-up reminders:  
  - Day 25: Check application status via portal  
  - Day 30: If no update, contact helpdesk

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter via portal or SMS  
- [ ] Confirm sanctioned amount and sum insured  
- [ ] Ensure premium has been debited (for loanee farmers) or paid (for voluntary farmers)  
- [ ] Monitor crop status and report any loss via CLAP App or KRPH Helpline (14447)  
- [ ] For claims: use Policy ID to check status via Application Status feature  
- [ ] Claim amount will be credited electronically to the insured bank account  
- [ ] On-account payment (up to 25% of likely claims) available if expected yield <50% of normal yield  
- [ ] Utilization certificate not required for PMFBY (claim-based payout)  
- [ ] Success fee invoice to be raised only if agreed upon in consultancy terms
