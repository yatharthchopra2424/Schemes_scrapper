# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Beneficiary type verified: Individual farmer, entrepreneur, society/SHG/FPO, manufacturer, or dealer  
- [ ] Farmer-specific: Aadhaar number provided  
- [ ] Farmer-specific: Land records (record-of-right) submitted  
- [ ] Farmer-specific: Bank details (bank passbook copy) provided  
- [ ] Farmer-specific: Identity proof (non-Aadhaar) submitted  
- [ ] Farmer-specific: Caste category certificate (if SC/ST/OBC) provided  
- [ ] Entrepreneur/Society/Manufacturer: GST certificate submitted  
- [ ] Entrepreneur/Society/Manufacturer: PAN submitted  
- [ ] Manufacturer: Product test report submitted  
- [ ] CHC project applicant: Agriculture graduate certificate provided  
- [ ] CHC project applicant: Domicile certificate provided  
- [ ] CHC project applicant: Date of birth proof provided  
- [ ] CHC project with loan > ₹25 lakh: Bank loan documents uploaded  
- [ ] All applicants: Correct state, district, block, and village selected during registration  
- [ ] All applicants: Accurate details furnished to avoid debarment during physical verification  
- [ ] Manufacturer: GST registration and product test reports submitted  
- [ ] Dealer: Registered through manufacturer  

*Source: Eligibility and Required Documents sections from KEY FACTS*

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Aadhaar card  
- PAN card  
- Bank passbook/statement  
- GST certificate (if applicable)  
- Udyam registration (if applicable)  
- ITR (for entrepreneurs/societies/manufacturers)  
- Identity proof (Voter ID, driving license, passport, etc.)  

### Scheme-Specific Documents
- Record-of-right of land (for farmers)  
- Passport size photograph  
- Copy of ID proof (except Aadhaar)  
- Caste category certificate (for SC/ST/OBC)  
- GST certificate (for Manufacturer/Entrepreneur)  
- PAN (for Entrepreneur/Society/Manufacturer)  
- Product test report (for Manufacturer)  
- Bank loan documents and account details (for back-ended subsidy in CHC projects over ₹25 lakh)  
- Bill/invoice of machinery  
- Machine details (make, model, serial no., engine no., chassis no.)  
- Joint photographs (farmer, implement, dealer)  
- Agriculture graduate certificate (for CHC applicant)  
- Domicile certificate (for CHC applicant)  

*Source: Required Documents list from KEY FACTS*

### Document Quality Check
- File size: Under 5 MB per document  
- File format: PDF or JPEG/PNG  
- Name matching: Applicant name must match across all documents (Aadhaar, bank, land records)  
- Certification: Self-attested copies acceptable; gazetted officer attestation preferred for land records  
- Language: Documents in Hindi or English; vernacular documents require certified translation  
- Validity: Land records and certificates must be current (issued within last 6 months where applicable)  
- Bank details: IFSC code and account number clearly visible  
- Photographs: Clear, recent, with visible faces and machinery details

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for single implement applications. For CHC projects, a basic project report is implied through the upload of project details (agriculture graduate, domicile, DOB certificate) and implement bills. **Verify with nodal officer** if a detailed DPR is expected for CHC projects exceeding certain thresholds.  

*Source: Application Process and FAQs from KEY FACTS and Supporting Evidence*

### Application Form Filling Protocol
1. Register on https://agrimachinery.nic.in by selecting correct beneficiary type (Farmer, Entrepreneur, Society/SHG/FPO, Manufacturer)  
2. Enter accurate Aadhaar/mobile/name, state, district, block, village, land area, address, pincode, bank details, and identity proof  
3. For Farmer: Ensure land details and bank information are correctly entered  
4. For Entrepreneur/Society: Enter GSTN/PAN, contact details, and address accurately  
5. For Manufacturer: Upload GST certificate, product details, test report, and bank details  
6. Accept terms and conditions to receive User ID and password via SMS  
7. Login using credentials and navigate to the relevant module (Single Implement or CHC)  
8. For machinery purchase: Select implement, check availability, add application, generate PIN, select dealer, negotiate price, upload bill and joint photographs  
9. For CHC project: Apply for CHC establishment, upload project details (agriculture graduate, domicile, DOB certificate), await government approval, print permit, upload implement bill and loan documents (if applicable)  
10. Double-check all entries before final submission; incorrect details (gender, DOB, mobile, category, bank, land) may lead to debarment during physical verification  

*Source: Application Process and Key Caveats from KEY FACTS*

- [ ] Bill/invoice uploaded with correct machinery details (make, model, serial no.)

- [ ] Declarations and terms and conditions accepted  
- [ ] Application reference number and PIN noted for tracking

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the final submission confirmation page showing the application reference number  
- Store the reference number securely for tracking and future reference  
- Save a copy of the submitted application and all uploaded documents  
- Set follow-up reminders for:  
  - 3 days post-submission: Confirm receipt via SMS/email  
  - 7 days: Check application status on portal  
  - 15 days: Follow up if no update on status  
  - After physical verification: Confirm subsidy approval and payment file generation

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from government officer  
- [ ] Confirm sanctioned amount matches expected subsidy (centre + state/top-up limits)  
- [ ] Verify subsidy disbursement via RTGS/NEFT to beneficiary’s bank account (farmer or dealer, as selected during bill upload)  
- [ ] Utilization certificate: Not required for SMAM as subsidy is DBT-linked to verified purchase; however, retain all bills and joint photographs for audit purposes  
- [ ] Invoice success fee as per firm’s engagement terms  
- [ ] Advise client to retain records for minimum 3 years for potential audit  
- [ ] For CHC: Ensure joint photographs (farmer, implement, officer) are uploaded post-verification as per process  

*Source: Financial Support, Application Process, and Key Caveats from KEY FACTS*
