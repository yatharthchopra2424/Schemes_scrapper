## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN Card of the Entity  
- Audited Financial Statements (ITR) for last 2 years  
- GST Registration Certificate (if applicable)  
- Bank Statements of last 6 months  
- Udyam Registration Certificate (if MSME)  
- Authorization Letter / Board Resolution for application submission  

### Scheme-Specific Documents
- Detailed Project Report (DPR) outlining micro irrigation promotion plan, target farmers, area coverage, and technology to be deployed  
- Land lease / ownership documents for demonstration plots (if applicable)  
- Memorandum of Understanding (MoU) with farmers or farmer groups willing to adopt micro irrigation  
- Technical feasibility report from empaneled agency or agricultural university  
- List of proposed micro irrigation equipment with specifications and cost estimates  
- Utilization plan for fund disbursement (tranche-wise)  
- No Objection Certificate (NOC) from State Agriculture/Horticulture Department (if required)  
- Past performance report on similar agri-projects (if any)  

### Document Quality Check
- All documents must be legible, scanned in PDF format (max file size: 5 MB per document)  
- Names on documents must exactly match the registered entity name  
- Financial statements must be audited and signed by a Chartered Accountant  
- DPR must be signed by the project lead and authorized signatory  
- All certificates (PAN, GST, Udyam) must be valid and not expired  
- Documents in regional languages must be accompanied by certified Hindi/English translation  
- Bank statements must be stamped and signed by the bank authority

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
**Required**: Yes, a Detailed Project Report (DPR) is mandatory for MIF applications.  

**Standard Sections**:  
- Executive Summary  
- Organization Background and Credentials  
- Project Objectives (aligned with MIF goals: water use efficiency, farmer income enhancement)  
- Target Beneficiaries (number and profile of farmers)  
- Geographical Coverage (village, block, district)  
- Technology Plan (type of micro irrigation: drip/sprinkler, spacing, pressure requirements)  
- Implementation Plan (phased rollout, timeline, responsibilities)  
- Budget Breakdown (equipment, installation, training, monitoring)  
- Sustainability and Maintenance Plan  
- Risk Assessment and Mitigation Measures  
- Expected Outcomes (water saved, area covered, yield improvement)  
- Annexures: MoUs, land documents, technical quotes, authorization letters  

> **Note**: Verify DPR format and approval protocol with NABARD’s nodal officer, as specific templates may be prescribed.

### Application Form Filling Protocol
1. Access the NABARD portal (https://nabard.org) and navigate to the ‘Lending’ or ‘Schemes’ section for Micro Irrigation Fund.  
2. If direct link is unavailable, use the search function or contact NABARD’s helpdesk for the correct application URL.  
3. Fill all fields in the application form using **exact names and numbers** as per registered documents (PAN, Udyam, Bank Account).  
4. Ensure the project cost and loan amount requested are clearly specified and match the DPR budget.  
5. Select the correct applicant category: FPO / Cooperative / SHG / State Agency.  
6. Upload all documents in PDF format, ensuring each file is named clearly (e.g., “PAN_ABCFPO.pdf”, “DPR_MIF_ProjectX.pdf”).  
7. Declarations must be signed digitally or physically scanned with signature; unsigned forms will be rejected.  
8. Before final submission, preview the entire form to confirm no fields are left blank or marked “TBD”.  

### Internal Review Gate
- [ ] All applicant details (name, PAN, address, bank) match supporting documents  
- [ ] Project cost in application form matches DPR budget summary  
- [ ] Loan amount requested does not exceed eligible limit (typically up to 70% of project cost)  
- [ ] All universal and scheme-specific documents are attached and correctly named  
- [ ] DPR includes all required sections and is signed by authorized signatory  
- [ ] Declarations and undertakings are signed and dated  
- [ ] No spelling or formatting errors in text fields  
- [ ] Application reference number is noted after submission (to be filled post-submission)
