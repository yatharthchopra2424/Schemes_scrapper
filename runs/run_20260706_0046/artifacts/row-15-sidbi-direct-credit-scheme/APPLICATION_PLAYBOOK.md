# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] MSME unit in operation (minimum vintage varies by product: 2 years for project funding, 3 years for machinery loan, 2 years for GST Sahay, 6 months for JAKs)
- [ ] Mandatory Udyam Registration Certificate
- [ ] Mandatory GST Registration
- [ ] No defaults to banks/FIs
- [ ] Audited accounts available
- [ ] Cash profit in recent financial years (last audited financial year for GST Sahay, last two years for 4E Financing Scheme)
- [ ] Valid CIBIL score (minimum 550 for Gig Flexi, satisfactory for other products)
- [ ] Sector-specific criteria (e.g., validated defence orders for Cash Defence, GST returns for GST Sahay, ITRs, bank statements)
- [ ] For project funding: Project Report required
- [ ] For machinery loan: Quotation for machinery required
- [ ] For invoice-based financing: Purchase/Sales Invoice required
- [ ] For green finance: Detailed Energy Audit and Detailed Project Report (DPR) vetted by EEC, SIDBI
- [ ] For venture debt: MSME <10 years with ₹10 Cr equity and backing from AIF/VC investor; ₹10 Cr operational income in last 2 years; DER up to 2:1
- [ ] For seed funding through incubators: Startup stage, IP-driven/product, unable to attract commercial VC investment
- [ ] For PRAYAAS IES: Micro-entrepreneur/micro-enterprise, focus on women entrepreneurs under SVEP or SHG graduates under Bank linkage program, operational in Bihar and Maharashtra (pilot)

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Udyam Registration Certificate
- PAN Card
- ITR (Income Tax Returns) for last 2-3 years
- GST Registration Certificate
- Bank Statements (last 6 months)
- GST Returns (last 6 months)
- Audited Financial Statements (Balance Sheet, P&L)
- CIBIL Score Report
- Authorization letter from signatory
- NACH mandate
- Digital document execution consent

### Scheme-Specific Documents
- Project Report (for project funding)
- Purchase/Sales Invoice (for invoice-based financing like GST Sahay, FPS Sahay, JAKs)
- Quotation for machinery (for machinery loan)
- Land and building documents (if applicable)
- Details of collateral (if required)
- Detailed Energy Audit (DEA) and Detailed Project Report (DPR) vetted by EEC, SIDBI (for 4E Financing Scheme)
- Validated defence orders (for Cash Defence)
- Jan Aushadhi Kendras registration with PMBI (for GST Sahay-JAKs)
- FPS dealer license from State government/Department of Food and Public Distribution (for FPS Sahay)
- Equity investment documents (for seed funding through incubators)
- Venture debt framework compliance documents (for venture debt financing)
- Referral partner agreement (if applying through referral partner)

### Document Quality Check
- All documents must be legible, scanned in PDF format
- File size per document should not exceed 5 MB unless specified otherwise
- Names on documents must match exactly with Udyam/GST registration
- Financial documents must be certified by a Chartered Accountant where applicable
- Documents must be in English or Hindi; if in regional language, certified translation required
- Bank statements must show account holder name matching business name
- ITR must be filed and acknowledged by Income Tax Department
- Udyam and GST certificates must be valid and not expired
- Project Report must include technical feasibility, financial projections, and implementation timeline
- Invoices must be GST-compliant and show clear transaction details

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required for:
- Project Funding (expansion/modernization/technology upgradation)
- 4E Financing Scheme (Energy Efficiency investments)
Standard sections include: Executive Summary, Project Description, Technical Feasibility, Market Analysis, Implementation Schedule, Financial Projections (including loan repayment capacity), Risk Assessment, and Environmental & Social Impact (for 4E Financing Scheme). For other products like machinery loan or invoice-based financing, a DPR is not explicitly required but verify with nodal officer if project scope warrants it.

### Application Form Filling Protocol
1. Access the SIDBI portal at https://sidbi.in/home-product and select the appropriate loan product (e.g., Project Loan, Machinery Loan, Working Capital, Green Finance, GST Sahay).
2. Complete registration and KYC process using Udyam and GST details.
3. Fill in all mandatory fields marked with *; leave no mandatory field blank.
4. Ensure loan amount requested does not exceed product limits (e.g., up to Rs. 50 crore for project funding, Rs. 3 crore for machinery loan, Rs. 50 lakh for GST Sahay).
5. Select the correct product variant (e.g., GST Sahay for general MSMEs, GST Sahay-JAKs for Jan Aushadhi Kendras).
6. Enter financial figures exactly as per audited statements and ITRs; avoid rounding or estimation.
7. Upload documents in the specified format (PDF, max 5 MB per file unless otherwise stated) with clear, descriptive filenames (e.g., "Udyam_Certificate.pdf", "GST_Return_Q1_2026.pdf").
8. Review the entered data against uploaded documents before final submission to ensure consistency.
9. Accept the terms and conditions and provide digital consent for document execution and NACH mandate.
10. Save a draft before final submission to allow for internal review.

### Internal Review Gate
- [ ] All mandatory fields in the application form are completed
- [ ] All scheme-specific and universal documents are attached and legible
- [ ] Document names match the checklist and are correctly labeled
- [ ] Financial figures in form match audited accounts and ITRs
- [ ] Loan amount requested is within product-specific limits
- [ ] Authorization letter and NACH mandate are signed and attached
- [ ] Declarations regarding no defaults to banks/FIs are signed
- [ ] Digital document execution consent is provided
- [ ] Application draft has been reviewed by a second consultant for accuracy
- [ ] Screenshot of the completed form (before submission) has been taken for records

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the SIDBI portal at https://sidbi.in/home-product
- Upon successful submission, take a screenshot of the confirmation page showing the Application Reference Number and timestamp
- Store the reference number in the case file and set up automated reminders for follow-up at 7, 15, and 30 days post-submission
- Save all submission-related documents (screenshot, reference number) in a dedicated folder labeled with the Case ID and scheme name

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify the approval letter from SIDBI, checking sanctioned amount, interest rate, tenure, and moratorium period
- [ ] Confirm that the sanctioned amount matches the requested amount or note any variations with justification
- [ ] Execute digital loan documents and NACH mandate as per the approval terms
- [ ] Ensure disbursement is received directly into the designated bank account
- [ ] Set up repayment schedule in accordance with the approved terms (e.g., monthly installments, bullet repayment)
- [ ] Maintain utilization records for the loan amount as per end-use verification requirements
- [ ] Prepare and submit Utilization Certificate (if required by the product) within the stipulated timeframe
- [ ] Track repayment dues and ensure timely payment to avoid penalties or default
- [ ] Upon successful repayment, obtain and store the loan closure certificate from SIDBI
- [ ] Calculate and invoice the success fee as per the consultancy agreement with the client
- [ ] Conduct a post-closure review with the client to document lessons learned and satisfaction levels
