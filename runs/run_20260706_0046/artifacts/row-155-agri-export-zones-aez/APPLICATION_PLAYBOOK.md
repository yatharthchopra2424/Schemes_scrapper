# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a farmer, farmer producer company, agro-processing unit, exporter, or other stakeholder engaged in production, processing, and export of agricultural products  
- [ ] Applicant is engaged in activities related to scheduled products under APEDA  
- [ ] Applicant demonstrates export potential or existing export activity  
- [ ] Applicant is willing to participate in cluster-based collaboration with multiple stakeholders in a geographic region to develop an export-oriented agri-value chain  
- [ ] Applicant has obtained Registration-cum-Membership Certificate (RCMC) from APEDA (typically required for availing benefits)  
- [ ] Applicant possesses Import Export Code (IEC) from DGFT  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- PAN card of the applicant entity  
- GST registration certificate  
- Audited or provisional financial statements (ITR for last 2–3 years)  
- Bank statements (last 6 months)  
- Udyam Registration (MSME certificate, if applicable)  
- Import Export Code (IEC) issued by DGFT  
- Registration-cum-Membership Certificate (RCMC) from APEDA  

### Scheme-Specific Documents
- Project Report / Detailed Project Report (DPR) outlining infrastructure, value addition, and export plan  
- Proof of land ownership or lease agreement for infrastructure development  
- Memorandum of Understanding (MoU) among consortium members (for cluster-based participation)  
- Bank appraisal of the project (financial viability assessment)  
- Environmental and statutory clearances (if applicable to the project)  
- Details of proposed machinery, technology, and processing capacity  
- Marketing and export strategy document  
- Bank account details of the applicant entity  

### Document Quality Check
- All documents must be legible, scanned in PDF format (max file size: 5 MB per document)  
- File names must follow the format: `SchemeName_DocumentType_ApplicantName_Date.pdf` (e.g., `AEZ_DPR_AgroExportsLtd_20240515.pdf`)  
- Certified true copies required for registration certificates, financial statements, and legal documents  
- Documents in regional languages must be accompanied by certified English/Hindi translations  
- Signatures and seals must be visible and authentic  
- Bank statements must show the entity’s name matching PAN and RCMC

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
**Required.** The DPR must include the following standard sections:  
- Executive Summary  
- Project Background and Objectives  
- Cluster Description (geographic scope, participating stakeholders)  
- Infrastructure Plan (packhouses, processing units, cold chains, testing facilities)  
- Technology and Machinery Details  
- Quality Upgradation and Certification Plan  
- Market Development and Export Strategy  
- Financial Projections (costs, funding, revenue, profitability)  
- Implementation Timeline (milestones)  
- Export Linkage and Value Addition Justification  
- Risk Assessment and Mitigation Plan  
- Utilization Plan for APEDA Subsidy  

### Application Form Filling Protocol
1. Access the APEDA portal at https://apeda.gov.in/apedawebsite/aez and navigate to the Financial Assistance Scheme (FAS) section for AEZ applications.  
2. Ensure all fields in the application form are completed; leave no mandatory field blank.  
3. Upload documents in PDF format only, with file names matching the checklist format.  
4. Double-check that the entity name, PAN, and RCMC number are identical across all documents and the form.  
5. Clearly state the agri-product, geographic cluster, and export potential in the project summary.  
6. Specify the subsidy amount sought and break it down by component (infrastructure, quality, market promotion).  
7. Declare that the project demonstrates clear export linkage and value addition (as per scheme caveats).  
8. Confirm understanding that subsidy is disbursed on reimbursement basis after verification of expenditure and utilization certificates.  

### Internal Review Gate

- [ ] DPR completed with all required sections

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the APEDA portal: https://apeda.gov.in/apedawebsite/aez  
- Take a screenshot of the confirmation page showing the application reference number and timestamp  
- Save the reference number in the case file and set automated reminders for follow-up at 15, 30, and 45 days  
- Store all submitted documents and screenshots in a secure, access-controlled folder

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the approval letter from APEDA specifying the sanctioned subsidy amount and components  
- [ ] Confirm the disbursement schedule (installments tied to project milestones)  
- [ ] Utilize funds strictly as per the approved DPR and submit utilization certificates at each milestone  
- [ ] Maintain detailed records of expenditure, invoices, and bank statements for audit purposes  
- [ ] Submit periodic progress reports as required by APEDA  
- [ ] Upon project completion, submit final utilization certificate and completion report to claim the final subsidy installment  
- [ ] Ensure compliance with export targets; failure may result in fund recovery as per scheme caveats  
- [ ] Invoice the client for the success fee as per the retainer agreement [TO BE FILLED BY CONSULTANT]
