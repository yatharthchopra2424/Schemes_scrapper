# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a State Government or Union Territory (UT)  
- [ ] Project proposal is for fisher welfare activities (housing, sanitation, drinking water, community assets, livelihood support, accident insurance, health coverage, fisher cooperatives, self-help groups, skill development, training, or fisheries-related equipment/infrastructure)  
- [ ] Proposal includes beneficiary list and selection criteria based on socio-economic conditions  
- [ ] Proposal includes bank account details of the implementing agency  
- [ ] State/UT has committed matching share as per scheme norms  
- [ ] Beneficiary selection follows transparency and socio-economic criteria  
- [ ] Project is technically and financially feasible (to be appraised by Department of Fisheries)  
- [ ] Application is submitted through the State Government/UT to the Department of Fisheries  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/Registration Certificate of State Government/UT  
- PAN Card of State Government/UT  
- GST Registration (if applicable)  
- Bank Statements of implementing agency (last 6 months)  
- Udyam Registration (if applicable for implementing agency)  
- Authorization Letter from State Government/UT for project submission  

### Scheme-Specific Documents
- Project proposal from State Government/UT for fisher welfare activities  
- Utilization certificates of previous funds (if any)  
- Progress reports on implementation (if ongoing project)  
- Beneficiary list and selection criteria (based on socio-economic identification by State/UT)  
- Bank account details of implementing agency  

### Document Quality Check
- All documents must be legible and in PDF format  
- File size must not exceed 10 MB per document  
- Document names must match the checklist (e.g., "Utilization_Certificate_FY2023-24.pdf")  
- All certificates must be signed and stamped by authorized signatory  
- Documents must be in English or Hindi; if in regional language, certified translation must be attached  
- Beneficiary list must include Aadhaar-linked IDs or other government-verified identifiers

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a **Detailed Project Report (DPR)** is required. As per evidence, the application must include:  
- Infrastructure details (e.g., housing units, sanitation facilities, drinking water systems)  
- Production capacity (if livelihood support includes equipment)  
- Technology support and employment generation plans  
- Economics of operation and sustainability  
- Employment generation details  
- Monitoring and evaluation framework  

### Application Form Filling Protocol
1. Use only the official portal: [https://dof.gov.in](https://dof.gov.in)  
2. Fill all fields in English or Hindi; regional language requires certified translation  
3. Attach all scheme-specific documents as per checklist  
4. Ensure beneficiary list includes Aadhaar or voter ID for verification  
5. Clearly state the central share requested and matching share commitment from State/UT  
6. Declare that beneficiary selection follows transparency and socio-economic criteria  
7. Confirm that funds will be released only upon submission of utilization certificates and progress reports  
8. Double-check bank account details for fund transfer accuracy  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] Project proposal complete with objectives, budget, timeline, and implementation plan  
- [ ] Utilization certificates and progress reports attached (if applicable)  
- [ ] Beneficiary list and selection criteria clearly defined  
- [ ] Bank account details of implementing agency validated  
- [ ] Declarations signed and stamped by authorized officer  
- [ ] All documents uploaded in correct format and size  
- [ ] Application reference number noted after submission  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit application via [https://dof.gov.in](https://dof.gov.in) under "Schemes and Services" → "National Scheme on Welfare of Fishermen"  
- Take screenshot of submission confirmation page  
- Save application reference number (ARN) in case file  
- Set calendar reminders for follow-up at 15, 30, and 45 days post-submission

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and archive approval letter from Department of Fisheries  
- [ ] Verify sanctioned amount matches approved central share  
- [ ] Prepare utilization certificate format for fund release  
- [ ] Track installment-based fund release is tied to submission of utilization certificates and progress reports  
- [ ] Ensure State/UT releases matching share as per scheme norms  
- [ ] Monitor implementation progress and prepare quarterly reports  
- [ ] Coordinate with beneficiary groups for distribution of welfare benefits (housing kits, sanitation units, equipment, etc.)  
- [ ] Submit utilization certificate and progress report to trigger next installment  
- [ ] Maintain records for audit and potential RTI queries  
- [ ] Calculate and invoice success fee as per consultancy agreement
