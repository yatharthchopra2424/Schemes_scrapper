# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] MSME unit in operation for at least three years  
- [ ] Mandatory Udyam registration  
- [ ] Mandatory GST registration  
- [ ] No defaults to Bank/FIs  
- [ ] Cash profit in last audited financial results  
- [ ] PAN card of the business entity  
- [ ] Valid bank account in the name of the business  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- PAN card of the business  
- GST registration certificate  
- Udyam registration certificate  
- ITRs of last 2–3 years  
- Bank statements of last 6 months  
- Audited financial statements (Balance Sheet, P&L)  
- CIBIL score/report  

### Scheme-Specific Documents
- GST returns (as specified in scheme)  
- ITRs (as specified in scheme)  
- Bank Statement (as specified in scheme)  
- CIBIL score (as specified in scheme)  

### Document Quality Check
- All documents must be legible scans or clear photographs  
- File names must match the document type (e.g., "GSTR_July_2024.pdf")  
- File size must not exceed 5 MB per document  
- All documents must be self-attested by the applicant  
- Documents must be in English or Hindi; if in another language, a certified translation must be attached  
- Bank statements must show the account holder's name matching the business name
