# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is an aquaculture farmer, exporter, fisheries cooperative, or MSME engaged in marine products sector  
- [ ] Applicant is registered with MPEDA or its affiliated societies (NaCSA/RGCA)  
- [ ] Applicant has identified a relevant scheme component (value addition, infrastructure, training, hatchery development, etc.)  
- [ ] For value addition/infrastructure: Applicant demonstrates export potential and compliance with quality standards (if exporter)  
- [ ] For training/capacity building: Applicant is a registered farmer or technician  
- [ ] Project proposal includes objectives, methodology, budget, and expected outcomes  
- [ ] Applicant has proof of land ownership or lease agreement for farm/infrastructure  
- [ ] Applicant has bank statement or financial solvency certificate  
- [ ] Applicant has quotations for machinery/equipment to be procured  
- [ ] Environmental and pollution clearance certificates obtained (if applicable)  
- [ ] Training completion certificates available (for capacity building components)  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Business registration certificate  
- PAN card  
- ITR (last 2–3 years)  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam registration (if MSME)  

### Scheme-Specific Documents
- Registration certificate with MPEDA or affiliated societies (NaCSA/RGCA)  
- Project report detailing objectives, methodology, and budget  
- Proof of land ownership or lease agreement for farm/infrastructure  
- Bank statement or financial solvency certificate  
- Quotations for machinery/equipment to be procured  
- Environmental and pollution clearance certificates (if applicable)  
- Training completion certificates (for capacity building components)  
- Utilization certificates and progress reports (for subsequent installments)  

### Document Quality Check
- All documents must be legible scans or certified copies  
- File names must match document type (e.g., "MPEDA_Registration_Certificate.pdf")  
- File size must not exceed 5 MB per document  
- All certificates must be valid and not expired  
- Documents must be in English or Hindi; if in regional language, provide certified translation  
- Photographs must be geotagged (for infrastructure projects)  
- Bank statements must show applicant’s name and account details  
- Quotations must be on supplier letterhead with validity period

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a detailed project report is required. It must include:  
- Executive summary  
- Objectives and expected outcomes  
- Methodology and implementation plan  
- Detailed budget breakdown  
- Timeline for completion  
- Expected benefits (employment, export potential, technology adoption)  
- Risk assessment and mitigation plan  
- Sustainability and environmental compliance measures  

### Application Form Filling Protocol
1. Access the portal at https://e-mpeda.nic.in/registration/Reg_login.aspx using MPEDA-registered credentials  
2. Select the relevant scheme component (value addition, infrastructure, training, etc.)  
3. Fill all mandatory fields; leave no section blank  
4. Upload documents in the specified order and format as per portal prompts  
5. Ensure file names match the document checklist exactly  
6. Enter financial figures accurately; verify totals match project report  
7. Confirm Aadhaar-linked bank account details for subsidy transfer  
8. Review the declaration section and tick all required boxes  
9. Take a screenshot of each completed page before proceeding  
10. Save the application draft periodically to avoid loss due to session timeout  
11. Do not submit until all documents are uploaded and verified  
12. Use the “Preview” function to check for errors before final submission  

### Internal Review Gate
- [ ] All applicant and business details are correctly entered  
- [ ] Scheme-specific documents are uploaded and legible  
- [ ] Universal documents are attached and valid  
- [ ] Project report is complete and aligns with budget  
- [ ] Quotations are recent and on letterhead  
- [ ] Bank details match submitted statements  
- [ ] Declarations are signed and dated  
- [ ] No blank mandatory fields remain  
- [ ] Application reference number is noted after submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Click “Final Submit” only after internal review gate is cleared  
- Capture screenshot of the confirmation page showing application number and timestamp  
- Save the application number in the case file and set calendar reminders for follow-up at 15, 30, and 45 days  
- Store all submission screenshots and correspondence in a dedicated folder labeled with Case ID

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify approval letter from MPEDA  
- [ ] Confirm sanctioned amount matches approved project budget  
- [ ] Initiate procurement/infrastructure development as per project plan  
- [ ] Maintain records of all expenditures, invoices, and payment proofs  
- [ ] Submit utilization certificates and progress reports for subsequent installments  
- [ ] Ensure compliance with quality standards and environmental norms during implementation  
- [ ] Coordinate with MPEDA field officers for physical verification if required  
- [ ] Prepare and submit final utilization certificate upon project completion  
- [ ] Follow up for subsidy release after verification of utilization certificates  
- [ ] Retain all approval and completion documents for audit purposes  
- [ ] Calculate and invoice success fee as per consultancy agreement
