## Pricing Principles
1. **Value-Based Alignment**: Fees are calibrated to the actual financial benefit delivered under MIDH, which provides substantial subsidies for horticulture development (e.g., micro-irrigation, post-harvest management, cold chain, FPO formation) with typical project values ranging from ₹10 lakhs to several crores depending on scale.
2. **Risk-Adjusted Pricing**: Success fees reflect the scheme’s moderate implementation risk — while MIDH has a structured approval workflow (village → block → district → state → ministry), processing times vary by state and intervention type, and fund release is contingent on utilization certificates and physical verification.
3. **Tiered Accessibility**: The retainer-success fee structure ensures accessibility for farmer groups and FPOs (primary beneficiaries under MIDH) while capturing higher value from mid-market and enterprise clients implementing large-scale horticulture projects.
4. **Scheme-Specific Note**: MIDH has a proven track record of fund disbursement (e.g., ₹283.62 Cr released in FY 2022-23 against ₹901.32 Cr allocated), indicating moderate execution risk. The 3–6 month approval lag (per workflow evidence) justifies a deferred success fee model, with revenue recognition tied to fund release rather than application submission.
