## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. As per the application process:  
> "Detailed project report (DPR) is prepared and submitted" after initial assessment by the assigned Lean consultant.  

**Standard DPR Sections**:  
- Executive Summary  
- Unit Profile (MSME details, Udyam, location, products)  
- Current State Analysis (existing machinery, production process, waste identification)  
- Lean Implementation Plan (tools to be deployed: 5S, Kaizen, VSM, etc.)  
- Timeline and Milestones (phase-wise implementation schedule)  
- Project Cost Breakdown (consultant fees, training, equipment, contingency)  
- Expected Benefits (productivity gain, cost reduction, quality improvement)  
- Sustainability Plan (post-implementation monitoring)  
- Annexures (quotations, Udyam, financials, authorization)  

> **Note**: The DPR is prepared by the assigned Lean consultant post-screening. Consultants should verify DPR format requirements with the nodal officer if not specified in portal guidelines.  

### Application Form Filling Protocol
1. Register on the official LEAN scheme portal at [https://lean.msme.gov.in](https://lean.msme.gov.in) using valid email and mobile number  
2. Select “New Application” and enter Udyam Registration Number to auto-fetch unit details  
3. Ensure all entered details (name, address, activity) match Udyam, PAN, and GST records exactly  
4. Fill in project cost estimate clearly, ensuring beneficiary share (20%) is visible in calculations  
5. Upload all documents in PDF format, under 5 MB each, with correct naming convention  
6. In the “Project Proposal” section, summarize Lean objectives, tools, and expected outcomes  
7. Declare that the unit is operational and committed to handholding period  
8. Review all entries before final submission; no edits allowed after submission  

### Internal Review Gate
- [ ] All mandatory fields in the application form are filled  
- [ ] Udyam number matches across form, certificate, and portal auto-fill  
- [ ] Project cost does not exceed INR 50 lakhs (to ensure 80% subsidy ≤ INR 40 lakhs)  
- [ ] Bank details match the account where subsidy will be disbursed  
- [ ] Authorization letter is signed and dated  
- [ ] Project proposal is clear, feasible, and aligned with Lean principles  
- [ ] All documents are attached, legible, and within size limits  
- [ ] Declarations regarding operational status and commitment are checked  
- [ ] Application is reviewed by a second consultant before submission
