- Project proposal document (as per NTTM component guidelines)  
- Technical details and innovation aspect of the project  
- Land/building documents (if infrastructure component is involved)  
- Partnership/MoU documents (if collaboration with industry, academia, or research institutions is involved)  
- Undertaking and declaration forms (as specified by NTTM)  

### Document Quality Check
- All documents must be legible, scanned in PDF format (max file size: 5 MB per file unless otherwise specified)  
- File names must match the document type (e.g., "PAN_Card.pdf", "Audited Financial_Statements_2023.pdf")  
- Certificates must be valid and not expired (especially GST, Udyam, Incorporation)  
- Financial statements must be audited and signed by a Chartered Accountant  
- Project proposal must include clear objectives, methodology, budget, timeline, and expected outcomes  
- All declarations must be signed and stamped by the authorized signatory  
- Documents must be in English or Hindi; if in another language, a certified translation must be attached

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
- **Required**: Yes, a detailed project proposal (functioning as a DPR) is mandatory for all NTTM components.  
- **Standard Sections to Include**:  
  1. Executive Summary  
  2. Project Objectives and Alignment with NTTM Goals  
  3. Technical Details and Innovation Aspect  
  4. Methodology and Work Plan  
  5. Budget Breakdown (with justification)  
  6. Timeline and Milestones  
  7. Expected Outcomes (R&D output, market impact, employment, exports, etc.)  
  8. Sustainability and Scalability Plan  
  9. Annexures: Technical drawings, test reports, collaboration letters, etc.  

> **Note**: Confirm exact DPR format with the nodal officer for the specific component (R&D, market development, etc.).  

### Application Form Filling Protocol
1. Access the application portal at https://technicaltext.in and register/create login credentials.  
2. Select the **specific NTTM component** (R&D, market development, export promotion, infrastructure, skill development) under which the project falls.  
3. Fill in all applicant details exactly as per Certificate of Incorporation and PAN.  
4. Enter project title, objectives, and timeline clearly and concisely.  
5. Upload all documents in PDF format, ensuring file names are descriptive and under 5 MB.  
6. Declare that the project aligns with national technical textiles priorities and complies with GFR and CVC guidelines.  
7. Provide bank details for fund transfer (account must be in the applicant’s name).  
8. Review all entries before final submission; once submitted, edits may not be allowed.  
9. Save the application reference number immediately after submission.  
10. Do not submit multiple applications for the same project under different components without justification.
