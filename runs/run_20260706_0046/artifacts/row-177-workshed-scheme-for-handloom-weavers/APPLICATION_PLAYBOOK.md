# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID is assigned, the target scheme is selected. The steps are followed.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Implementing Agency (or State Government Organizations, National/State Level Handloom Organizations, Apex/Primary Handloom Weavers’ Co-operative Societies, Self Help Groups, or Producers’ Companies.
- [ ] [ ] For NGO IA: Registration on NITI Aayog Darpan Portal is mandatory.
- [ ] [ ] For Individual Workshed: Beneficiary is BPL/SC/ST/Women/differently-abled (100% GoI share) or Others (75:25 GoI:Beneficiary).
- [ ] [ ] For Common Workshed: Funding ratio is 90% GoI:10% Beneficiary.
- [ ] [ ] For Solar Lighting System for Common Workshed: Funding ratio is 90% GoI:10% Beneficiary.
- [ ] [ ] Cluster has up to 500 handloom workers at one location.
- [ ] [ ] Proposal is submitted by State Directorate or directly by IA (if WSC, IIHT, or National Level Organization) under intimation to State Directorate.
- [ ] [ ] Land cost is excluded from GoI funding for individual and common worksheds.
- [ ] [ ] Inter-component diversion within approved cost requires SLPC approval and intimation to O/o DC (HL).
- [ ] [ ] State Directorate must submit proposal copy to WSCs at least two weeks before SLPC meeting.

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation Certificate
- PAN Card
- ITR (last two years)
- GST Registration
- Bank Statements (last six months)
- Udyam Registration (if applicable)

### Scheme-Specific Documents
- Minutes of SLPC duly signed by Chairman and Members
- Baseline Survey of SCDP in prescribed proforma (Annexure A1)
- Diagnostic study, Intervention-wise Action Plan/total financial outlay (Annexure A2)
- Profile of IA indicating name, address, contact, PAN/TAN, Bank accounts (Annexure A3)
- Profit & Loss Account and Balance Sheet of IA for last two years
- For NGO: Score pattern for grading (Annexure A4) and certificate of registration on NITI Aayog Darpan Portal
- List of weavers for availing benefit of individual interventions (Annexure A7(I))
- For Common workshed: details of land with area, location, title in IA's name
- For Solar Lighting System: cost break-up, lighting capacity, warranty, installation place, workshed size, number of looms

### Document Quality Check
- [ ] File size under 10 MB per document
- [ ] File names match document descriptions exactly (e.g., "Annexure_A1_Baseline_Survey.pdf")
- [ ] All certificates are legible and valid (not expired)
- [ ] Documents are in English or Hindi; if regional language, certified translation attached
- [ ] Scanned copies are clear, no blurriness or cut-off text
- [ ] Bank statements show IA's name and account number
- [ ] PAN/TAN matches IA's name in registration documents
- [ ] Land documents show clear title in IA's name (for common workshed/solar lighting)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A Detailed Project Report (DPR) is not explicitly required as a standalone document; however, the Diagnostic Study and Intervention-wise Action Plan (Annexure A2) serves as the core technical proposal. If in doubt, verify with the nodal officer at O/o DC (HL).

### Application Form Filling Protocol
1. Ensure all fields in the application form are completed; leave no blank sections.
2. Attach all scheme-specific documents as per Annexures A1–A4 and A7(I).
3. For NGO IAs, upload the NITI Aayog Darpan registration certificate and Score pattern (Annexure A4).
4. Clearly specify the type of workshed (Individual/Common/Solar Lighting) and corresponding beneficiary category.
5. In the financial section, detail the GoI share and beneficiary share as per the funding pattern (100%, 75:25, or 90:10).
6. Exclude land cost from the project cost in the financials (as per scheme guidelines).
7. Provide bank account details matching the IA’s name for fund release via PFMS.
8. Sign and stamp the application form; ensure the Head of IA and State Director of Handlooms countersign where required.
9. Submit via the State Directorate or directly to O/o DC (HL) (if IA is WSC, IIHT, or National Level Organization) with intimation to State Directorate.
10. Retain a copy of the submitted application and all supporting documents for internal review.

### Internal Review Gate
- [ ] All application form fields completed
- [ ] All scheme-specific documents attached and clearly labeled
- [ ] Universal documents (PAN, ITR, GST, bank statements, Udyam) verified
- [ ] Financials exclude land cost and reflect correct GoI:Beneficiary ratio
- [ ] Bank account details match IA’s registration documents
- [ ] Declarations signed and stamped by authorized signatory
- [ ] For NGO: NITI Aayog Darpan certificate and Score pattern (Annexure A4) attached
- [ ] Minutes of SLPC signed by Chairman and Members
- [ ] Baseline Survey (Annexure A1) and Diagnostic Study (Annexure A2) completed and signed
- [ ] List of weavers (Annexure A7(I)) signed by local committee (WSC & State Govt.)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify approval letter from O/o DC (HL) specifying sanctioned amount and installment details
- [ ] Confirm that the sanctioned amount aligns with the applied GoI share (50% advance, balance on 70% UC of first installment)
- [ ] Receive first installment (50% of GoI share) in IA’s bank account
- [ ] Utilize funds as per approved action plan and submit Utilization Certificate (UC) for at least 70% of first installment
- [ ] Submit intervention-wise physical & financial progress report, expenditure statement (CA-signed), and monitoring report from Local Committee
- [ ] Ensure second installment is released upon receipt of UC for ≥70% of first installment
- [ ] Maintain all records for audit and future reference
- [ ] Coordinate with IA for successful project implementation and beneficiary outreach
- [ ] Prepare and submit final project completion report with photographs and beneficiary testimonials
- [ ] Follow up on utilization certificate submission and final settlement
