# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Enterprise type: Proprietorship, partnership, company, LLP, cooperative society, society, trust, HUF, or other (as per Udyam Registration portal)
- [ ] Investment in plant and machinery or equipment: 
  - Micro: ≤ ₹1 crore
  - Small: ≤ ₹10 crore  
  - Medium: ≤ ₹50 crore
- [ ] Turnover (excluding exports):
  - Micro: ≤ ₹5 crore
  - Small: ≤ ₹50 crore
  - Medium: ≤ ₹250 crore
- [ ] Sector: Manufacturing or services (both treated equally; no distinction)
- [ ] Age of business: No minimum age requirement; new enterprises can self-declare investment
- [ ] Geographic location: Pan-India (no state-specific restrictions)
- [ ] Social category and gender of entrepreneur: Required for registration (no restrictions)
- [ ] NIC code for economic activity: Must be provided during registration
- [ ] Aadhaar number: Required for all enterprise types (proprietor's Aadhaar for proprietorships, managing partner for partnership, karta for HUF, authorised signatory for companies/LLP/society/trust)
- [ ] PAN: Mandatory for all enterprise types except proprietorships not registered under any Act (where proprietor's PAN may be used)
- [ ] Bank account details: Required for registration
- [ ] GSTIN: Not mandatory for registration; exemption from GSTIN requirement is as per CGST Act, 2017 provisions
- [ ] No multiple Udyam Registrations: Enterprise cannot file more than one registration, but multiple activities (manufacturing, services, trading) can be added under one registration
- [ ] Classification based on frozen data: Investment and turnover data fetched from Income Tax and GSTN (previous financial year); self-declaration allowed for new enterprises without prior ITR (valid until first ITR filing)
- [ ] Benefits access: Udyam Registration is mandatory to avail benefits under most MSME Ministry schemes and Priority Sector Lending (PSL) as per RBI notification

**Sources**:  
- Key Facts: Eligibility, Required Documents, Application Process  
- Supporting Evidence: Gazette Notification S.O. 2119(E) dated 26 June 2020 (PDF: 220191.pdf), Amendment Notification S.O. 1055(E) dated 5 March 2021 (PDF: 225669.pdf), RBI Circulars (acceptance-urc-doucment-digilocker.pdf), Udyam Registration Portal (https://udyamregistration.gov.in)

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- [ ] PAN card (enterprise or proprietor's for unregistered proprietorships)
- [ ] Aadhaar number (of proprietor, managing partner, karta, or authorised signatory)
- [ ] Bank account details (account number, IFSC, bank name)
- [ ] Udyam Registration (if already registered; otherwise, this is the output)
- [ ] GSTIN certificate (if applicable; not mandatory for registration but required for PSL and scheme benefits)
- [ ] ITR/VITR (for investment and turnover auto-fetch; self-declaration accepted for new enterprises without prior ITR)
- [ ] Business address proof (electricity bill, rent agreement, or property tax receipt)

### Scheme-Specific Documents
- [ ] Details of investment in plant and machinery or equipment (auto-fetched from ITR/GSTN or self-declared for new enterprises)
- [ ] Turnover details (auto-fetched from ITR/GSTN or self-declared; exports excluded)
- [ ] Social category and gender of entrepreneur (self-declared)
- [ ] NIC code for economic activity (self-declared)
- [ ] Enterprise type (proprietorship, partnership, etc.)
- [ ] Geographic location and contact details (address, phone, email)

### Document Quality Check
- [ ] File size: PDF/JPEG/PNG under 5 MB each
- [ ] File naming: Use format `SchemeName_ClientName_DocumentType_Date.pdf` (e.g., `Udyam_Registration_Aadhaar_20240515.pdf`)
- [ ] All details must match exactly with Aadhaar and PAN (name, date of birth, address)
- [ ] Documents must be legible, scanned, and in colour where applicable
- [ ] Self-declarations must be on enterprise letterhead (if available) or plain paper with signature and date
- [ ] Language: English or Hindi; regional languages accepted if accompanied by certified translation
- [ ] No expired documents (validity checked for PAN, Aadhaar, bank statements)
- [ ] Bank statement: Last 6 months, showing enterprise name and transactions

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
- **Not required**. Udyam Registration is a self-declaration-based process with no project report or DPR needed. The system auto-fetches investment and turnover data from Income Tax and GST Networks.  
- **Note**: Verify with nodal officer only if client seeks linked scheme benefits (e.g., CGTMSE, interest subvention), but **not for Udyam Registration itself**.

### Application Form Filling Protocol
1. **Access only the official portal**: Use https://udyamregistration.gov.in (no other website/app is official).  
2. **Aadhaar validation**: Enter Aadhaar number and validate via OTP sent to linked mobile.  
3. **PAN entry**: Mandatory for all enterprises except proprietorships not registered under any Act (use proprietor’s PAN in such cases).  
4. **Enterprise details**: Fill legal name, type of organization, address, bank details, and NIC code for activity (use NIC 2008 codes; multiple activities allowed).  
5. **Investment and turnover**: System auto-fetches data from IT and GSTN for prior years; for new enterprises without ITR, self-declare based on promoter’s declaration (valid until first ITR filing).  
6. **Social category and gender**: Self-declare as required.  
7. **Declaration**: Confirm no more than one Udyam Registration exists; multiple activities can be added under one registration.  
8. **Submit and download**: After submission, download the Udyam Registration Certificate with dynamic QR code; no further action needed.  

**Sources**:  
- Key Facts: Application Process  
- Supporting Evidence: Udyam Registration Portal (https://udyamregistration.gov.in), Gazette Notification S.O. 2119(E) (PDF: 220191.pdf)

### Internal Review Gate
- [ ] All form fields completed accurately (name, Aadhaar, PAN, bank, address, NIC code)  
- [ ] Investment and turnover values match declared or auto-fetched data (check for export exclusion in turnover)  
- [ ] Documents attached: Aadhaar, PAN, bank details (if required for verification)  
- [ ] Declarations signed: Self-declaration of investment/turnover (if new enterprise), social category, gender, enterprise type  
- [ ] No duplicate Udyam Registration checked (via portal or helpline)  
- [ ] Certificate downloaded and verified for dynamic QR code and enterprise details  
- [ ] Reference number saved and shared with client

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- [ ] Submit form via https://udyamregistration.gov.in after final review  
- [ ] Capture screenshot of submission confirmation page showing Udyam Registration Number  
- [ ] Save reference number (Udyam Registration Number) in case file and client communication  
- [ ] Set follow-up reminder for 3 days post-submission to verify certificate download  
- [ ] Download and share Udyam Registration Certificate with client (PDF format)  
- [ ] Advise client to update registration if investment/turnover crosses category thresholds (portal allows online update)

- [ ] Verify sanctioned amount: Not applicable (registration is free; no financial sanction)  
- [ ] Utilization certificate: Not applicable (no fund disbursement)  
- [ ] Invoice success fee: [TO BE FILLED BY CONSULTANT] (if applicable per firm policy)  
- [ ] Advise client:  
  - Certificate has lifetime validity; no renewal needed  
  - Mandatory for accessing PSL, CGTMSE, interest subvention, GeM procurement, and other MSME schemes  
  - Update registration online if investment/turnover exceeds current category thresholds  
  - Use dynamic QR code on certificate for instant verification by banks and government departments  
- [ ] Link to related schemes: Guide client to apply for CGTMSE, PMEGP, or other MSME Ministry schemes using Udyam Registration Number
