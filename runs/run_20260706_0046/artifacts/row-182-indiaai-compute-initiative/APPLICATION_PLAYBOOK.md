# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] **Target Beneficiary Type**: Applicant must be one of the following: startups, researchers, enterprises, or academic institutions (as per scheme's target beneficiaries).
- [ ] **Registration Type**: Must be a legally registered entity in India (e.g., Private Limited Company, LLP, Society, Trust, Section 8 Company, or recognized academic/research institution).
- [ ] **Sector Alignment**: Applicant must be engaged in AI-related activities, including but not limited to AI model development, AI applications, AI research, or AI infrastructure utilization.
- [ ] **Geographic Scope**: Applicant must be based in India (Pan-India scheme).
- [ ] **Institutional Status**: Only institutional entities are eligible; individual submissions are not permitted (based on AIKosh EOI guidelines, which reflect the initiative's operational framework).
- [ ] **Data Compliance**: If contributing datasets or AI artefacts, must comply with DPDPA, NDSAP, and AIKosh Terms of Use and Privacy Policy.
- [ ] **India-Specific Focus**: Contributions (if applicable) must be wholly or partially relevant to India, containing India-specific content or artifacts.
- [ ] **Authorized Representative**: Applicant must designate at least one authorized representative (Administrative SPOC) for managing submissions and coordination.

> **Note**: While explicit eligibility criteria for the IndiaAI Compute Initiative are not detailed in the evidence, the above checklist is derived from the scheme's target beneficiaries, implementing agency guidelines (IndiaAI Mission), and related initiatives like AIKosh Platform, which share the same ecosystem and compliance framework. Verify any updates with the nodal officer.

**Sources**:  
- Scheme Key Facts: Target Beneficiaries (startups; researchers; enterprises; academic institutions)  
- Supporting Evidence: AIKosh EOI document (eligibility, submission guidelines)  
- Portal: https://indiaai.gov.in (IndiaAI Mission pillars, including IndiaAI Compute Capacity)

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration
- PAN Card of the entity
- GST Registration Certificate (if applicable)
- Audited Financial Statements (last 2 years)
- Income Tax Returns (ITR) of the entity (last 2 years)
- Bank Statements (last 6 months)
- Udyam Registration Certificate (for MSMEs)
- Authorization Letter for the designated SPOC (Single Point of Contact)
- Cancelled Cheque / Bank Passbook (for verification)

### Scheme-Specific Documents
- **Project Proposal / Concept Note**: Detailing the AI initiative, objectives, expected outcomes, and alignment with IndiaAI Mission pillars (especially IndiaAI Compute Capacity).
- **Technical Architecture Diagram**: If applying for compute access, showing planned usage of AI infrastructure (GPUs, AI services).
- **Use Case Description**: Specific AI application or research project to be undertaken using the initiative’s resources.
- **Data Compliance Declaration**: Confirmation that any data used or contributed adheres to DPDPA, NDSAP, and AIKosh guidelines.
- **Institutional Endorsement Letter**: From Head of Department / Registrar (for academic institutions) or Board Resolution (for startups/enterprises) authorizing the application.
- **AI Artefact Details (if applicable)**: For model/use case submissions—model documentation, version control details, licensing terms, and use case narrative (as per AIKosh EOI Addendum).
- **Dataset Metadata Sheet (if contributing data)**: Complete metadata as per AIKosh guidelines (organizational details, licensing, India-specific relevance).

### Document Quality Check
- [ ] All documents are legible, scanned in PDF format (max file size: 5 MB per document unless otherwise specified).
- [ ] File names follow format: `CaseID_DocumentType_Version.pdf` (e.g., `CASE001_IncorporationCertificate_v1.pdf`).
- [ ] Names on documents exactly match the registered entity name and authorized representative’s name.
- [ ] All certificates are valid and not expired (check validity dates).
- [ ] Declarations and undertakings are signed and stamped by the authorized signatory.
- [ ] Documents are in English or accompanied by a certified English translation.
- [ ] For AI artefacts/models: Ensure originality, non-infringement, and proper documentation (as per AIKosh EOI Addendum).
- [ ] Metadata sheets include all required fields: organizational details, data format, source type, licensing terms, and India-specific relevance.

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A Detailed Project Report (DPR) is **not explicitly mandated** for the IndiaAI Compute Initiative based on the evidence. However, a structured **Project Proposal / Concept Note** is essential.  
If the nodal officer requests a DPR, include the following standard sections:  
- Executive Summary  
- Problem Statement and Objectives  
- Methodology and Technical Approach  
- Resource Requirements (Compute, Data, Personnel)  
- Work Plan and Timeline  
- Expected Outcomes and Impact  
- Budget Utilization Plan (if financial support is involved)  
- Risk Assessment and Mitigation  
- Sustainability and Scalability Plan  
- Annexures (Team CVs, Letters of Support, etc.)  

> **Verify with nodal officer** whether a DPR or concept note is preferred for this scheme.

### Application Form Filling Protocol
1. **Access the Portal**: Apply exclusively through the official IndiaAI Portal: https://indiaai.gov.in  
2. **Authenticate**: Use the registered email and mobile number to log in or create an account on the portal.  
3. **Select Scheme**: Navigate to “Initiatives” or “Apply” section and choose **IndiaAI Compute Initiative** (or IndiaAI Compute Capacity pillar).  
4. **Fill All Fields**: Do not leave any mandatory field blank; if not applicable, write “Not Applicable” with justification.  
5. **Attach Documents**: Upload all documents as per the checklist; ensure PDF/A format where possible.  
6. **Declare Compliance**: Explicitly affirm adherence to DPDPA, NDSAP, and AIKosh Terms of Use in the declaration section.  
7. **Review Before Submit**: Preview the entire form to avoid errors; once submitted, edits may not be allowed.  
8. **Save Draft**: Periodically save progress to prevent data loss due to session timeout.  
9. **Note Reference**: Upon submission, immediately save the application reference number and take a screenshot of the confirmation page.  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] Application form 100% complete with no blank mandatory fields  
- [ ] All universal and scheme-specific documents attached and quality-checked  
- [ ] Declarations signed and dated by authorized representative  
- [ ] Project proposal clearly aligns with IndiaAI Mission objectives (democratizing compute access, indigenous AI development, industry collaboration)  
- [ ] Technical feasibility of proposed AI use case validated  
- [ ] Data/artefact contributions (if any) comply with IP and privacy norms  
- [ ] Application reference number saved and submission screenshot stored  
- [ ] Follow-up reminders set for Day 18, 25, and 30

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the IndiaAI Portal (https://indiaai.gov.in) before end of Day 18.  
- Immediately after submission:  
  - Take a **screenshot** of the confirmation page showing application reference number, date, and time.  
  - Save the reference number in a secure, access-controlled log (e.g., Case File > Submission Records).  
  - Send an auto-confirmation email to the client with the reference number and next steps.  
- Set calendar reminders for follow-up on Day 25 and Day 30 if no update is received.

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and securely store the **approval letter** from IndiaAI Mission (via email or portal download).  
- [ ] Verify the **sanctioned resources** (e.g., GPU hours, access duration, AI services allocated) against the request.  
- [ ] Onboard the client to the IndiaAI Compute platform using credentials provided.  
- [ ] Monitor utilization and ensure compliance with usage policies (e.g., no illegal, unethical, or non-Indian data processing).  
- [ ] Assist in preparing **Utilization Certificate (UC)** if required, detailing how resources were used for the approved AI initiative.  
- [ ] Track milestones and outcomes for impact reporting (e.g., models developed, datasets contributed, research papers published).  
- [ ] Coordinate with the client for **success fee invoicing** as per the engagement agreement.  
- [ ] Advise on renewal or extension of resource access, if applicable, before expiry.  
- [ ] Document lessons learned and update internal knowledge base for future applications.  

> **Note**: Post-approval monitoring duration may vary based on the sanction period. Maintain contact until project closure or resource utilization is complete.
