# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity is registered in India (Certificate of Incorporation or Registration)
- [ ] Entity is an Indian startup, MSME, academic institution, or research organization
- [ ] Entity works in the cybersecurity domain
- [ ] Entity demonstrates capability or potential in cybersecurity innovation, research, or solution development
- [ ] Entity has PAN and GST details
- [ ] Entity has a bank account for financial transactions
- [ ] Entity can provide an authorized signatory letter
- [ ] Entity can disclose details of existing funding or partnerships (if any)
- [ ] Entity can prepare a project proposal detailing objectives, methodology, and expected outcomes
- [ ] Entity can provide technical specifications or proof of concept (if applicable)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation or Registration
- PAN Card
- GST Registration Certificate
- Bank Statements (last 6 months)
- Udyam Registration (for MSMEs)
- Income Tax Returns (last 2 years)
- Audited Financial Statements (if applicable)
- Authorized Signatory Letter on company letterhead

### Scheme-Specific Documents
- Project proposal detailing objectives, methodology, and expected outcomes
- Technical specifications or proof of concept (if applicable)
- Details of existing funding or partnerships (if any)

### Document Quality Check
- All documents must be legible scans or clear photographs
- File names must match the document type (e.g., "PAN_Card.pdf", "GST_Certificate.pdf")
- File size must not exceed 5 MB per document
- All certificates must be valid and not expired
- Documents in regional languages must be accompanied by certified English translations
- Authorized signatory letter must be on official letterhead, signed, and stamped
- Project proposal must include clear objectives, methodology, timeline, and expected outcomes
- Bank details must include account number, IFSC code, and bank name matching the entity name

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A Detailed Project Report (DPR) is not explicitly mandated, but a **project proposal detailing objectives, methodology, and expected outcomes** is required. If the specific call for proposals under CCoE requires a DPR, verify with the nodal officer. Standard sections to include if DPR is needed:  
- Executive Summary  
- Project Objectives  
- Methodology and Work Plan  
- Technical Approach  
- Budget and Financial Plan  
- Implementation Timeline  
- Expected Outcomes and Impact  
- Risk Assessment and Mitigation  
- Sustainability Plan  

### Application Form Filling Protocol
1. Access the official CCoE portal at **https://www.meity.gov.in/ccoe** for announcements and application links.  
2. Read the specific call for proposals carefully to confirm eligibility, deadlines, and document requirements.  
3. Fill all mandatory fields in the application form; leave no section blank unless marked optional.  
4. Ensure the project proposal aligns with CCoE objectives: indigenous cybersecurity tech, capacity building, government-industry-academia collaboration, innovation, critical infrastructure protection, R&D in emerging threats, startup ecosystem, and standards development.  
5. Upload documents in the specified format (PDF/JPEG, <5 MB each) with clear, descriptive file names.  
6. Double-check that the authorized signatory letter is uploaded and matches the applicant entity name.  
7. Validate that bank details are correct and match the registered entity name for fund disbursement.  
8. Save a draft before final submission and review all entries for accuracy.  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] All universal and scheme-specific documents collected and quality-checked  
- [ ] Project proposal is complete, clear, and aligned with CCoE objectives  
- [ ] Application form is fully filled with no missing mandatory fields  
- [ ] All uploaded documents are legible, correctly named, and within size limits  
- [ ] Authorized signatory letter is signed, stamped, and on letterhead  
- [ ] Bank details are accurate and match the entity name  
- [ ] Declarations and undertakings are signed where required  
- [ ] Application reference number is noted post-submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the designated online portal or email as specified in the CCoE announcement.  
- Take a screenshot of the submission confirmation page showing the timestamp and reference number.  
- Store the application reference number securely in the case file.  
- Set a follow-up reminder for 15 days post-submission to check status.  
- Save all submission emails and portal confirmations in a dedicated folder.

### Escalation Path
- Level 1: Portal helpdesk – Contact via the MeitY CCoE portal (https://www.meity.gov.in/ccoe) or general MeitY helpdesk  
- Level 2: Nodal officer – Email: **ceo-dibd@digitalindia.gov.in** (as per scheme contact details in evidence)  
- Level 3: RTI filing if no response within statutory SLA – Address RTI application to Central Public Information Officer, Ministry of Electronics and Information Technology, New Delhi – 110001

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and securely store the approval letter from MeitY/CCoE  
- [ ] Verify the sanctioned amount, disbursement schedule, and milestones in the approval communication  
- [ ] Prepare utilization certificates as per the format and timeline specified in the approval  
- [ ] Ensure timely submission of progress reports and monitoring documents  
- [ ] Coordinate with CCoE for access to infrastructure, mentorship, testing facilities, and collaboration opportunities  
- [ ] Utilize funds strictly for approved objectives: prototype development, proof-of-concept, scaling, or other specified activities  
- [ ] Maintain records of all expenditures, invoices, and bills for audit purposes  
- [ ] Submit final project report and utilization certificate upon completion  
- [ ] Follow up on invoice for success fee (if applicable per consultancy agreement)  
- [ ] Explore opportunities for technology transfer, government/defense sector collaboration, and participation in cybersecurity drills as outlined in scheme benefits  
- [ ] Ensure compliance with IPR agreements, reporting requirements, and milestone adherence to avoid support discontinuation
