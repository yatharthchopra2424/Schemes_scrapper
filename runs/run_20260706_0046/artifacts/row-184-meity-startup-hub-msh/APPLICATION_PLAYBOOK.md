## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Startup is incorporated in India (Certificate of Incorporation available)  
- [ ] Startup operates in technology-focused sectors: electronics, IT, AI, IoT, blockchain, or other emerging technologies  
- [ ] Startup demonstrates innovation and scalability in its business model or technology solution  
- [ ] Startup is in early stage (no explicit age limit, but focus on early-stage per scheme objectives)  
- [ ] Startup has not been previously incubated under MeitY Startup Hub (implied by onboarding process)  
- [ ] Startup is willing to undergo periodic performance review as part of incubation support  

> **Note**: No turnover, employee count, or specific age thresholds are specified in the evidence. Eligibility is based on technology focus, innovation, and incorporation status.

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A formal Detailed Project Report (DPR) is **not explicitly required**, but a **business plan or project proposal** is mandatory. This should include:  
- Executive summary  
- Problem statement and innovative solution  
- Technology focus (electronics, IT, AI, IoT, blockchain, etc.)  
- Business model and scalability plan  
- Market analysis and go-to-market strategy  
- Funding requirements and utilization plan  
- Team details and qualifications  
- Timeline for prototype development or product launch  

> **Note**: Verify with the nodal officer if additional technical details are expected for deep-tech sectors.

### Application Form Filling Protocol
1. Access the official portal: [https://msh.meity.gov.in](https://msh.meity.gov.in)  
2. Register as a new user using the authorized signatory’s email and mobile number  
3. Fill in startup details exactly as per Certificate of Incorporation (name, CIN, date of incorporation, address)  
4. Select primary technology domain from dropdown: Electronics, IT, AI, IoT, Blockchain, or Other Emerging Technologies  
5. Upload all documents in PDF format, ensuring file names are clear (e.g., “Incorporation_Certificate.pdf”)  
6. In the business plan section, summarize innovation, scalability, and technology focus in ≤500 words  
7. Disclose all existing funding sources truthfully; omission may lead to disqualification  
8. Review all entries before final submit — no edits allowed after submission  
9. Take a screenshot of the confirmation page with application reference number  
10. Save the reference number for all future correspondence  

### Internal Review Gate
- [ ] All mandatory fields in the application form are completed  
- [ ] Certificate of Incorporation, PAN, and Authorization Letter show matching entity name and details  
- [ ] Business plan clearly articulates technology focus and innovation  
- [ ] Documents are uploaded in correct sections and are legible  
- [ ] Authorization letter is signed and dated  
- [ ] No blank fields in critical sections (technology focus, existing funding, contact details)  
- [ ] Application reference number has been generated and recorded
