# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] The applicant is a State Government or Implementing Agency (e.g., Bharat Broadband Network Limited - BBNL) proposing a project for BharatNet.
- [ ] The project targets Gram Panchayats as the primary unit for connectivity.
- [ ] The proposal includes technical feasibility, financial plan, right-of-way clearance, and monitoring plan.
- [ ] The project aligns with the objective of providing broadband connectivity to all Gram Panchayats in the country.
- [ ] The applicant has secured or can secure right-of-way and infrastructure sharing facilitation from State/Local authorities.
- [ ] The project is submitted for technical and financial appraisal by BBNL and Department of Telecommunications (DoT).
- [ ] Funding is subject to annual budgetary allocations and utilization certificates.
- [ ] The applicant commits to operational sustainability through maintenance and revenue models.

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/Registration Certificate
- PAN Card
- Audited Financial Statements / ITR (last 3 years)
- GST Registration Certificate
- Bank Statements (last 6 months)
- Udyam Registration (if applicable)
- Authorization Letter from Board/Competent Authority

### Scheme-Specific Documents
- Project proposal from state government
- Technical feasibility report
- Financial plan and cost estimates
- Right-of-way clearance documents
- Implementation agency details
- Monitoring and maintenance plan

### Document Quality Check
- All documents must be legible, scanned in PDF format, and clearly named (e.g., "State_Proposal_BharatNet.pdf").
- File size should not exceed 10 MB per document; compress if necessary.
- All certificates and reports must be issued by competent authorities and bear official seals/signatures.
- Documents in regional languages must be accompanied by certified English/Hindi translations.
- Declarations and undertakings must be signed and stamped by authorized signatories.

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. Based on the evidence, the DPR must include:  
- Executive Summary  
- Project Objectives (aligned with BharatNet goals: broadband to all Gram Panchayats, e-governance, digital inclusion)  
- Technical Design (network architecture, optical fibre layout, equipment specifications)  
- Financial Plan (cost estimates, funding sources: government budget, USOF, state contributions)  
- Implementation Timeline (milestone-based disbursement)  
- Right-of-Way and Infrastructure Sharing Strategy  
- Monitoring and Maintenance Plan (for operational sustainability)  
- Risk Mitigation (addressing delays in right-of-way, coordination challenges)  
- Socio-Economic Impact Assessment (telemedicine, education, e-agriculture, digital banking)  

### Application Form Filling Protocol
1. Use the official application format as specified by the Department of Telecommunications (DoT) for infrastructure proposals.  
2. Fill all fields in block letters; avoid abbreviations unless standard (e.g., BBNL, USOF).  
3. Attach all scheme-specific documents as annexures and reference them in the form.  
4. Clearly state the project scope: number of Gram Panchayats to be covered, districts, and states involved.  
5. Specify the funding pattern and expected disbursement schedule linked to milestones.  
6. Declare that the project does not duplicate existing infrastructure and adheres to cost-sharing norms.  
7. Confirm compliance with environmental and safety norms where civil works are involved.  
8. Ensure the authorized signatory signs and stamps the form; attach board resolution if applicable.  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] All universal and scheme-specific documents collected and quality-checked  
- [ ] DPR/project report completed and internally reviewed  
- [ ] Application form filled completely with no blank mandatory fields  
- [ ] All documents attached and properly referenced  
- [ ] Declarations signed and stamped by authorized signatory  
- [ ] Copy of submission saved for internal records

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the completed application via the DoT portal or designated nodal office (as per evidence: proposals submitted to Department of Telecommunications).  
- Take a screenshot of the submission confirmation or receipt.  
- Store the application reference number securely.  
- Set calendar reminders for follow-up at 15, 30, and 45 days post-submission.

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the official approval letter from DoT/BBNL specifying sanctioned amount and project scope  
- [ ] Confirm the financial assistance pattern (subsidy for laying optical fibre, network infrastructure, operational sustainability)  
- [ ] Schedule utilization certificate submissions as per milestone achievement  
- [ ] Ensure compliance with monitoring and maintenance plan for service continuity  
- [ ] Track fund disbursement against milestones (civil works, fibre laying, equipment installation, testing, commissioning)  
- [ ] Prepare and submit utilization certificates and progress reports to funding agency  
- [ ] Coordinate with BBNL/DoT for handover and monitoring of network infrastructure  
- [ ] Invoice success fee as per consultancy agreement upon milestone achievement or final approval
