# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity type: Any entity, including startups, MSMEs, entrepreneurs, or small businesses
- [ ] Registration: Must register on the designated PM-WANI portal
- [ ] Technical compliance: Must comply with technical and operational guidelines issued by the Department of Telecommunications
- [ ] Security standards: Must adhere to security and service quality standards
- [ ] No turnover, employee count, sector, or age of business restrictions specified

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Proof of identity (Aadhaar, PAN, etc.)
- Proof of address
- Business registration certificate
- Bank account details
- PAN card
- ITR (Income Tax Return)
- GST registration certificate
- Udyam registration (for MSMEs)

### Scheme-Specific Documents
- Technical details of Wi-Fi equipment to be deployed

### Document Quality Check
- File size: Ensure documents are within portal-specified limits
- Name matching: Names on documents must match exactly
- Certification: Documents must be self-attested or gazetted officer-attested where required
- Language: Documents must be in English or Hindi; if in another language, provide certified translation
- Clarity: Scanned copies must be legible with no blurring or cut-off information

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The PM-WANI scheme does not mandate a Detailed Project Report (DPR). However, applicants must provide technical details of Wi-Fi equipment as part of the application. Verify with the nodal officer if any additional project details are needed for specific use cases.

### Application Form Filling Protocol
1. Access the portal at https://dot.gov.in/pm-wani
2. Select “Register as Public Data Office (PDO)” or “Register as PDO Aggregator”
3. Enter accurate entity details (name, registration number, address)
4. Upload all required documents in prescribed format (PDF/JPEG, under 2 MB each)
5. Specify technical details of Wi-Fi equipment (make, model, frequency, power output, coverage area)
6. Declare compliance with DoT technical and security guidelines
7. Review all entries before final submission — no edits allowed after submission
8. Save acknowledgment receipt with application reference number

### Internal Review Gate
- [ ] All form fields completed accurately
- [ ] All universal and scheme-specific documents uploaded
- [ ] Documents are legible, correctly named, and within size limits
- [ ] Technical details of Wi-Fi equipment are specific and complete
- [ ] Declarations of compliance with DoT guidelines are acknowledged
- [ ] Application reference number saved and shared with client

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via https://dot.gov.in/pm-wani
- Take a screenshot of the confirmation page showing application reference number and timestamp
- Save the reference number in the case file and inform the client
- Set a follow-up reminder for 15 days post-submission to check status

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Collect and verify approval letter from DoT
- [ ] Confirm sanctioned rights: Authorization to operate as PDO or PDO aggregator under PM-WANI
- [ ] Note: No financial subsidy is provided; revenue is generated through user fees collected at PDOs with settlement via PDO aggregators
- [ ] Deploy Wi-Fi access points as per technical details submitted
- [ ] Integrate with PM-WANI ecosystem for authentication and service delivery via a certified PDO aggregator
- [ ] Begin service delivery and monitor user uptake
- [ ] Maintain records of usage and revenue for internal tracking and compliance
- [ ] Ensure ongoing adherence to technical guidelines and security standards issued by DoT
- [ ] No utilization certificate or financial reporting to government required (as no grant is involved)
