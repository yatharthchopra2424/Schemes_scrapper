# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a State Government, State Power Utility, Public Sector Undertaking, private developer, or cooperative society  
- [ ] Project capacity is up to 25 MW  
- [ ] Project is technically feasible as per CEA guidelines  
- [ ] Detailed Project Report (DPR) prepared as per CEA guidelines  
- [ ] Necessary clearances obtained from forest, environment, and irrigation departments  
- [ ] Geological and hydrological survey reports completed  
- [ ] Single line diagram and layout plan prepared  
- [ ] Power Purchase Agreement (PPA) or consent from State Utility secured  
- [ ] Incorporation/registration documents of applicant available  
- [ ] Financial viability report prepared  
- [ ] Undertaking for project completion within stipulated time provided  
- [ ] For special category states (North Eastern and Himalayan states), eligibility for enhanced CFA (100% for survey/investigation, up to ₹7 crore/MW for implementation) verified  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/registration documents  
- PAN card  
- ITR (last 2–3 years)  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam/MSME registration (if applicable)  

### Scheme-Specific Documents
- Detailed Project Report (DPR) as per CEA guidelines  
- Land ownership or lease documents  
- Clearances from forest, environment, and irrigation departments  
- Geological and hydrological survey reports  
- Single line diagram and layout plan  
- Power Purchase Agreement (PPA) or consent from State Utility  
- Financial viability report  
- Undertaking for completion of project within stipulated time  

### Document Quality Check
- All documents must be legible, self-attested, and in English or Hindi (with certified translation if in regional language)  
- File size: Each document < 10 MB; total upload < 50 MB  
- File naming: Use format `SchemeName_ApplicantName_DocumentType_Date.pdf` (e.g., `SHP_ABC_Infra_LandDocs_20250801.pdf`)  
- All certificates must be valid and not expired  
- DPR must be signed and stamped by authorized signatory  
- Undertaking must be on company letterhead and notarized if required

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
**Required.** The DPR must include:  
- Project overview and site details  
- Hydrological and geological survey findings  
- Civil works design (dam, intake, penstock, powerhouse, tailrace)  
- Electro-mechanical equipment specifications  
- Environmental impact assessment and mitigation plan  
- Clearance status and compliance  
- Financial analysis (cost estimates, funding plan, IRR, NPV)  
- Implementation schedule (milestone-wise)  
- Single line diagram and layout plan  
- Undertaking for timely completion  

### Application Form Filling Protocol
1. Download the application form from the State Nodal Agency (SNA) portal or MNRE website.  
2. Fill all fields in block letters; avoid overwriting or correction fluid.  
3. Attach all scheme-specific and universal documents as per the checklist.  
4. Ensure the undertaking for project completion is signed by the authorized signatory.  
5. Verify that the DPR is compliant with CEA guidelines for small hydro projects.  
6. Confirm that the project capacity does not exceed 25 MW.  
7. Double-check bank details and PAN for financial transactions.  
8. Retain a copy of the submitted application and all enclosures for records.  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] DPR complete and as per CEA guidelines  
- [ ] All scheme-specific documents attached and legible  
- [ ] Universal documents (PAN, ITR, bank statements, etc.) submitted  
- [ ] Undertaking for project completion signed and dated  
- [ ] Application form filled completely with no blank mandatory fields  
- [ ] Documents self-attested and in correct format  
- [ ] Reference number from SNA noted after submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the hard copy of the application and DPR to the State Nodal Agency (SNA)  
- Obtain a receipt/acknowledgment with inward number and date  
- Scan and save the acknowledgment receipt  
- Note the application reference number provided by SNA  
- Set a follow-up reminder for 15 days after submission to check status with SNA

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the approval letter from MNRE/SNA  
- [ ] Confirm sanctioned amount and disbursement schedule (instalments based on milestones)  
- [ ] Utilize funds only for approved project components as per LOA  
- [ ] Submit utilization certificates and progress reports for each instalment release  
- [ ] Ensure project completion within stipulated timeline; seek approval for extensions with penalties if applicable  
- [ ] Maintain records of all expenditures, invoices, and bank statements for audit  
- [ ] Coordinate with MNRE/SNA for final inspection and project closure  
- [ ] Submit project completion report and self-declaration letter upon commercial operation  
- [ ] Claim success fee as per consultancy agreement upon fund utilization verification
