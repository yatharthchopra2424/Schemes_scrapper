# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Project is a wind and/or solar power project (existing or new hybrid)
- [ ] Project is grid-connected
- [ ] Project complies with Central Electricity Authority (CEA) technical standards and grid connectivity norms
- [ ] Hybridization ensures optimal utilization of transmission infrastructure and land
- [ ] Hybrid project does not exceed sanctioned capacity at the point of interconnection
- [ ] Wind and solar components are connected at a single point to the grid
- [ ] Applicant is a power producer, renewable energy developer, independent power producer (IPP), or state utility
- [ ] Project has obtained necessary clearances (environmental, forest, aviation, defence) if applicable

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation/Registration
- PAN Card
- Memorandum and Articles of Association
- Board resolution authorizing the project
- GST Registration
- Udyam Registration (if applicable)
- Bank statements (last 6 months)
- Income Tax Returns (last 2 years)

### Scheme-Specific Documents
- Detailed Project Report (DPR)
- Power Purchase Agreement (PPA) or intent to enter into PPA
- Land documents (ownership or lease agreement)
- Single line diagram and layout plan
- Technical specifications of wind turbines and solar PV modules
- Grid connectivity approval from the concerned transmission utility
- Environmental and forest clearances (if applicable)
- No Objection Certificate (NOC) from the Aviation Authority (if applicable)
- Clearance from the Ministry of Defence (if applicable)

### Document Quality Check
- All documents must be legible, scanned in PDF format
- File size per document should not exceed 10 MB
- Document names must match the checklist (e.g., "DPR_WindSolarHybrid_ProjectX.pdf")
- All certificates and clearances must be valid and issued by competent authorities
- Documents in regional languages must be accompanied by self-attested English/Hindi translations
- Undertakings and declarations must be signed and stamped where required

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. Standard sections to include:
- Project overview and objectives
- Wind and solar technology selection and specifications
- Hybridization methodology and system design
- Single point of grid connection details
- Site assessment and land details
- Grid impact study and CEA technical compliance
- Environmental and social impact assessment
- Project implementation schedule
- Financial plan and cost estimates
- Operations and maintenance plan
- Risk assessment and mitigation measures
- Clearances and approvals status

### Application Form Filling Protocol
1. Access the application portal at https://mnre.gov.in and navigate to the relevant scheme section or contact SECI/state nodal agency as per MNRE guidelines.
2. Download the official application form or DPR template if specified by SECI or the state nodal agency.
3. Fill all fields accurately; do not leave any mandatory section blank.
4. Ensure consistency between data in the DPR and the application form (e.g., project capacity, location, technology).
5. Attach all required documents as per the checklist, clearly labeled.
6. Self-attest all document copies where required.
7. Verify that the project does not exceed sanctioned capacity at the point of interconnection and that wind/solar components connect at a single grid point.
8. Save a copy of the completed application and all attachments before submission.

### Internal Review Gate
- [ ] All application form fields completed accurately
- [ ] DPR includes all required sections and technical details
- [ ] All universal and scheme-specific documents are attached and legible
- [ ] Document file sizes are within limits and names are standardized
- [ ] Declarations and undertakings are signed and dated
- [ ] Project complies with CEA grid connectivity norms and single point of interconnection rule
- [ ] Hybridization does not exceed sanctioned capacity at interconnection point
- [ ] Contact details (email, phone) are correct for follow-up
- [ ] Application is ready for submission via SECI or state nodal agency as per MNRE process

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application (DPR and documents) to the Solar Energy Corporation of India Limited (SECI) or the respective state nodal agency as per MNRE guidelines.
- Obtain and save a screenshot of the submission confirmation or receipt.
- Record the application reference number or acknowledgment details.
- Set follow-up reminders for 15 days after submission if no acknowledgment is received.

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and securely store the approval letter from SECI or state nodal agency
- [ ] Verify the sanctioned project capacity and hybridization details in the approval
- [ ] Confirm eligibility to access benefits under existing wind and solar schemes (e.g., GBI, accelerated depreciation, concessional finance via IREDA)
- [ ] Initiate project implementation as per approved DPR and timeline
- [ ] After commissioning, apply for applicable incentives (GBI, tax benefits, etc.) through respective implementing agencies (e.g., IREDA for concessional finance, MNRE/SECI for GBI)
- [ ] Maintain records for utilization certificates and compliance reporting as required by incentive schemes
- [ ] Track and report success fee or invoicing as per consultancy agreement terms
