  - Valid Aadhaar number (for authentication)  
  - Recent electricity bill (to verify connection and address)  
  - Mobile number (for OTP-based authentication on portal/app)  

> **Evidence Note**: The UJALA scheme (https://ujala.gov.in) is designed for mass consumer access via online portal or mobile app with minimal documentation — primarily Aadhaar-linked authentication and electricity bill verification.

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
- **Not required**. The UJALA scheme is a direct benefit transfer (DBT) or point-of-sale subsidy model for individual consumers. No Detailed Project Report (DPR) is needed for household applicants.  
- If applying as a bulk consumer (e.g., housing society, apartment complex), **verify with nodal officer** whether a simplified proposal is required.  

### Application Form Filling Protocol
1. **Access the portal**: Visit [https://ujala.gov.in](https://ujala.gov.in) or the EESL UJALA portal ([https://www.ujala.com](https://www.ujala.com))  
2. **Authenticate via Aadhaar**: Enter Aadhaar number and validate using OTP sent to registered mobile  
3. **Verify electricity details**: Enter consumer number from latest bill (account number, subdivision, DISCOM name)  
4. **Select product**: Choose from available LED bulbs (typically 7W, 9W, 12W) — quantities limited per household (e.g., max 5 bulbs)  
5. **Confirm delivery address**: Ensure it matches the electricity bill address  
6. **Agree to terms**: Confirm domestic use only and no resale  
7. **Submit and note reference number**: Save application ID for tracking  
8. **Check for payment**: If applicable, pay nominal amount online (many states offer free bulbs)  

> **Portal-Specific Note**: The official URL https://ujala.gov.in currently returns a 404 error. Use the EESL-managed portal [https://www.ujala.com](https://www.ujala.com) or contact your DISCOM for local distribution points.
