# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Manufacturer of appliances (as per scheme definition)
- [ ] Appliance falls under the Standards & Labelling (S&L) programme list (BEE programme (mandatory or voluntary regime)
- [ ] Appliance model is not already registered under BEE S&L (check public list)
- [ ] Manufacturer has valid GST registration and PAN
- [ ] Manufacturer has Udyam/MSME registration (if applicable)
- [ ] Manufacturer has testing facility or access to NABL-accredited lab for star rating testing
- [ ] Manufacturer can affix QR code on every appliance bearing BEE star label (as mandated)
- [ ] Manufacturer agrees to integrate with BEE star label mobile app for sales logging (if applicable)
- [ ] Application is submitted online via https://www.beestarlabel.com/
- [ ] Application submitted before 25th September 2025 (Building Star Labeling Program under revision; no applications accepted from this date until further notice)
- [ ] Manufacturer is based in India (Pan-India scheme)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Business Registration
- PAN Card of the business
- GST Registration Certificate
- Udyam Registration (if MSME)
- Bank Statement (last 6 months)
- ITR of last 2 financial years
- Authorization Letter for Consultant (if applicable)

### Scheme-Specific Documents
- Product technical specification sheet (including energy consumption data)
- Test report from NABL-accredited lab for star rating (as per BEE S&L standards)
- Brand authorization letter (if applying under brand name)
- Declaration of conformity with BEE S&L programme requirements
- Details of QR code implementation plan for appliances
- Information on integration with BEE star label mobile app (for sales logging)
- Sample of proposed star label design (as per BEE guidelines)

### Document Quality Check
- All documents must be in PDF format
- File size not exceeding 5 MB per document
- File names must follow format: `SchemeName_DocumentType_ApplicantName.pdf`
- All certificates must be valid and not expired
- English language preferred; Hindi documents must be accompanied by certified English translation
- Scanned copies must be clear and legible
- Test reports must be issued by NABL-accredited laboratories
- Declarations must be signed and stamped by authorized signatory

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for this scheme. The application is primarily an online registration for star labelling. However, if detailed project reporting is needed for any associated energy efficiency initiative, verify with the nodal officer.

### Application Form Filling Protocol
1. Access the portal: https://www.beestarlabel.com/
2. Select “New Application” or “Register Appliance Model”
3. Enter manufacturer details exactly as per PAN and GST
4. Select appliance category from the predefined list (Room AC, Refrigerator, LED Lamps, etc.)
5. Enter model number, brand name, and technical specifications (energy consumption, star rating sought)
6. Upload all required documents in PDF format
7. Declare compliance with QR code mandate and mobile app integration
8. Submit the application and note down the application reference number
9. Track application status via the portal using the reference number
10. Ensure all declarations are signed digitally or via scanned copy
11. Do not leave any mandatory field blank
12. Verify that the appliance model is not already registered in the public BEE approved models list
13. Confirm that the star rating claimed matches the test report from NABL lab
14. Keep a copy of the submitted application and acknowledgment

### Internal Review Gate
- [ ] All fields in the application form are filled accurately
- [ ] All universal and scheme-specific documents are attached
- [ ] Test report is from NABL-accredited lab and valid
- [ ] Declarations are signed and stamped
- [ ] QR code and mobile app integration details are provided
- [ ] Application reference number is saved and shared with client
- [ ] No duplicate model already exists in BEE public list
- [ ] Submission done before 25th September 2025 (if applicable)

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via https://www.beestarlabel.com/
- Take a screenshot of the confirmation page showing application reference number and timestamp
- Save the reference number in the case file and inform the client
- Set a follow-up reminder for 15 days post-submission
- Monitor portal for any queries or requests for additional information

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from BEE
- [ ] Confirm sanctioned star rating and validity period
- [ ] Download and save the list of approved models from BEE public domain (linked to S&L application)
- [ ] Ensure QR codes are affixed on all manufactured appliances as per mandate
- [ ] Integrate sales logging with BEE star label mobile app (if applicable)
- [ ] Inform client to commence manufacturing and labeling
- [ ] Monitor for any post-approval compliance requirements
- [ ] Prepare for utilization certificate if financial assistance is involved (verify with nodal officer)
- [ ] Follow up on invoice for success fee as per consultancy agreement
- [ ] Maintain records for future renewals or updates to the model
