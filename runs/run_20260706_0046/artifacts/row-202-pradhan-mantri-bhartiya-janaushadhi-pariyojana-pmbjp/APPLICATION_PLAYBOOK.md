# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is an individual entrepreneur, proprietor, partnership, charitable institute/hospital, NGO/trust/society, or government/nominated agency  
- [ ] Individual applicant holds a D.Pharm/B.Pharm degree OR employs degree holders and provides proof at application or final approval  
- [ ] Entrepreneur/pharmacist/trust/society/charitable organization employs B.Pharm/D.Pharm degree holders and provides proof  
- [ ] Applicant owns or hires space (minimum 120 sq. ft.) with proper lease agreement  
- [ ] Applicant has secured a registered pharmacist (name and State Council registration provided)  
- [ ] Applicant submits financial capacity documents (ITR for last two years, bank statement for last 6 months, PAN/Aadhar)  
- [ ] Applicant obtains a drug license in the name of 'Pradhan Mantri Janaushadhi Kendra'  
- [ ] Applicant adheres to distance policy: minimum 1 km between Kendras; no restriction within 500m of hospitals with 100+ beds or medical college-associated hospitals  
- [ ] For special incentive eligibility (if applicable): applicant belongs to women entrepreneur, Divyang, SC/ST, ex-serviceman, aspirational district (NITI Aayog-notified), Himalayan, Island, or North-Eastern state category and provides relevant certificate  

**Sources**:  
- Eligibility criteria from KEY FACTS  
- Application portal: https://janaushadhi.gov.in

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Aadhaar Card  
- PAN Card  
- ITR for last two years  
- Bank statement for last 6 months  
- GST registration declaration (once threshold limit is achieved)  
- Udyam Registration (if applicable for MSMEs)  

### Scheme-Specific Documents
- Certificate of SC/ST or Divyang (PWD) or General category Registration certificate  
- Pharmacist Registration Certification  
- Undertaking of distance policy as per guideline  
- Self-Undertaking of PMBJP Kendra for availing one-time special incentive (if applicable under woman entrepreneur/divyaang/SC/ST/ex-serviceman/aspirational district/Himalayan/Island Territories/North-Eastern States)  
- Three cheques from Indian Nationalized Banks in favor of PMBI  
- One cancelled cheque from Indian Nationalized Banks to PMBI  
- Proof of space ownership or lease agreement (minimum 120 sq. ft.)  
- Proof of securing a pharmacist (name, State Council registration)  
- Drug License in the name of 'Pradhan Mantri Janaushadhi Kendra'  

### Document Quality Check
- All documents must be self-attested  
- File size: each PDF < 5 MB  
- File names must match document type (e.g., "Aadhaar_Card.pdf")  
- Photocopies must be clear and legible  
- Undertakings must be signed and stamped by applicant  
- Bank documents must show applicant’s name matching PAN/Aadhar  
- Drug license must be issued in the exact name: 'Pradhan Mantri Janaushadhi Kendra'  
- All documents must be in English or accompanied by certified translation

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for PMBJP application. However, if applying for special incentive reimbursement post-approval, a utilization certificate (Form GFR 19A) and bill submissions are required. Verify with nodal officer for any updates.  

### Application Form Filling Protocol
1. Visit https://janaushadhi.gov.in and click 'APPLY FOR KENDRA' tab  
2. Click 'REGISTER NOW' and fill applicant details (mobile number, email ID)  
3. Upon registration, note the USER ID and PASSWORD sent to your email  
4. Login using USER ID/PASSWORD or via registered mobile/email using 'Get OTP' option  
5. Fill application form: enter basic and proposed Kendra details  
6. Adhere to distance policy: declare no existing Kendra within 1 km radius  
7. Upload required documents in PDF format (each < 5 MB)  
8. For location tagging: drag and drop location icon within blue circle to exact address/shop/building  
9. Pay application fee of Rs. 5,000 via online payment gateway (exempt if eligible category proof submitted)  
10. After submission, confirmation email will be sent; check status online or call helpline 18001808080  

**Critical Rules**:  
- Ensure all uploaded documents are legible and under 5 MB  
- Double-check that the Kendra name in drug license matches 'Pradhan Mantri Janaushadhi Kendra' exactly  
- Confirm location pin is accurately placed within the blue circle on the map  
- Select correct applicant category (individual/proprietor/partnership/etc.) in the form  
- If claiming fee exemption, upload category certificate before payment step  
- Undertaking of distance policy must be signed and uploaded  
- Do not leave any mandatory field blank  
- Save a copy of the submitted application for your records  

### Internal Review Gate
- [ ] All application form fields completed accurately  
- [ ] All required documents uploaded (universal + scheme-specific)  
- [ ] Each document PDF < 5 MB and clearly named  
- [ ] Undertaking of distance policy signed and uploaded  
- [ ] Drug license issued in name of 'Pradhan Mantri Janaushadhi Kendra'  
- [ ] Pharmacist registration proof attached  
- [ ] Space ownership/lease agreement shows minimum 120 sq. ft.  
- [ ] Application fee paid or exemption proof uploaded  
- [ ] Declarations signed (GST, special incentive if applicable)  
- [ ] Contact details (mobile, email) correct and accessible

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the final submission confirmation page showing application reference number  
- Store the reference number securely in case file  
- Set calendar reminders for follow-up at 7, 15, and 30 days post-submission  
- Save submission confirmation email from portal  
- Note down the expected timeline for approval (typically 15–30 days, though rolling)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from PMBI  
- [ ] Confirm sanctioned amount (normal incentive: up to Rs. 20,000/month; special incentive: Rs. 2.00 lakhs if eligible)  
- [ ] Ensure drug license is active and in the name of 'Pradhan Mantri Janaushadhi Kendra'  
- [ ] Install and activate PMBI-provided POS software for billing and inventory  
- [ ] Begin procurement of medicines from PMBI’s Central/Regional Warehouse or authorized distributors  
- [ ] Maintain stocking mandate: 180–200 medicines for 100% incentive disbursement  
- [ ] For special incentive reimbursement (if applicable): submit original bills, bank details, Form GFR 19A, and undertakings within 90 days of Kendra opening  
- [ ] File monthly utilization reports and purchase data via POS system  
- [ ] Track invoice success fee for consulting services post-approval
