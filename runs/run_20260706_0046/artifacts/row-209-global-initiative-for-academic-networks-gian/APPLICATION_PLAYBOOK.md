# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Institution is a Government (State or Central) higher education Institution / University  
- [ ] Institution is ranked in the top 200 in NIRF overall rankings  
- [ ] Institution has at least NAAC ‘A’ grade (CGPA 3.0 and above)  
- [ ] Competent authority has appointed a local coordinator for GIAN (with name, email, mobile)  
- [ ] Formal request letter from the highest Authority (VC / Director) of the Institute is available  
- [ ] NAAC ‘A’ grade certificate is available  
- [ ] Proof of NIRF Ranking in top 200 is available  
- [ ] Formal office order for appointment of local coordinator, GIAN of the Institute/University is available (including name, email address and mobile number)  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation certificate  
- PAN card  
- Income Tax Returns (ITR) of last 3 years  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam Registration (if applicable)  

### Scheme-Specific Documents
- Formal request letter from the highest Authority (VC / Director) of the Institute  
- NAAC ‘A’ grade certificate  
- Proof of NIRF Ranking in top 200  
- Formal office order for appointment of local coordinator, GIAN of the Institute/University (including name, email address and mobile number)  

### Document Quality Check
- All documents must be legible scans or clear photographs  
- File names must match the document description (e.g., NAAC_Certificate.pdf, NIRF_Ranking_Proof.pdf)  
- File size must not exceed 5 MB per document  
- All certificates must be issued by authorized bodies (NAAC, NIRF, etc.)  
- Documents must be in English or accompanied by certified translation  
- Signatures and seals must be visible and authentic

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for GIAN scheme. Proposals are submitted in PDF format via the GIAN portal. Verify with nodal officer if any additional project report is needed for specific course proposals.  

### Application Form Filling Protocol
1. Ensure the local coordinator logs into the GIAN portal (https://www.gian.iitkgp.ac.in/GREGN/) using credentials provided after eligibility verification  
2. Edit profile to provide accurate contact details (name, email, mobile)  
3. Circulate the proposal template (available in portal download section) to faculty for course proposal submission  
4. Invite course coordinators via the 'Invite Proposal' menu using authentic email IDs  
5. Course coordinators must upload proposals in PDF format and click 'Final Submit'  
6. Local coordinator must scrutinize the proposal and foreign faculty consent form before clicking 'Accept'  
7. Ensure all proposals meet the prescribed format and include signed foreign faculty consent form in PDF  
8. Reject and request resubmission if documents lack information or are improperly formatted  

### Internal Review Gate
- [ ] Local coordinator profile is updated with correct contact details  
- [ ] All course proposals are in PDF format  
- [ ] Foreign faculty consent forms are signed, scanned, and uploaded in PDF  
- [ ] Proposals include course duration, lecture hours, faculty details, and budget alignment  
- [ ] Local coordinator has clicked 'Accept' for all proposals after scrutiny  
- [ ] Proposal status shows 'Submitted to Section Coordinator for Review'  
- [ ] All declarations and undertakings in the portal are completed

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the submission confirmation page showing proposal status  
- Store the GIAN portal reference number for each proposal  
- Set follow-up reminders for status checks every 7 days  
- Monitor proposal tracking via the GIAN portal's 'Proposal Tracking' option

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive approval mail from National Coordinator requesting upload of final brochure and course dates  
- [ ] Coordinate with course coordinator to upload final brochure and finalize course dates in the portal  
- [ ] Verify receipt of official signed sanction letter with fund details sent to the Institute  
- [ ] Confirm fund allocation release via PFMS after brochure upload  
- [ ] During course: Monitor via portal, ensure participant feedback submission  
- [ ] After course: Submit course completion report and fund utilization certificate to IIT Kharagpur within 15 days  
- [ ] Upload expenditure statement in PFMS section by the concerned person  
- [ ] Ensure all approved courses are completed by 31st December 2020 (per Local Coordinator manual; verify current validity with nodal officer)  
- [ ] Apply dollar conversion rate of Rs. 83 per USD for F.Y. 2023-24 (subject to review for subsequent years)  
- [ ] Ensure contingencies and other expenses (excluding travel and honorarium of foreign faculty) do not exceed 35% of total fund provided  
- [ ] Earmark maximum of Rs. 5000/- per course for local coordinator office expenses and honorarium from contingency expense  
- [ ] Note: Foreign faculty not entitled to travel allowance in virtual mode; only honorarium paid (limited to $3000 for ≥12 hrs, $5000 for ≥20 hrs)  
- [ ] Note: GIAN to MOOC conversion of completed courses is discontinued for both in-person and virtual mode
