# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Confirm the user is a student, learner, or member of the general public (no restrictions apply)
- [ ] Verify the user is located in India (service is Pan-India)
- [ ] Confirm the user has access to a television set or mobile device for viewing
- [ ] Ensure the user understands there are no eligibility criteria, fees, or application requirements
- [ ] Validate that the user seeks free educational content for school, higher education, or competitive exam preparation
- [ ] Confirm the user is aware that the service is available 24x7 via DD Free Dish, Dish TV, or JIO TV app
- [ ] Check if the user needs guidance on installing DD Free Dish or configuring set-top box parameters (MPEG4 compatible after June 7, 2023)
- [ ] Verify the user is not seeking financial support, certification, or credit transfer (scheme does not provide these)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- [ ] Proof of identity (Aadhaar, PAN, passport, or voter ID)
- [ ] Proof of address (utility bill, rental agreement, or Aadhaar)
- [ ] Bank account details (for any potential future scheme linkage, though not required for access)
- [ ] Educational enrollment proof (student ID, bonafide certificate, or admission letter) – *optional but recommended for targeted support*
- [ ] Udyam registration (if applicable for institutional users)
- [ ] GST registration (if applicable for institutional users)
- [ ] Income Tax Returns (ITR) – *not required for access, but may be useful for profiling*

### Scheme-Specific Documents
- [ ] **No scheme-specific documents are required** to access SWAYAM PRABHA channels, as the service is free and open to all without application or registration.

### Document Quality Check
- [ ] All documents must be clear, legible scans or photographs
- [ ] File size should not exceed 5 MB per document
- [ ] File names must match the applicant's name as per government ID
- [ ] Documents must be in English or Hindi; regional languages accepted if accompanied by a certified translation
- [ ] No self-attestation required for access, but if submitted for institutional profiling, documents should be signed and dated
- [ ] Photographs must be recent (within last 6 months) for identity proof

1. Installing a **DD Free Dish** set-top box (available for < Rs. 2,000) and configuring it with the following parameters (MPEG4 compatible required after June 7, 2023):

   - Symbol Rate: 29500 KSPS  
   - FEC: 3/4

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
- **Not applicable.** SWAYAM PRABHA does not provide financial support or require project proposals. It is a free broadcasting service.  
- **Action:** Flag "verify with nodal officer" only if the client mistakenly believes funding is involved; otherwise, clarify that no DPR is needed.

### Application Form Filling Protocol
- **Not applicable.** There is **no application form** for accessing SWAYAM PRABHA channels.  
- **Critical Rules for Client Guidance:**  
  1. Do not attempt to fill any application form — none exists for access.  
  2. Avoid third-party portals claiming to offer "registration" or "approval" for SWAYAM PRABHA — these are misleading.  
  3. Direct users only to the official portal: https://swayamprabha.gov.in  
  4. Emphasize that access is immediate upon proper hardware setup (DD Free Dish/Dish TV/JIO TV).  
  5. Warn against paying any fees for "access" or "certification" — the service is completely free.  
  6. Confirm that no login or registration is required to view content (though optional registration exists for SMS alerts).  
  7. Guide users to the Help Manual for technical setup: https://swayamprabha.gov.in/Help_manual  
  8. Remind users that MPEG2 set-top boxes must be upgraded to MPEG4-compatible boxes after June 7, 2023, to continue receiving channels.

### Internal Review Gate

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- **Not applicable.** There is no submission process for accessing SWAYAM PRABHA.  
- **Action:**  
  - Advise client to take a screenshot of their configured DD Free Dish set-top box parameters or JIO TV app showing Swayam Prabha channels as proof of successful access.  
  - Store this screenshot in the client case file with timestamp.  
  - Set a follow-up reminder for 7 days post-guidance to confirm successful viewing.  
  - No reference number is generated, as no formal submission occurs.
