# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity is an Indian company, startup, MSME, or private sector organisation  
- [ ] Engaged in defence manufacturing, design, development, or supply of defence equipment, systems, or services  
- [ ] Contributes to indigenisation, technology absorption, or Make in India initiatives under Atmanirbhar Bharat framework  
- [ ] Possesses valid Certificate of Incorporation / Registration  
- [ ] Has PAN of the entity  
- [ ] Holds GST Registration Certificate  
- [ ] Has UDYAM Registration (if MSME)  
- [ ] Provides product specifications and technical brochures  
- [ ] Holds manufacturing licence or industrial licence (if applicable)  
- [ ] Submits past performance certificates or supply orders  
- [ ] Provides bank details and cancelled cheque  
- [ ] Submits authorised signatory letter  
- [ ] Declares compliance with defence standards  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN of the entity  
- ITR (last 2–3 years)  
- GST Registration Certificate  
- Bank statements (last 6 months)  
- Udyam Registration (for MSMEs)  

### Scheme-Specific Documents
- Product specifications and technical brochures  
- Manufacturing licence or industrial licence (if applicable)  
- Past performance certificates or supply orders  
- Authorised signatory letter  
- Declaration of compliance with defence standards  

### Document Quality Check
- File size under 10 MB per document  
- File names match document type (e.g., PAN_Card.pdf)  
- All certificates are valid and not expired  
- Documents are in English or Hindi; if in another language, certified translation attached  
- Scanned copies are clear, legible, and colour where required  
- Bank details include account number, IFSC, and cancelled cheque

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required for this scheme. However, a detailed project report may be needed for linked schemes like DPEPP. **Verify with nodal officer** if DPR is required for financial incentives under allied schemes.

### Application Form Filling Protocol
1. Access the application via the Ministry of Defence portal: **https://www.mod.gov.in**  
2. Select “Vendor Registration” or “Expression of Interest (EOI)” for defence procurement opportunities  
3. Fill in entity details exactly as per Certificate of Incorporation and PAN  
4. Upload all documents in the specified format (PDF/JPEG, <10 MB)  
5. Ensure authorised signatory letter is uploaded and signed  
6. Declare compliance with defence standards explicitly in the form  
7. Double-check bank details for accuracy before submission  
8. Save draft and review before final submission  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] All universal and scheme-specific documents collected and validated  
- [ ] Application form fields filled accurately and completely  
- [ ] Documents attached as per checklist  
- [ ] Declarations signed and dated  
- [ ] Authorised signatory letter uploaded  
- [ ] Declaration of compliance with defence standards included  
- [ ] Application draft reviewed by senior consultant

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via **https://www.mod.gov.in**  
- Take a screenshot of the confirmation page showing submission timestamp and reference number  
- Store the reference number securely in the case file  
- Set follow-up reminders for Day 25 and Day 35  
- Notify client of successful submission with reference number
