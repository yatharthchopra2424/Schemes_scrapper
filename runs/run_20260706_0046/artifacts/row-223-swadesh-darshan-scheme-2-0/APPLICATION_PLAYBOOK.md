## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a **State Government** or **Union Territory Administration** (as per scheme guidelines)
- [ ] Project is aligned with one of the **identified thematic circuits** under Swadesh Darshan Scheme 2.0
- [ ] Project adheres to scheme guidelines, including norms for **sustainable tourism**
- [ ] **Environmental clearances** have been obtained (if applicable)
- [ ] **Land availability certificate** is in place (land must be free from encumbrances with clear title)
- [ ] Project proposal includes a **convergence plan** with other central and state schemes
- [ ] **Circuit map and thematic justification** are prepared and submitted
- [ ] **State Level Empowered Committee (SLEC) clearance** has been obtained
- [ ] Project does not seek funding for **recurring expenses or manpower** (only capital infrastructure)
- [ ] Beneficiary state/UT is prepared to bear the prescribed **cost share** (60:40 for general, 90:10 for NE/Himalayan, 100% for UTs)

- [ ] All documents are in **English or Hindi**; if in regional language, certified translation attached
- [ ] File size per document does not exceed 10 MB; compress if necessary without losing clarity

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
✅ **Required** – The Detailed Project Report (DPR) is a **mandatory** document for Swadesh Darshan Scheme 2.0.  
**Standard Sections to Include**:
- Executive Summary
- Project Background and Objectives (aligned with thematic circuit)
- Site Selection and Land Details
- Tourism Infrastructure Components (wayside amenities, accommodation, eco-lodges, pathways, illumination, etc.)
- Circuit Map and Thematic Justification
- Environmental and Social Impact Assessment (if applicable)
- Project Implementation Schedule (Gantt chart)
- Detailed Cost Estimates (item-wise, as per CPWD/PWD schedule of rates)
- Funding Pattern and Financial Plan (60:40, 90:10, or 100% as applicable)
- Operation and Maintenance Plan (post-completion)
- Convergence Plan with Other Schemes (e.g., PRASAD, HRIDAY, MGNREGA)
- Risk Assessment and Mitigation Measures
- Expected Outcomes (tourist footfall, employment generation, revenue projections)
- Annexures: Land documents, SLEC clearance, NOCs, drawings, BOQ

> **Note**: DPR must be prepared strictly as per Swadesh Darshan Scheme 2.0 guidelines issued by the Ministry of Tourism. Verify latest template with nodal officer if unsure.

### Application Form Filling Protocol
1. Access the application portal at [https://tourism.gov.in](https://tourism.gov.in) and navigate to the "Swadesh Darshan Scheme 2.0" section under "Schemes".
2. Download the latest proposal submission format (if available) or use the standard DPR-based DPR as the primary submission.
3. Ensure all fields in the DPR are complete; leave no section blank – if not applicable, write “Not Applicable” with justification.
4. Clearly state the **identified thematic circuit** (e.g., Buddhist Circuit, Coastal Circuit, Desert Circuit) the project aligns with.
5. Specify the **exact funding pattern** applicable (60:40, 90:10, or 100%) based on state/UT category.
6. Attach all scheme-specific documents as separate PDFs with correct labeling.
7. Confirm that the **Undertaking for Operation and Maintenance** is signed by the authorized state/UT representative.
8. Do not include any recurring costs (salaries, office expenses) in the project budget – only capital infrastructure is eligible.
9. Save a draft before final submission and verify file sizes and attachments.

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the **approval letter/sanction order** from the Ministry of Tourism
- [ ] Confirm the **sanctioned amount** and **funding pattern** (60:40, 90:10, 100%) as per eligibility
- [ ] Verify that funds are to be released in **installments** based on physical and financial progress
- [ ] Ensure the **Utilization Certificate (UC)** format is understood and ready for submission after each installment
- [ ] Confirm that **progress reports** (physical and financial) are required for subsequent fund releases
- [ ] Advise client to bear their **prescribed share** of project cost as per scheme guidelines
- [ ] Ensure no expenditure is incurred on **recurring expenses or manpower** (only capital works allowed)
- [ ] Monitor project timelines to ensure completion within **stipulated period** as per sanction
- [ ] Prepare for **site visits** by Ministry officials or third-party monitoring agencies
- [ ] Upon project completion, submit final **Utilization Certificate and Completion Report**
- [ ] Coordinate with finance team to claim **success fee** as per engagement terms (post-approval milestone)
