## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a State Government, Public Sector Undertaking (PSU), Joint Venture Company, or other entity engaged in mineral exploration activities  
- [ ] Proposal is for exploration of minerals specified in the First Schedule of the Mines and Minerals (Development and Regulation) Act, 2015  
- [ ] Project follows guidelines issued by NMET from time to time  
- [ ] Applicant agrees to bear 50% of total project cost (NMET grant covers up to 50%)  
- [ ] Project includes activities such as reconnaissance, prospecting, general exploration, geophysical surveys, geochemical sampling, drilling, or related exploration activities  
- [ ] Applicant has capacity to submit utilization certificates and progress reports for installment-based disbursement  
- [ ] Project timeline is defined and realistic; extensions require prior NMET approval

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
✅ **Required** – The Detailed Project Report (DPR) is a mandatory document for NMET grant applications.  

**Standard Sections to Include**:  
- Executive Summary  
- Project Objectives (aligned with NMET goals: regional/detailed exploration, critical minerals, import substitution)  
- Geological Background and Justification for Block Selection  
- Methodology (reconnaissance, prospecting, geophysical/geochemical surveys, drilling plan)  
- Work Plan and Timeline (Gantt chart or phase-wise milestones)  
- Detailed Budget Estimate (breakdown: personnel, equipment, surveys, drilling, contingency)  
- Expected Outcomes (mineral resource estimation, reports, data generation)  
- Environmental and Social Considerations (if applicable)  
- Risk Assessment and Mitigation Plan  
- Commitment to 50% Cost Sharing by Applicant  
- Declaration of Compliance with NMET Guidelines  

> **Sources**: NMET Grants Key Facts (Required Documents, Application Process)  

### Application Form Filling Protocol
1. Access the NMET portal at **https://nmet.nic.in** and navigate to the “Proposal Submission” or “Apply for Grant” section.  
2. Create a user account using official email and mobile number; verify via OTP.  
3. Select “NMET Grant for Mineral Exploration” as the scheme type.  
4. Fill in applicant details exactly as per PAN and incorporation documents (name, address, CIN/LLPIN, PAN, GST).  
5. Upload the Detailed Project Report (DPR) as a single PDF file (ensure it is signed and complete).  
6. Upload budget estimate, exploration license, and cost-sharing undertaking in the respective sections.  
7. Declare that the applicant will bear 50% of the project cost and that funds will be used solely for approved exploration activities.  
8. Preview all entries and attachments before final submission; ensure no blank mandatory fields.  
9. Submit the application and save/download the acknowledgment receipt with application number.  
10. Note: If the portal requires offline submission via email, use **nmetscheme@gmail.com** with all documents and a cover letter.
