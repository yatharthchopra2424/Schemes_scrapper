# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Exporter of notified goods/products as per Foreign Trade Policy (FTP)
- [ ] Exports made under Importer Exporter Code (IEC) granted by DGFT
- [ ] Eligibility determined based on product description and ITC(HS) code as notified under the scheme
- [ ] Business type: Exporter, Manufacturer, or MSME
- [ ] IEC registration is valid and active
- [ ] Exports made within the financial year (applications typically submitted within the financial year of export)
- [ ] Product is notified under MEIS for the relevant financial year
- [ ] Exporter has realized export proceeds in foreign currency
- [ ] IEC is linked to PAN (post-GST implementation)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- IEC Certificate
- PAN Card
- GST Registration Certificate
- Bank Statements (last 6 months)
- ITR (last 2 years)
- Udyam Registration (if MSME)
- Digital Signature Certificate (DSC)

### Scheme-Specific Documents
- Shipping Bill(s)
- Proof of realization of export proceeds (Bank Realization Certificate)
- Packing List
- Commercial Invoice(s)
- IEC Certificate (reiterated as mandatory)

### Document Quality Check
- All documents must be legible scans or clear photographs
- File names must match document type (e.g., "Shipping_Bill_Jan2026.pdf")
- File size should not exceed 5 MB per document
- All certificates must be valid and not expired
- Documents must be in English or accompanied by certified translation
- IEC details must match across all documents (IEC number, firm name, address)
- Bank Realization Certificate must clearly show FOB value and date of realization
- Shipping Bill must match invoice details (description, quantity, value)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for MEIS. The scheme is document-based and does not require a Detailed Project Report (DPR). However, if additional justification is needed, verify with the nodal officer.

### Application Form Filling Protocol
1. Register on the DGFT website (https://dgft.gov.in) using valid email and mobile number.
2. Log in to the DGFT portal using your credentials.
3. Navigate to the MEIS section under Export Promotion Schemes.
4. Select the correct financial year for which the export was made.
5. Enter accurate IEC details (must match PAN post-GST).
6. Upload all required documents in the specified format (PDF/JPEG, <5 MB).
7. Ensure the product description and ITC(HS) code match the notified MEIS product list.
8. Declare the FOB value of exports accurately as per shipping bill and invoice.
9. Confirm that the export was made under the IEC and that proceeds have been realized.
10. Review all entries before final submission; no edits allowed after submission.
11. Submit the application and save the acknowledgment receipt.
12. Monitor application status via the portal using the reference number.

### Internal Review Gate
- [ ] All application fields completed accurately
- [ ] IEC number matches PAN and is valid
- [ ] Shipping Bill, Invoice, Packing List, and Bank Realization Certificate are consistent (value, description, date)
- [ ] Product is verified as notified under MEIS for the relevant financial year
- [ ] All documents are uploaded, legible, and within size limits
- [ ] Declarations regarding eligibility and realization of proceeds are signed
- [ ] Application is submitted within the financial year of export
- [ ] Reference number saved and follow-up reminders set

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via https://dgft.gov.in after internal review
- Take a screenshot of the confirmation page showing the application reference number
- Store the reference number securely in the case file
- Set follow-up reminders for Day 25 and Day 35 to check application status
- Save all communication and portal activity logs

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from DGFT (issued electronically via portal)
- [ ] Confirm sanctioned amount (duty credit scrips value) matches eligibility calculation
- [ ] Download and verify duty credit scrips issued electronically in the IEC holder’s account
- [ ] Ensure utilization certificate is prepared if required for internal audit
- [ ] Coordinate with client on utilization of scrips (payment of customs duty, excise duty, service tax, or other dues)
- [ ] Track utilization and maintain records for compliance
- [ ] Follow up on success fee invoice as per engagement agreement
- [ ] Advise client on scrip transfer/trading options if not utilized directly
- [ ] Maintain records for 5 years as per DGFT compliance requirements
- [ ] Notify client of any scheme updates or changes affecting scrip validity or usage
