# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Target beneficiary is a tribal MFP gatherer  
- [ ] Target beneficiary is a Self Help Group (SHG)  
- [ ] Target beneficiary is a Van Dhan Vikas Kendra (VDVK)  
- [ ] Target beneficiary is a tribal artisan  
- [ ] Target beneficiary is a forest dweller  
- [ ] The MFP being collected/processed is among the 50 non-nationalized MFPs listed in Annexure 1 of the scheme guidelines  
- [ ] The activity involves procurement, value addition, or marketing of Minor Forest Produce (MFP)  
- [ ] The applicant is located in any state or union territory of India (pan-India coverage)  
- [ ] The applicant is willing to form or is already part of a SHG, producer company, cooperative, or other collective to improve bargaining power  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Identity proof (Aadhaar, Voter ID, PAN Card)  
- Address proof (utility bill, ration card, passport)  
- Bank account details (cancelled cheque, bank passbook)  
- PAN card of the entity/individual  
- GST registration (if applicable)  
- Udyam Registration (for MSMEs)  
- Income Tax Returns (ITR) of the last 2 years  
- Bank statements of the last 6 months  

### Scheme-Specific Documents
- Resolution from the Self Help Group (SHG) to open a savings bank account (as per Annexure-A of the advisory on bank accounts)  
- Specimen signatures/thumb impressions of SHG representatives  
- Copy of ID and address proof of authorized SHG representatives  
- Photographs of authorized representatives  
- Copy of resolution by SHG to open savings account  
- For VDVK: Resolution passed by Managing Committee (one representative from each SHG) to open a bank account in the name of the Kendra  
- Stamp (seal) made for the VDVK bank account  
- Details of the MFP being collected/processed (name, quantity, MSP rate)  
- Procurement plan or action plan for MFP collection and value addition  
- Details of training undertaken on sustainable harvesting, conservation, regeneration, value addition, and marketing  
- Proof of formation of SHG/VDVK (registration certificate, if applicable)  
- List of MFP items covered under the scheme (from Annexure 1)  

### Document Quality Check
- All documents must be legible and clear scans  
- File size should not exceed 5 MB per document  
- File names must match the document type (e.g., SHG_Resolution_BankAccount.pdf)  
- Names on documents must match exactly as per official records  
- Documents must be self-attested or notarized where required  
- Language: Hindi or English; if in regional language, certified translation must be attached  
- Bank account must be in the name of the SHG/VDVK, not an individual member

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required in the evidence. However, a detailed action plan for procurement, infrastructure, training, value addition, and marketing (Van Dhan) must be prepared as per the role of the District Implementing Unit. **Verify with nodal officer if a formal DPR is required.**

### Application Form Filling Protocol
1. Access the application portal at https://trifed.tribal.gov.in  
2. Ensure all fields are filled accurately; no blank fields allowed  
3. Upload documents in PDF format only, with correct naming convention  
4. Bank account details must be in the name of the SHG/VDVK, not an individual  
5. MSP rate claimed must match the latest notified rate for the specific MFP from Annexure 1  
6. Clearly state the role of the applicant (gatherer, SHG, VDVK, artisan) in the value chain  
7. Attach proof of training on sustainable harvesting and value addition  
8. Declare that no fees/charges/royalties will be imposed on MFP processing or marketing (as per scheme guidelines)  
9. Confirm that the applicant will not be evicted or displaced without settlement of rights  
10. Submit the application and save the acknowledgment receipt  

### Internal Review Gate
- [ ] All personal and entity details are correctly filled  
- [ ] All universal and scheme-specific documents are attached  
- [ ] Bank account is in the name of the SHG/VDVK  
- [ ] MSP rate matches Annexure 1 for the claimed MFP  
- [ ] Resolution for bank account opening is signed by authorized representatives  
- [ ] Proof of training on sustainable harvesting and value addition is attached  
- [ ] Declarations regarding no fees on MFP processing and compliance with FRA/PESA are included  
- [ ] Application form is reviewed and signed by the authorized signatory  
- [ ] Screenshot of submission is saved  
- [ ] Application reference number is recorded

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the TRIFED portal: https://trifed.tribal.gov.in  
- Take a screenshot of the confirmation page showing the application reference number  
- Store the reference number securely in the case file  
- Set a follow-up reminder for 15 days after submission  
- Save all communication and documents in a dedicated folder labeled with Case ID

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify the approval letter from TRIFED or State Nodal Department  
- [ ] Confirm the sanctioned amount matches the applied MSP and quantity of MFP  
- [ ] Ensure funds are disbursed to the SHG/VDVK bank account (not individual)  
- [ ] Initiate procurement of MFP as per the approved action plan  
- [ ] Begin value addition and marketing activities as per Van Dhan Vikas Karyakram guidelines  
- [ ] Maintain records of procurement, expenditure, and sales for utilization certificate  
- [ ] Submit utilization certificate and statement of account to TRIFED via the Nodal Agency  
- [ ] Coordinate with the District Implementing Unit for audit of scheme operations  
- [ ] Plan for reinvestment of profits into scaling up value addition activities  
- [ ] Ensure compliance with no-fee/charge/royalty rule on MFP processing and marketing  
- [ ] Link with Haat Bazaar Sanchika for last-mile market connectivity  
- [ ] Participate in training and capacity-building programs organized by TRIFED/State Nodal Department  
- [ ] Monitor and report progress monthly to the State Level Coordination and Monitoring Committee (SLCMC)
