# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is an Indian startup, MSME, or innovator
- [ ] Applicant is a legally registered entity in India
- [ ] Applicant is developing medical devices, in-vitro diagnostics, digital health solutions, or other MedTech products
- [ ] Applicant possesses a clear innovation or technological solution with potential for healthcare impact
- [ ] Applicant demonstrates readiness for prototype testing or clinical validation
- [ ] Preference may be given to solutions addressing unmet medical needs or aligned with national health programs

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation certificate
- PAN card
- ITR (last 2–3 years)
- GST registration
- Bank statements (last 6 months)
- Udyam registration (for MSMEs)

### Scheme-Specific Documents
- Covering letter indicating type of application
- Application in Form-40 with date, signature, and seal/stamp of Indian agent or manufacturer
- Name and address of authorized agent in India (with valid wholesale license)
- Names and address of manufacturer and factory premises
- Name of the drug(s) or medical device to be registered
- Number of sites involved in manufacturing
- Original Power of Attorney
- TR-6 Challan of fees paid
- Copy of import permission for new drug(s) in Form-45 or Form-45A
- Copy of valid wholesale or manufacturing license of the Indian agent
- Company's authorization letter for bearer
- Schedule D(I) and Schedule D(II) with undertaking
- Notarized copy of Plant Master File (PMF)
- Notarized copy of Drug Master File (DMF)
- Original notarized copy of manufacturing license, FSC, GMP, COPP (for finished products)

### Document Quality Check
- File size: Ensure documents are within portal limits (typically <10 MB per file)
- File naming: Use clear, consistent naming (e.g., "ApplicantName_DocumentType_Date.pdf")
- All documents must be legible, scanned in color if originally colored
- Signatures and seals must be visible and authentic
- Documents in English or accompanied by certified translation
- Notarized documents must have valid notary stamp and signature

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required for the MedTech Regulatory Sandbox. However, applicants must provide supporting documents including product description, technical specifications, preclinical data (if any), and team credentials. Verify with nodal officer if not mentioned, flag "verify with nodal officer."

### Application Form Filling Protocol
1. Access the designated CDSCO portal for online application submission  
2. Fill Form-40 completely with accurate details of applicant, agent, and manufacturer  
3. Ensure all dates are in DD-MM/YYYY format  
4. Attach seal/stamp of the Indian agent or manufacturer on Form-40  
5. Double-check the name and address of the authorized agent in India  
4. Upload all scheme-specific documents in the prescribed format (PDF preferred)  
5. Provide a clear, concise product description highlighting innovation and healthcare impact  
6. Include technical specifications and preclinical/clinical data (if available)  
7. Detail team credentials and expertise relevant to the MedTech innovation  
8. Declare readiness for prototype testing or clinical validation in the application  

### Internal Review Gate
- [ ] All application form fields completed accurately  
- [ ] All scheme-specific documents uploaded and legible  
- [ ] Signatures and seals present where required  
- [ ] Declarations signed and dated  
- [ ] Product description clearly outlines innovation and healthcare impact  
- [ ] Team credentials demonstrate capability to execute the project  
- [ ] No missing or ambiguous information in the submission

### Submission Protocol
- Submit application via the designated CDSCO portal  
- Take screenshot of confirmation page showing successful submission  
- Save application reference number immediately upon receipt  
- Set follow-up reminders for Day 25 and Day 35 if no acknowledgment received

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and securely store the approval letter/MoU from CDSCO  
- [ ] Verify sanctioned non-financial support details (regulatory guidance, accelerated review pathways, etc.)  
- [ ] Prepare utilization certificate documenting sandbox activities undertaken  
- [ ] Track progress reports and final outcomes as per MoU requirements  
- [ ] Coordinate with CDSCO for feedback and recommendations toward regulatory approval or commercialization  
- [ ] Ensure all sandbox activities remain within predefined scope and duration as agreed in MoU  
- [ ] Bear all costs related to product development, testing, trials, and prototyping (as per scheme caveats)  
- [ ] Retain intellectual property rights (CDSCO does not claim ownership)  
- [ ] Use sandbox outcomes advisory only; prepare for formal regulatory submission post-sandbox  
- [ ] Maintain confidentiality of submitted data as per CDSCO policy
