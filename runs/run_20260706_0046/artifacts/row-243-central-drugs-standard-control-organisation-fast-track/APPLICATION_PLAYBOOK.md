# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a manufacturer, importer, exporter, or authorized agent of drugs, biologics, medical devices, or cosmetics seeking registration, import licensing, or market authorization in India.
- [ ] Applicant complies with the Drugs and Cosmetics Act, 1940, and Rules 1945.
- [ ] Applicant submits required documentation via the SUGAM portal.
- [ ] Applicant adheres to Good Manufacturing Practices (GMP), Good Distribution Practices (GDP).
- [ ] Applicant provides valid wholesale/manufacturing licenses, product details, stability data, and undertakings as specified in CDSCO guidelines.
- [ ] Startups and MSMEs may avail relaxations in experience and turnover criteria under relevant government policies.

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation Certificate
- PAN Card
- Income Tax Returns (ITR)
- GST Registration
- Bank Statements (last 6 months)
- Udyam Registration (for MSMEs)

### Scheme-Specific Documents
- Covering Letter indicating type of application
- Application in Form-40 (for Registration Certificate) or Form 8/8A (for Import License)
- Original Power of Attorney
- TR-6 Challan of fees paid (1500 USD per site or equivalent in INR; 1000 USD per drug or equivalent)
- Copy of Import permission for new drug (Form-45 or Form-45A)
- Copy of Valid Wholesale License (20B/21C) or Manufacturing License of Indian agent
- Company’s authorization letter for bearer
- Schedule D (I) and (II) Undertaking
- Notarised copy of Plant Master File (PMF)
- Notarised copy of Drug Master File (DMF)
- Original Notarised Copy of Manufacturing Licence, FSC, GMP, COPP (for finished products)
- Attested/Appostilled copy of Product Registration Certificate (e.g., CFDA, EDQM)
- Original label/specimen label complying with Rule 96, indicating subject drug with pharmacopoeial specification, importer name & address, and Import License number

### Document Quality Check
- File size: Each document must be legible and not exceed 10 MB unless specified otherwise.
- File naming: Use clear, consistent naming (e.g., "ApplicantName_DocumentType_Date.pdf").
- All copies must be self-attested or notarized as required.
- Documents must be in English or accompanied by a certified translation.
- Signatures and seals must be visible and valid.

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not mentioned in evidence. Flag: **verify with nodal officer.**

### Application Form Filling Protocol
1. Access the SUGAM portal at https://sugam.cdsco.in.
2. Determine the correct application form (Form 40 for Registration Certificate, Form 8/8A for Import License) based on product type.
3. Fill all fields accurately; do not leave mandatory fields blank.
4. Upload documents in the specified order and format as per the checklist.
5. Ensure the TR-6 challan reflects the correct fee amount (1500 USD/site or 1000 USD/drug).
6. Verify that the Power of Attorney is original and authenticated.
7. Confirm that labels comply with Rule 96 of Drugs and Cosmetics Rules, 1945.
8. Double-check all entries before final submission.

### Internal Review Gate
- [ ] All application form fields completed.
- [ ] All scheme-specific documents attached and legible.
- [ ] TR-6 challan uploaded and fee amount correct.
- [ ] Power of Attorney is original and authenticated.
- [ ] Labels comply with Rule 96.
- [ ] Declarations and undertakings signed and sealed.
- [ ] No discrepancies in applicant name, address, or product details across documents.

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the SUGAM portal at https://sugam.cdsco.in.
- Take a screenshot of the confirmation page showing the application reference number.
- Store the reference number securely in the case file.
- Set follow-up reminders for Day 25 and Day 35 to check application status.
