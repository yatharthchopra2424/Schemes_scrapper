# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is an individual aged 18 to 45 years  
- [ ] Applicant is a resident of Madhya Pradesh  
- [ ] Applicant possesses a viable business idea or early-stage startup  
- [ ] Applicant is a first-time entrepreneur or has not previously availed benefits under similar state startup schemes  
- [ ] Business is registered or in the process of registration under relevant Indian laws (e.g., Private Limited, LLP, Partnership, Sole Proprietorship)  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Identity Proof (Aadhaar Card, Voter ID, PAN)  
- Address Proof (Electricity Bill, Rent Agreement, Aadhaar)  
- PAN Card  
- ITR (Income Tax Returns) for last 2 years (if applicable)  
- GST Registration Certificate (if applicable)  
- Bank Statements (last 6 months)  
- Udyam Registration Certificate (if applicable)  

### Scheme-Specific Documents
- Educational Qualification Certificates  
- Business Plan / Project Report  
- Bank Account Details (Cancelled Cheque or Passbook Copy)  
- Certificate of Incorporation / Registration (if applicable)  
- Partnership Deed or LLP Agreement (if applicable)  
- Passport-sized Photographs  
- Declaration of No Prior Benefit from Similar State Scheme  
- Proof of Residency in Madhya Pradesh  

### Document Quality Check
- All documents must be clear, legible scans (PDF or JPEG)  
- File size should not exceed 5 MB per document  
- File names must match the document type (e.g., "Aadhaar.pdf", "Business_Plan.pdf")  
- Self-attested copies required for all documents  
- Documents must be in Hindi or English; if in another language, certified translation required  
- Photographs must be recent (within last 6 months), passport size, with white background

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Business Plan / Project Report is required as per the scheme's required documents. Standard sections should include:  
- Executive Summary  
- Business Model and Value Proposition  
- Market Analysis and Target Audience  
- Product/Service Description  
- Technology and Innovation Aspects  
- Marketing and Sales Strategy  
- Operational Plan  
- Financial Projections (3–5 years)  
- Funding Requirements and Utilization Plan  
- Milestones and Timeline  
- Team Background  
- Risk Analysis and Mitigation  

### Application Form Filling Protocol
1. Access the MP e-District portal at https://mpedistrict.gov.in  
2. Register as a new user using valid email and mobile number  
3. Log in with credentials and navigate to 'Services'  
4. Search and select 'MP Startup Policy & Yuva Udyami Yojana' from the service list  
5. Fill all mandatory fields in the online form accurately — do not leave any blank  
6. Upload documents in the specified format (PDF/JPEG, <5 MB each)  
7. Ensure the Business Plan/Project Report is uploaded under the designated section  
8. Double-check all entered details (name, DOB, address, business info) before submission  
9. Pay any applicable processing fee via the portal’s payment gateway  
10. Submit the application and save the acknowledgment slip with Application Number  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] All universal and scheme-specific documents collected and quality-checked  
- [ ] Application form filled completely with accurate information  
- [ ] Business Plan/Project Report uploaded and reviewed for completeness  
- [ ] Declarations (e.g., no prior benefit) signed and attached  
- [ ] Photographs meet specifications (size, background, recency)  
- [ ] Application number noted and submission screenshot saved  
- [ ] Follow-up reminders set for Day 18 and Day 30

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the MP e-District portal  
- Take a screenshot of the confirmation page showing the Application Number and timestamp  
- Store the Application Number securely in the case file  
- Set calendar reminders for follow-up on Day 25 and Day 35  
- Monitor application status weekly via the portal using the Application Number

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the approval letter from the portal or via email  
- [ ] Confirm the sanctioned amount and disbursement schedule (tranche-based on milestones)  
- [ ] Set up utilization tracking mechanism for funds received  
- [ ] Prepare and submit Utilization Certificates as per milestone completion  
- [ ] Ensure startup remains operational for minimum 2 years post-funding to avoid clawback  
- [ ] Coordinate with MPSAPS for access to non-financial benefits (incubation, mentorship, market linkage)  
- [ ] Track and document success fee invoice for consulting services upon fund disbursement  
- [ ] Maintain records for audit and compliance (documents, correspondence, financials) for minimum 5 years
