2. **Risk-Adjusted Pricing**: Success fees reflect moderate risk due to rolling application basis and dependency on infrastructure availability and performance evaluations; processing time is not explicitly stated but implied to be variable based on review cycles.
3. **Market Competitiveness**: Rates benchmarked against similar state-level incubation schemes in India, adjusted for West Bengal-specific ecosystem maturity.
4. **Scheme-Specific Note**: The Bengal Silicon Valley Startup Hub offers non-financial support (infrastructure, mentorship, shared facilities) without specified direct financial outlay per beneficiary.
