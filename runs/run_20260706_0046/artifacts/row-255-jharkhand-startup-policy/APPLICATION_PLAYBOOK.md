# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Startup is registered in Jharkhand OR willing to establish operations in Jharkhand  
- [ ] Working on innovative ideas, products, or services  
- [ ] Potential for scalability and employment generation  
- [ ] Entity type: Startup (as defined under Jharkhand Startup Policy-2021)  
- [ ] Applicant must be a legal entity (private limited company, LLP, partnership firm, or sole proprietorship) registered under relevant Indian statutes  
- [ ] Business must be operational or in pre-revenue stage with a demonstrable prototype or MVP  
- [ ] No prior blacklisting by any government agency  

*Sources: Jharkhand Startup Policy-2021 (Downloads section, Jharkhand State Portal); Eligibility criteria from KEY FACTS block*

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN of the entity  
- GST registration certificate (if applicable)  
- Bank account details (cancelled cheque or bank statement)  
- Udyam Registration (MSME)  
- ITR of the last 2 financial years (if applicable)  
- Authorized signatory details (board resolution or authorization letter)  

### Scheme-Specific Documents
- Business plan or pitch deck  
- Proof of innovation or prototype (photos, videos, demo access, IP filings if any)  
- Detailed project report outlining innovation, scalability, and employment potential  

### Document Quality Check
- All documents must be legible scanned copies (PDF format preferred)  
- File size per document: < 5 MB  
- File names must match document type (e.g., "Certificate_of_Incorporation.pdf")  
- All certificates must be valid and not expired  
- Documents in regional languages must be accompanied by certified Hindi/English translation  
- Authorized signatory details must match PAN and bank account holders

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A detailed project report (DPR) is **required** as part of the scheme-specific documents. It must include:  
- Executive summary  
- Problem statement and innovative solution  
- Technology or methodology used  
- Market analysis and scalability potential  
- Employment generation plan  
- Financial projections (for 3 years)  
- Prototype validation details (if applicable)  
- Roadmap for utilization of policy benefits (incubation, mentorship, funding access)  

*Sources: Required Documents from KEY FACTS (Business plan or pitch deck, Proof of innovation); Application Process step 3*

### Application Form Filling Protocol
1. Access the Jharkhand Startup Policy-2021 document from the Downloads section of the Jharkhand State Portal (https://jharkhand.gov.in)  
2. Read eligibility and guidelines thoroughly before filling any form  
3. Fill all fields in the application form accurately; leave no mandatory field blank  
4. Ensure consistency of entity name, PAN, and address across all documents and the form  
5. Attach all required documents in the specified order and format (PDF, <5 MB each)  
6. Declaration by authorized signatory must be signed and dated  
7. Do not exaggerate claims about innovation or scalability; ensure all statements are verifiable  
8. Preview the entire application before final submission to avoid errors  

*Sources: Application Process from KEY FACTS; Jharkhand State Portal User Manual (jharkhandstateportalusermanual.pdf) for portal navigation guidance*

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] Universal and scheme-specific documents collected and quality-checked  
- [ ] Application form filled completely with accurate information  
- [ ] Project report/pitch deck included and reviewed for clarity and completeness  
- [ ] Declarations signed by authorized signatory  
- [ ] File names and formats compliant with quality check standards  
- [ ] Final PDF application package assembled and ready for submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the completed application via the designated channel as specified in the Jharkhand Startup Policy-2021 (typically through a nodal officer or online portal linked from the policy document)  
- Take a screenshot of the submission confirmation page or receipt  
- Store the application reference number (if generated) in the case file  
- Save a copy of the submitted application (PDF) with naming convention: `CaseID_JharkhandStartupPolicy_Application.pdf`  
- Set follow-up reminders for Day 25 and Day 35  

*Sources: Application Process step 4 from KEY FACTS; Jharkhand State Portal navigation guidance*

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify approval letter sanctioning benefits under Jharkhand Startup Policy-2021  
- [ ] Confirm sanctioned benefits (access to incubation, mentorship, networking, prototype support, regulatory facilitation)  
- [ ] Coordinate with nodal officer for benefit disbursement or access provision  
- [ ] Maintain utilization records for all availed benefits (e.g., attendance at mentorship sessions, incubator usage logs)  
- [ ] Prepare and submit utilization certificate if required for continued support  
- [ ] Track invoice for success fee as per engagement agreement  
- [ ] Advise client on compliance: maintain registration and operational presence in Jharkhand to retain eligibility  

*Sources: Benefits and Key Caveats from KEY FACTS (access to incubation centers, mentorship, networking, prototype development, regulatory facilitation; continued support subject to Jharkhand presence)*
