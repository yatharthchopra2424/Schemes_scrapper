# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Startup is incorporated as a Private Limited Company, Registered Partnership Firm, Limited Liability Partnership, or Cooperative Society  
- [ ] Period of existence and operations does not exceed 10 years from date of incorporation (20 years for DeepTech)  
- [ ] Annual turnover does not exceed INR 200 crore in any financial year since incorporation (INR 300 crore for DeepTech)  
- [ ] Entity is not formed by splitting up or reconstructing an existing business  
- [ ] Entity works towards innovation, development, or improvement of products/services or has a scalable business model with high potential for wealth and employment generation  
- [ ] Startup must obtain DPIIT recognition via the Startup India portal before applying to the Innovation Week Challenge  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN of the entity  
- GST registration certificate (if applicable)  
- Bank statements (last 6 months)  
- Udyam Registration (if applicable)  
- Income Tax Returns (last 3 years)  

### Scheme-Specific Documents
- Pitch deck or business description  
- Authorization letter from authorized signatory  
- Details of funding received (if any)  

### Document Quality Check
- All documents must be in PDF format  
- File size must not exceed 5 MB per document  
- File names must match the document type (e.g., "Incorporation_Certificate.pdf")  
- All information must match across documents (e.g., company name, PAN, incorporation date)  
- Documents must be legible and certified where required (e.g., audited financials)  
- Documents must be in English or accompanied by a certified translation

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for the Innovation Week Challenge. A pitch deck or business description is sufficient. If a detailed project report is requested for a specific sub-challenge, verify with the nodal officer.

### Application Form Filling Protocol
1. Register on the Startup India portal (startupindia.gov.in) using a valid email and mobile number  
2. Complete the DPIIT recognition application under the 'Get Recognised' section  
3. Navigate to the Innovation Week Challenge or specific program page  
4. Fill in all startup details accurately (name, incorporation date, PAN, address)  
5. Provide a clear innovation description highlighting scalability, employment potential, and wealth creation  
6. Upload documents in the prescribed format and size limits  
7. Review all entries before submission to avoid errors  
8. Submit the application and note the application reference number  

### Internal Review Gate
- [ ] All application fields are complete and accurate  
- [ ] Required documents are uploaded and meet quality standards  
- [ ] Authorization letter is signed by an authorized signatory  
- [ ] Pitch deck clearly outlines innovation, scalability, and impact  
- [ ] Declarations are signed and dated  
- [ ] Application reference number is saved and shared with the client  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the confirmation page after submission  
- Store the application reference number securely  
- Set a follow-up reminder for 15 days post-submission  
- Monitor the dashboard on startupindia.gov.in for status updates

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and save the approval letter or selection notification  
- [ ] Verify sanctioned benefits (e.g., cash prize amount, mentorship access, investor connect eligibility)  
- [ ] Utilize handholding support and networking opportunities as offered  
- [ ] Prepare utilization certificate if financial support is awarded  
- [ ] Track invoice for success fee as per consultancy agreement  
- [ ] Explore linkage to further schemes such as SISFS, Fund of Funds, or Credit Guarantee Scheme  
- [ ] Ensure compliance with any post-approval reporting requirements
