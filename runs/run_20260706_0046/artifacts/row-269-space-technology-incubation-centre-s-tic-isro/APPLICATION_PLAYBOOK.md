## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A **Detailed Project Report (DPR) or detailed project proposal is required** for the S-TIC application.  

**Standard Sections to Include**:  
- Executive Summary  
- Problem Statement (space technology challenge being addressed)  
- Proposed Solution / Innovation  
- Technology Approach and Methodology  
- Proof of Concept / Prototype Details (if available)  
- Team Qualifications and Roles  
- Intellectual Property Status (existing and planned)  
- Implementation Plan and Timeline  
- Resource Requirements (mentorship, infrastructure access needed from ISRO)  
- Potential Applications and Impact (aligned with ISRO’s mission and national space program)  
- Collaboration and Commercialization Strategy  
- Risk Assessment and Mitigation Plan  
- Budget (if seeking external funding; note: S-TIC does not provide direct grants)  

> **Note**: While a formal DPR is not mandated, a comprehensive project proposal covering the above is essential for selection. Verify specific format preferences with the nodal officer if submitting via a designated incubation centre.

### Application Form Filling Protocol
Follow these 8 critical rules when filling the application via the ISRO S-TIC portal:  
1. **Access the correct portal**: Use only https://www.isro.gov.in/s-tic — avoid third-party links.  
2. **Register accurately**: Use official email and mobile number; verify OTP promptly.  
3. **Complete all mandatory fields**: Incomplete applications are rejected at screening.  
4. **Align with ISRO priorities**: Explicitly link your project to domains like satellite tech, remote sensing, navigation, or space applications.  
5. **Be concise and technical**: Use clear language; avoid fluff. Highlight innovation and feasibility.  
6. **Upload documents as per specs**: PDF only, max 5 MB per file, named correctly.  
7. **Sign declarations digitally**: Use DSC or e-sign where required; ensure declaration of originality is signed.  
8. **Review before submission**: Preview the entire form; confirm no errors in project details, team info, or contact data.  

> **Portal Note**: The ISRO S-TIC portal may redirect to a designated incubation centre’s application interface. Confirm the submission path during registration.
