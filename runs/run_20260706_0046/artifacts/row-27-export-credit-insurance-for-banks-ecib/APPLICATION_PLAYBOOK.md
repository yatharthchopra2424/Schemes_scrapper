# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a bank or financial institution in India
- [ ] Bank extends pre-shipment and/or post-shipment credit to exporters
- [ ] Exporter is an Indian entity engaged in export of goods or services
- [ ] Transaction involves an overseas buyer
- [ ] Credit facility is for a bonafide export transaction as per RBI guidelines
- [ ] Bank seeks insurance cover for specific export credit facilities
- [ ] Bank submits details of exporter, overseas buyer, nature of goods/services, value, and tenure of credit
- [ ] Bank approaches ECGC with request for ECIB cover

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Bank incorporation certificate
- PAN card of the bank
- Bank’s audited financial statements (last 2 years)
- GST registration certificate (if applicable)
- Bank statements (last 6 months)
- Udyam registration (if applicable for MSME-focused lending)
- Board resolution authorizing the application for ECIB cover

### Scheme-Specific Documents
- Loan sanction letter to the exporter
- Export order or contract between exporter and overseas buyer
- Invoice and shipping documents (bill of lading, airway bill, etc.)
- Buyer’s creditworthiness details (credit report, financial statements, etc.)
- Bank’s due diligence report on the exporter and transaction
- Completed ECIB policy application form
- Details of security offered for the loan
- RBI approval documents (if applicable for specific transactions or countries)

### Document Quality Check
- All documents must be legible and in PDF format
- File size for each document should not exceed 5 MB
- Document names must match the checklist (e.g., "Loan_Sanction_Letter.pdf")
- All certificates must be valid and not expired
- Bank statements must show the account holder name matching the bank’s name
- Declarations must be signed and stamped by authorized signatory
- Documents must be in English or accompanied by certified translation

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for ECIB scheme. The application is based on transaction-specific documents rather than a project report. **Verify with nodal officer if any additional explanatory note is needed for complex transactions.**

### Application Form Filling Protocol
1. Access the ECGC client portal at https://www.ecgcltd.in using registered credentials
2. Navigate to the ECIB section and select “Apply for Cover”
3. Fill in bank details (name, address, PAN, GSTIN) exactly as per incorporation documents
4. Enter exporter details (name, address, IEC code, Udyam/MSME registration if applicable)
5. Provide overseas buyer details (name, address, country, creditworthiness summary)
6. Specify transaction details: nature of goods/services, invoice value, currency, tenor of credit (pre-shipment/post-shipment)
7. Indicate loan amount sought and requested insurance cover percentage (up to 90%)
8. Upload all required documents in the specified sections
9. Declare that the transaction is bonafide and as per RBI guidelines
10. Confirm that exhaustive recovery efforts will be undertaken in case of default before claim submission
11. Review all entries for accuracy before final submission
12. Submit the application and save the acknowledgment/reference number

### Internal Review Gate
- [ ] All fields in the application form are complete and accurate
- [ ] All scheme-specific and universal documents are attached and legible
- [ ] Declarations regarding bonafide transaction and recovery efforts are signed
- [ ] Reference number from portal submission is recorded
- [ ] Follow-up reminder set for 7 days post-submission
- [ ] Application matches the eligibility criteria verified in Stage 1

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the ECGC portal at https://www.ecgcltd.in
- Immediately after submission, take a screenshot of the confirmation page showing the application reference number and timestamp
- Store the screenshot and reference number in the case folder with naming convention: `ECIB_Submission_[Case ID]_[YYYYMMDD].png`
- Set an internal follow-up reminder for 7 days after submission to check application status
- If no update received, initiate follow-up via email or helpline

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify the approval letter/policy document from ECGC
- [ ] Confirm the sanctioned insurance cover amount and percentage (up to 90% of loan amount)
- [ ] Ensure the policy is issued and active before loan disbursement to exporter
- [ ] Monitor the loan disbursement under the covered facility
- [ ] In case of default, ensure bank exhausts recovery efforts before filing claim
- [ ] Guide client on claim submission process post-default (if applicable)
- [ ] Utilization certificate not applicable (insurance cover, not grant)
- [ ] Success fee invoice to be raised upon successful policy issuance or claim settlement (as per engagement letter)
