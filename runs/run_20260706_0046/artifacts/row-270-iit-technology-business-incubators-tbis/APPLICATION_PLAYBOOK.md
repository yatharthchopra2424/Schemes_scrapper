# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Technology-based startup or entrepreneur seeking incubation support at IIT Bombay's Technology Business Incubator (TBI)
- [ ] Innovation quotient demonstrated in business idea or prototype
- [ ] Scalability potential of the technology solution
- [ ] Alignment with IIT Bombay's focus areas (as per TBI program)
- [ ] Proof of concept or prototype details available
- [ ] Business plan or project proposal prepared
- [ ] Team member profiles and CVs compiled
- [ ] Incorporation documents ready (if applicable)
- [ ] IP details or patent filings documented (if any)
- [ ] Funding details or financial projections prepared

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation certificate (if applicable)
- PAN card of business/entity
- Bank statements (last 6 months)
- Udyam Registration (for MSMEs)
- GST registration certificate (if applicable)
- ITR of promoters/business (last 2 years, if applicable)

### Scheme-Specific Documents
- Business plan or project proposal
- Team member profiles and CVs
- Proof of concept or prototype details
- Incorporation documents (if applicable)
- IP details or patent filings (if any)
- Funding details or financial projections

### Document Quality Check
- All documents must be legible and in PDF format (unless specified otherwise)
- File names must match document type (e.g., "Business_Plan.pdf", "Team_CVs.pdf")
- File size should not exceed 10 MB per document
- Documents must be in English or Hindi; if in another language, certified translation required
- All certificates must be valid and not expired
- Financial projections must be realistic and based on verifiable assumptions

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A formal Detailed Project Report (DPR) is not explicitly required for this scheme. However, a comprehensive business plan or project proposal is mandatory. If further detailing is needed, verify with the nodal officer at IIT Bombay TBI.

### Application Form Filling Protocol
1. Access the application portal at https://www.iitb.ac.in/incubator  
2. Review eligibility and program details thoroughly before starting the form  
3. Fill all sections accurately; do not leave any mandatory field blank  
4. Upload documents in the specified format (PDF preferred) and ensure file names are clear  
5. Describe the innovation clearly, highlighting technology quotient and scalability  
6. Provide realistic financial projections based on verifiable assumptions  
7. Ensure team CVs highlight relevant expertise and roles  
8. Double-check all entries before final submission to avoid errors  

### Internal Review Gate
- [ ] All application form fields completed accurately  
- [ ] All scheme-specific documents attached and clearly labeled  
- [ ] Universal documents (PAN, bank statements, etc.) included  
- [ ] Declarations and undertakings signed where required  
- [ ] Business plan clearly outlines innovation, market potential, and implementation roadmap  
- [ ] Financial projections are realistic and well-justified  
- [ ] No spelling or formatting errors in the application  
- [ ] Application submitted within the client’s target timeline

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the successful submission confirmation page showing the application reference number  
- Store the reference number securely in the case file  
- Set a follow-up reminder for 15 days after submission to check application status  
- Save all uploaded documents in a dedicated folder for the case

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and review the approval/offer letter from IIT Bombay TBI  
- [ ] Verify the sanctioned support (e.g., access to infrastructure, mentorship, funding assistance)  
- [ ] Complete onboarding formalities as specified in the offer letter  
- [ ] Utilize incubation benefits (office space, lab facilities, mentorship, networking)  
- [ ] Prepare utilization certificate if required for any grant component  
- [ ] Track milestone achievements for continued support  
- [ ] Invoice success fee as per consultancy agreement (if applicable)  
- [ ] Maintain records of all interactions and benefits availed for audit purposes
