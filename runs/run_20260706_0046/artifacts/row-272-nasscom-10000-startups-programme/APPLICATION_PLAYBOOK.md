## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The NASSCOM 10000 Startups Programme does not mandate a Detailed Project Report (DPR). Instead, applicants submit a pitch deck and product description as part of the online application.  
**Action**: Verify with nodal officer if any specific format is preferred for the pitch deck, though no such requirement is stated in the evidence.

### Application Form Filling Protocol
1. Access the official portal: [https://10000startups.com](https://10000startups.com) and navigate to the 'Apply' or 'Register' section.  
2. Create an account or log in using a valid email ID and mobile number.  
3. Fill in startup details: legal name, date of incorporation, registered address, PAN, GSTIN (if applicable), and Udyam number.  
4. Provide founder information: names, roles, educational background, work experience, and contact details for all promoters.  
5. Describe the product/service: clearly state the problem, solution, technology stack (e.g., AI, IoT, blockchain), and current development stage (idea, prototype, MVP, early revenue).  
6. Outline the business model: revenue streams, target customers, go-to-market strategy, and scalability potential.  
7. Share traction metrics: user numbers, revenue (if any), partnerships, pilot results, or prototype test results.  
8. Disclose any existing funding: amount, source (angel, VC, self-funded), and use of funds.  
9. Upload all required documents in PDF format, ensuring file names are descriptive and under 10 MB each.  
10. Review all entries for accuracy and completeness before final submission — no edits are allowed after submission.  
11. Submit the application and save the confirmation screen or reference number.  
12. Monitor email for communication from NASSCOM regarding interview/pitch session invites.
