## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The initiative does not mandate a Detailed Project Report (DPR). Instead, a pitch deck or business plan is required as part of the application.  
**Action**: Verify with nodal officer if any additional project documentation is sought during shortlisting, though not mentioned in the standard process.

### Application Form Filling Protocol
1. Access the application portal at [https://ciie.co](https://ciie.co) and navigate to the Bharat Inclusion Initiative section.  
2. Create an account or log in using a valid email and mobile number.  
3. Fill in all mandatory fields accurately; incomplete forms will not be considered.  
4. Ensure the startup name, registration number, and PAN match exactly across all documents and the form.  
5. Clearly articulate the innovative nature of the product/service/business model in the designated sections.  
6. Explicitly define the target underserved and low-income population and how the solution addresses their specific needs.  
7. Highlight traction metrics (users, revenue, pilots, partnerships) if available; if pre-revenue, emphasize validation steps (e.g., surveys, prototypes, LOIs).  
8. Upload all scheme-specific documents in PDF format, adhering to the naming convention and size limits specified in the Document Quality Check.  
9. Review the entire application before submission; no edits are possible after final submit.  
10. Submit only after confirming all declarations are read and accepted.
