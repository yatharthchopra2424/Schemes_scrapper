# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] The startup is incorporated as a Private Limited Company, Registered Partnership Firm, Limited Liability Partnership, or Cooperative Society.
- [ ] The startup is DPIIT-recognised (must have valid DPIIT recognition certificate).
- [ ] The startup has a technology-enabled business idea.
- [ ] The startup is working towards innovation, development, or improvement of products, processes, or services.
- [ ] The startup has a scalable business model with high potential for wealth and employment generation.
- [ ] The startup was not formed by splitting up or reconstructing an existing business.
- [ ] The startup’s period of existence and operations does not exceed 10 years from the date of incorporation (or 20 years for DeepTech startups).
- [ ] The startup’s annual turnover does not exceed Rs. 200 crore in any financial year since incorporation (or Rs. 300 crore for DeepTech startups).

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration
- PAN of the entity
- GST registration certificate
- Bank statements (last 6 months)
- Udyam Registration (if applicable)
- Income Tax Returns (ITR) for the last 2–3 financial years
- Audited financial statements (if applicable)

### Scheme-Specific Documents
- Pitch deck or business description
- Details of funding received (if any)
- Authorized signatory authorization letter

### Document Quality Check
- All documents must be in PDF format (max 5 MB per file unless otherwise specified)
- File names must match the document type (e.g., "Certificate_of_Incorporation.pdf")
- All certificates must be valid and not expired
- Documents must be in English or accompanied by a certified translation
- Authorized signatory letter must be on company letterhead and signed by a director or authorized signatory
- PAN details must match the entity name in incorporation documents

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The SIDBI Startup Mitra portal does not mandate a Detailed Project Report (DPR). However, a pitch deck or business description is required as part of the application. If further details are needed by incubation partners post-shortlisting, verify with the nodal officer.

### Application Form Filling Protocol
1. Visit the Startup India portal at https://www.startupindia.gov.in/  
2. Navigate to the Startup Mitra – Incubation Portal section  
3. Register or log in to your Startup India profile (BHASKAR ID required)  
4. Complete the application form with accurate details about your startup, including innovation, business model, and team  
5. Upload required documents: Certificate of Incorporation, PAN, and pitch deck  
6. Ensure all fields marked as mandatory are filled  
7. Double-check that uploaded files are legible and within size limits  
8. Review the application thoroughly before final submission  
9. Submit the application and save the confirmation/reference number  
10. Monitor your dashboard for updates from incubation partners  

### Internal Review Gate
- [ ] All application form fields are complete and accurate  
- [ ] Required documents (Certificate of Incorporation, PAN, pitch deck) are attached  
- [ ] Authorized signatory authorization letter is signed and on letterhead  
- [ ] DPIIT recognition status is verified and valid  
- [ ] No contradictory information in business description vs. incorporation documents  
- [ ] File sizes are within limits and formats are correct (PDF)  
- [ ] Application has been reviewed for spelling and clarity  
- [ ] Submission screenshot and reference number have been recorded

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the Startup India portal as per the protocol above  
- Take a screenshot of the confirmation page showing the application reference number  
- Store the reference number securely in the case file  
- Set a follow-up reminder for 7 days after submission to check status  
- Mark the case as “Submitted” in the tracker

### Escalation Path
- Level 1: Startup India Portal Helpdesk (via the “Contact Us” page on https://www.startupindia.gov.in)  
- Level 2: Nodal Officer – SIDBI Startup Mitra Scheme (details to be confirmed via portal; otherwise [TO BE FILLED BY CONSULTANT])  
- Level 3: RTI filing if no response within statutory SLA (typically 30 days for government schemes)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and save the approval/intimation letter from the incubation partner or SIDBI  
- [ ] Verify the sanctioned benefits (e.g., admission to incubation program, mentorship access)  
- [ ] If applicable, prepare and submit utilization certificates as required by the incubation partner  
- [ ] Track milestone progress and maintain records for future renewals or reapplications  
- [ ] Coordinate with the client to invoice success fee as per engagement agreement  
- [ ] Advise client on leveraging the incubation support to apply for linked schemes (SISFS, FFS, CGSS)  
- [ ] Ensure client maintains DPIIT recognition to continue accessing benefits
