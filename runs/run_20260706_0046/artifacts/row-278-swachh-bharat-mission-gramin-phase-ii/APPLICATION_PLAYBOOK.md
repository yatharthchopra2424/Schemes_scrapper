# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a rural household, Gram Panchayat, village, self-help group (SHG), NGO, or Corporate Social Responsibility (CSR) entity including Central Public Sector Enterprises (CPSEs)  
- [ ] Project is located in a rural area (as defined by the Department of Drinking Water and Sanitation)  
- [ ] Project falls under eligible SBM-G Phase II activities: Individual Household Latrines (IHHL), Community Sanitary Complexes (CSC), Solid and Liquid Waste Management (SWM/LWM), or GOBARdhan projects  
- [ ] For GOBARdhan projects: Application submitted before 2024–25 deadline for financial assistance  
- [ ] Project proposal includes scope, location, and beneficiaries  
- [ ] Land availability proof or Gram Panchayat resolution for land use is available  
- [ ] Cost estimate and bill of quantities prepared  
- [ ] Implementation plan and timeline defined  
- [ ] Monitoring and operation & maintenance (O&M) plan in place  
- [ ] Bank account details of implementing agency ready  
- [ ] Registration certificate of NGO/CSR entity (if applicable)  
- [ ] Gram Panchayat resolution endorsing the project  
- [ ] Environmental and social safeguards compliance (if required)  
- [ ] Project adheres to guidelines issued by the Department of Drinking Water and Sanitation under Ministry of Jal Shakti  
- [ ] For CSR/CPSE applicants: Compliance with Section 135 of the Companies Act and CSR Guidelines  

*Sources: Scheme Key Facts (Eligibility, Required Documents, Application Process, Key Caveats); Portal: https://swachhbharatmission.gov.in/*

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/Registration Certificate (for NGOs, SHGs, CSR entities, CPSEs)  
- PAN Card of the applicant entity  
- Latest Income Tax Return (ITR)  
- GST Registration Certificate (if applicable)  
- Bank statements (last 6 months)  
- Udyam Registration (for MSMEs, if applicable)  
- Aadhaar and PAN of authorized signatory  

### Scheme-Specific Documents
- Project proposal detailing scope, location, and beneficiaries  
- Land availability proof or Gram Panchayat resolution for land use  
- Cost estimate and bill of quantities  
- Implementation plan and timeline  
- Monitoring and operation & maintenance (O&M) plan  
- Bank account details of implementing agency  
- Registration certificate of NGO/CSR entity (if applicable)  
- Gram Panchayat resolution endorsing the project  
- Environmental and social safeguards compliance (if required)  

### Document Quality Check
- All documents are legible, scanned in PDF format (max file size: 5 MB per document)  
- File names follow format: `SchemeName_DocumentType_ApplicantName_Date.pdf` (e.g., `SBMG_PhaseII_ProjectProposal_ABC_NGO_20240515.pdf`)  
- Names on documents match exactly with the applicant’s registration details  
- Certificates are valid and not expired (where applicable)  
- Hindi or English language; if in regional language, certified translation attached  
- All declarations are signed and stamped by authorized signatory  
- Bank account details include account holder name, account number, IFSC, and bank branch

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. Based on the scheme’s required documents, the DPR must include:  
- Executive summary  
- Project background and objectives  
- Scope of work (IHHL, CSC, SWM, LWM, or GOBARdhan)  
- Location details and beneficiary profile  
- Land availability and site plan  
- Technical design and specifications  
- Cost estimate and bill of quantities  
- Implementation schedule and timeline  
- Operation and maintenance (O&M) plan  
- Monitoring and evaluation framework  
- Financial plan and funding sources  
- Risk assessment and mitigation measures  
- Environmental and social impact assessment (if applicable)  
- Annexures: Land documents, approvals, quotes, etc.  

*Sources: Scheme Key Facts (Required Documents); Portal: https://swachhbharatmission.gov.in/*

### Application Form Filling Protocol
1. Access the official portal: https://swachhbharatmission.gov.in/  
2. Navigate to the “Application Form” section under “Important Links” or “Know your Swachh Bharat data (MIS)”  
3. Select the correct scheme: **Swachh Bharat Mission – Gramin Phase II**  
4. Fill in applicant details exactly as per registration documents (name, PAN, address, contact)  
5. Select project type: IHHL, CSC, SWM, LWM, or GOBARdhan  
6. Enter project location (state, district, block, village, Gram Panchayat) with pin code  
7. Upload all scheme-specific documents in the prescribed format and size  
8. Declare compliance with SBM-G Phase II guidelines and rural area requirement  
9. For CSR/CPSE applicants: Confirm adherence to Section 135 of Companies Act and CSR Guidelines  
10. Review all entries before final submission; ensure no blank mandatory fields  
11. Save draft periodically to avoid data loss  
12. Submit only after internal review gate clearance  

*Sources: Scheme Key Facts (Application Process); Portal: https://swachhbharatmission.gov.in/ (links: Application Form For IHHL, Dashboard, GOBARdhan)*

### Internal Review Gate
- [ ] All applicant details match registration documents  
- [ ] Project type correctly selected (IHHL, CSC, SWM, LWM, GOBARdhan)  
- [ ] Project location is rural and accurately specified  
- [ ] All scheme-specific documents uploaded and legible  
- [ ] File sizes within limits (≤5 MB per file)  
- [ ] Document names follow naming convention  
- [ ] Cost estimate and bill of quantities are complete and itemized  
- [ ] Implementation timeline is realistic and phased  
- [ ] O&M plan includes responsibilities, duration (min. 10 years for CSR), and funding  
- [ ] Bank account details are correct and verified  
- [ ] Declarations are signed and dated  
- [ ] For GOBARdhan: Application submitted before 2024–25 deadline  
- [ ] For CSR/CPSE: CSR compliance statement included  
- [ ] No contradictory information across documents  
- [ ] Reference number noted after submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the Swachh Bharat Mission Gramin portal: https://swachhbharatmission.gov.in/  
- Take a screenshot of the confirmation page showing the application reference number and timestamp  
- Store the reference number in the case file and set up automated reminders for follow-up  
- Save all submitted documents and screenshots in the client’s digital folder with backup  
- Note the expected timeline for appraisal (Block/District level officials) as per guidelines

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from District Water and Sanitation Committee or State SBM-G cell  
- [ ] Confirm sanctioned amount matches approved project cost and scheme limits (e.g., up to Rs. 50 Lakh per district for GOBARdhan model projects)  
- [ ] Verify fund release schedule is linked to physical progress milestones  
- [ ] Ensure utilization certificate (UC) format is understood and prepared in advance  
- [ ] Plan for installation of Swachhata Green Leaf Rating or other IEC materials if applicable  
- [ ] Track physical progress against implementation timeline  
- [ ] Prepare and submit utilization certificates (UCs) as per installment release conditions  
- [ ] Monitor operation and maintenance (O&M) compliance post-implementation  
- [ ] Report project completion via Swachh Survekshan Grameen MIS for ODF Plus status assessment (Aspiring, Rising, Model)  
- [ ] Coordinate with Gram Panchayat or implementing agency for long-term sustainability  
- [ ] Submit final project completion report and request closure  

*Sources: Scheme Key Facts (Application Process, Benefits, Objectives); Portal: https://swachhbharatmission.gov.in/*
