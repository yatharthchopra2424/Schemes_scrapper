# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Exporter of APEDA-scheduled products  
- [ ] Valid Registration-cum-Membership Certificate (RCMC) from APEDA  
- [ ] Valid Import Export Code (IEC) from DGFT  
- [ ] Exported product and destination covered under current TMA notification  
- [ ] Claim submitted within stipulated time frame post-shipment as per respective TMA notification  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Import Export Code (IEC)  
- PAN Card  
- GST Registration Certificate  
- Bank Statements (last 6 months)  
- Udyam Registration (if MSME)  
- Audited Financial Statements / ITR (last 2 years)  

### Scheme-Specific Documents
- Registration-cum-Membership Certificate (RCMC) from APEDA  
- Shipping Bills  
- Proof of payment of international freight  
- Proof of payment of marketing expenses  
- Bank details for reimbursement  
- Self-declaration form as per TMA guidelines  

### Document Quality Check
- All documents must be legible, scanned in PDF format  
- File size not exceeding 5 MB per document  
- Name on documents must match IEC/RCMC details exactly  
- Self-declaration must be signed and stamped  
- Documents in English or accompanied by certified translation  

### Client Communication Template

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for TMA claims. Verify with nodal officer if any additional documentation is sought during scrutiny.  

### Application Form Filling Protocol
1. Ensure IEC and RCMC numbers are entered exactly as issued  
2. Select the correct product category and destination country as per current TMA notification  
3. Enter FOB value and quantity accurately from shipping bills  
4. Attach all documents in the order specified in the checklist  
5. Double-check bank account details for reimbursement  
6. Self-declaration must be signed, dated, and stamped  
7. Do not leave any mandatory field blank  
8. Save draft before final submission  

### Internal Review Gate
- [ ] All applicant details match IEC and RCMC  
- [ ] Product and destination eligible under current TMA notification  
- [ ] Shipping bills, freight, and marketing proofs attached  
- [ ] Bank details correct and verified  
- [ ] Self-declaration form completed and signed  
- [ ] All documents legible and within size limits  
- [ ] Application draft reviewed for completeness  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take screenshot of submission confirmation with timestamp  
- Store application reference number securely  
- Set follow-up reminders at 15 and 30 days post-submission

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and archive approval letter from APEDA  
- [ ] Verify sanctioned amount matches claim submitted  
- [ ] Monitor bank account for reimbursement credit  
- [ ] Utilization certificate not required for TMA (reimbursement-based)  
- [ ] Invoice success fee as per consultancy agreement  
- [ ] Maintain records for audit purposes (minimum 5 years)
