# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a debutant filmmaker (first feature film, children's film, or documentary film)
- [ ] Project aligns with NFDC's production guidelines and objectives under the DCDFC scheme
- [ ] Submission is made through a government-supported film festival (IFFI Goa, Mumbai International Film Festival, Film Bazaar, etc.)
- [ ] Project is a feature film, children's film, or documentary film
- [ ] Applicant is an Indian filmmaker or content creator (individual or entity)
- [ ] Project reflects diversity in Indian cinema and highlights unique aspects of Indian culture
- [ ] Applicant agrees to co-production terms if applicable (partnership with Indian or international filmmakers)
- [ ] Project complies with NFDC's extant production guidelines

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation certificate / PAN card
- ITR of last 2-3 years
- GST registration (if applicable)
- Bank statements (last 6 months)
- Udyam Registration (for MSMEs)
- Aadhaar/PAN of authorized signatory
- Passport-sized photographs
- Address proof

### Scheme-Specific Documents
- Detailed project proposal (synopsis, script, budget, shooting schedule)
- Director's profile and filmography (emphasizing debutant status)
- Proof of submission through a government-supported film festival (application confirmation, festival registration)
- Letter of intent from co-producer (if applicable, for international/Indian partnership)
- NFDC Production Guidelines acknowledgment (signed)
- Project alignment note with DCDFC scheme objectives
- Any prior awards or recognitions (if applicable)

### Document Quality Check
- All documents must be legible scans or clear photographs
- File names must match the document type and applicant name (e.g., "Project_Synopsis_JohnDoe.pdf")
- PDF files must be under 10 MB each
- Declarations and undertakings must be signed and dated
- Language: English or Hindi; if regional language, provide certified translation
- Bank statements must show consistent transactions and be stamped by the bank
- ITR must be filed and verified via income tax portal

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required as a standalone DPR; however, a detailed project proposal (including synopsis, script, budget, shooting schedule, and director’s note) is mandatory. Verify with nodal officer if a formal DPR is expected for high-budget projects.

### Application Form Filling Protocol
1. Access the application via the designated government-supported film festival portal (IFFI, MIFF, Film Bazaar)  
2. Select the NFDC Production Grants / DCDFC scheme category during submission  
3. Fill in all applicant details accurately (name, contact, PAN, bank details)  
4. Upload the project proposal as a single PDF file (ensure it includes synopsis, budget, timeline)  
5. Attach director’s profile and proof of festival submission  
6. If applicable, upload co-producer agreement or letter of intent  
7. Acknowledge and sign the NFDC Production Guidelines declaration  
8. Double-check all entries before final submission; incomplete forms will be rejected  

### Internal Review Gate
- [ ] All applicant details complete and accurate  
- [ ] Project proposal includes synopsis, script, budget, and shooting schedule  
- [ ] Director’s profile confirms debutant status  
- [ ] Proof of submission to government-supported film festival attached  
- [ ] NFDC Production Guidelines acknowledgment signed  
- [ ] Co-producer documents attached (if applicable)  
- [ ] File sizes under 10 MB and named correctly  
- [ ] Declarations dated and signed  
- [ ] No spelling or formatting errors in narrative sections  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application through the official portal of the selected government-supported film festival (IFFI, MIFF, Film Bazaar)  
- Take a screenshot of the confirmation page showing submission timestamp and application ID  
- Store the application reference number in the case file  
- Set a follow-up reminder for 15 days post-submission  
- Save all communication and documents in a dedicated folder labeled with Case ID

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter from NFDC specifying sanctioned amount and co-production terms (if any)  
- [ ] Confirm that financial support covers 100% of production costs as per scheme guidelines  
- [ ] Utilization Certificate: Ensure timely submission as per NFDC’s fund release schedule  
- [ ] Maintain detailed records of all expenditures against the sanctioned budget  
- [ ] Coordinate with NFDC for disbursement tranches linked to production milestones  
- [ ] Upon completion, submit final report, audit statement, and utilization certificate for closure  
- [ ] Track success fee invoice as per consultancy agreement (if applicable)  
- [ ] Assist client in participating in NFDC initiatives like Film Bazaar for project promotion (post-approval)
