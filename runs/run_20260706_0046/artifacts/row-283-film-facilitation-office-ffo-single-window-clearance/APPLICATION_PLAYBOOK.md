## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The FFO process does not mandate a Detailed Project Report (DPR). However, a clear script/synopsis and production schedule are essential. If additional project justification is sought by nodal agencies, verify requirements with the concerned department or FFO helpdesk.

### Application Form Filling Protocol
1. Access the FFO portal at **https://ffo.gov.in** and register as a new user using valid email and mobile number.  
2. Select the type of clearance(s) required (e.g., location, drone, road closure, defense, civil aviation, ASI).  
3. Fill in applicant details accurately: name, entity type, PAN, contact information, and address.  
4. Upload the script/synopsis under the designated section — ensure it reflects the actual film content and intent.  
5. Enter production schedule with precise dates, shift timings, and shooting locations.  
6. Provide location details with GPS coordinates and attach annotated maps; specify if shooting involves private, public, or restricted land.  
7. If drone usage is involved, complete the UAV section with make, model, serial number, purpose, flight duration, and altitude.  
8. List all equipment (cameras, lights, sound gear) and crew members with roles and identification details.  
9. Declare that the information provided is true and that final clearances rest with respective agencies (MoD, MHA, MoCA, ASI, etc.).  
10. Review all entries before submission — incomplete or inconsistent details may lead to delays or rejection.  
11. Submit the application and save the acknowledgment receipt with application reference number.  
12. Monitor status regularly via the portal; respond promptly to any queries from FFO or nodal agencies.

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application exclusively through the official FFO portal: **https://ffo.gov.in**  
- Upon submission, capture a screenshot of the confirmation page showing the application reference number and timestamp  
- Store the reference number in the case file and share it with the client  
- Set calendar reminders to check application status every 3–4 days  
- Note that FFO forwards applications to relevant agencies (MoD, MHA, MoCA, ASI, etc.) — follow-up may be needed with nodal officers
