# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is any person willing to venture into exports of handicrafts
- [ ] Applicant has a valid Import Export Code (IEC) (self-certified copy required)
- [ ] Applicant has determined registration type: 'Merchant Exporter', 'Manufacturer Exporter', or 'Merchant-cum-Manufacturer Exporter'
- [ ] If partnership firm: Partnership Deed is available
- [ ] If private limited or limited company: Photocopy of certificate of incorporation (Memorandum of Article of Association) and resolution deed regarding signing authority are available
- [ ] If Export House: Export House Certificate is available
- [ ] If manufacturer exporter: MSME UAM or Udhyam registration and self-declaration certifying type of Handicrafts product manufacturing are available
- [ ] Applicant has a valid GSTIN number (copy required)
- [ ] Applicant has checked EPCH website member directory to avoid similar or duplicate names
- [ ] Applicant understands that membership is a pre-condition for registration
- [ ] Applicant understands Registration cum Membership Certificate is valid for 5 years subject to annual renewal

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- PAN card
- ITR (Income Tax Return) for last 2-3 years
- GST registration certificate
- Bank statements (last 6 months)
- Udyam Registration (if applicable)
- IEC (Import Export Code) certificate

### Scheme-Specific Documents
- Self certified copy of Import Export Code (IEC) (mandatory)
- Partnership Deed (if partnership firm)
- Photocopy of certificate of incorporation (Memorandum of Article of Association) and resolution deed regarding signing authority (if private limited or limited firm)
- Export House Certificate (if Export House applies for membership)
- MSME UAM or Udhyam & self declaration certifying type of Handicrafts product manufacturing (if manufacturer exporter)
- Copy of GSTIN number

### Document Quality Check
- All documents must be legible and clear scans
- File names must match document type (e.g., IEC_Copy.pdf, GST_Certificate.pdf)
- Self-certified documents must include declaration and signature
- PDF format preferred; file size under 5 MB per document
- All certificates must be valid and not expired
- Documents must be in English or Hindi; if in regional language, provide certified translation
- Photographs must be passport size with white background (if applicable)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for EPCH membership application. Flag: "verify with nodal officer." (No DPR mentioned in evidence for membership process.)

### Application Form Filling Protocol
1. Access the application portal at https://epch.in/apply-new-membership
2. Select "Apply for New Membership"
3. Clearly specify interest in: Membership, Registration as 'Merchant Exporter', or Registration as 'Manufacturer Exporter' (or all)
4. If no specific preference indicated, RCMC will be issued as 'Merchant Exporter' by default
5. Enter all organizational details accurately matching submitted documents
6. Upload self-certified copy of IEC (mandatory)
7. Upload entity-specific documents based on business type (Partnership Deed, Incorporation docs, Export House Certificate, MSME UAM + self-declaration, or GST copy)
8. Declare that you have checked EPCH member directory to avoid similar/duplicate names
9. Review all entries before final submission – no edits possible after submission
10. Proceed to payment gateway for fees (Entrance + Annual fee + GST)

### Internal Review Gate
- [ ] Application form completed with accurate organizational details
- [ ] Membership category preference clearly indicated (Merchant/Manufacturer/Both)
- [ ] Self-certified IEC copy uploaded
- [ ] Entity-specific documents uploaded based on business structure
- [ ] GSTIN copy uploaded
- [ ] Declaration made about name verification via EPCH member directory
- [ ] All documents legible, properly named, and within size limits
- [ ] Fee calculation verified: Rs. 8,850 (year of enrollment) or Rs. 5,900 (renewal)
- [ ] Authorized signatory identified and ready for declaration

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit application via https://epch.in/apply-new-membership
- Take screenshot of confirmation page showing application reference number
- Save reference number and timestamp in case file
- Set calendar reminder for follow-up at 7 days, 15 days, and 30 days post-submission
- Monitor email (including spam) for communication from EPCH (mails@epch.com)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Approve and download Registration cum Membership Certificate (RCMC) from EPCH portal
- [ ] Verify sanctioned membership benefits: access to EPCH infrastructure, marketing, information facilities, participation in international trade fairs (IHGF, IFJAS, etc.), seminars/workshops, and specific centres (International Lace Trade Centre, Moradabad Resource Centre, etc.)
- [ ] Note RCMC validity: 5 years subject to annual membership renewal
- [ ] Set annual renewal reminder: Membership fee due 1st April, payment to be made by 30th June each year (renewal fee Rs. 5,900)
- [ ] Utilize EPCH member privileges: access to member directory, participation in EPCH-organized events, and use of facilities like Design Register for IPR protection
- [ ] Track utilization of benefits for future renewal justification
- [ ] Prepare for annual renewal: re-verify name uniqueness via EPCH member directory, ensure GST and IEC validity, process renewal payment by 30th June
- [ ] Invoice success fee as per consultancy agreement (to be filled by consultant)
