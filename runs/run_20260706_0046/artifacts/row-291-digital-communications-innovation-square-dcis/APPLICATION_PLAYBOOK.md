# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- ✅ Entity type: Startup, MSME, innovator, or entity engaged in telecom innovation, standardisation, or development of digital communication solutions  
- ✅ Sector: Telecom innovation, standardisation, or digital communication solutions  
- ✅ Alignment with national telecom priorities: Preference given to entities working on 5G/6G technologies, indigenous solutions, and those aligned with national telecom priorities  
- ✅ Registration: Valid Certificate of Incorporation or Registration  
- ✅ PAN: Valid PAN of the entity  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation or Registration  
- PAN of the entity  
- ITR (Income Tax Returns)  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam Registration (for MSMEs)  

### Scheme-Specific Documents
- Proposal document detailing the innovation  
- Technical specifications and diagrams  
- Proof of concept or prototype details  
- Team details and qualifications  

### Document Quality Check
- File size: Each document < 10 MB  
- File naming: Use format `[SchemeAbbr]_[ClientName]_[DocType]_[YYYYMMDD].pdf` (e.g., DCIS_Innovatech_Proposal_20260515.pdf)  
- Language: English or Hindi; if other language, provide certified translation  
- Certification: All certificates must be valid and issued by competent authority  
- Clarity: Scanned documents must be legible; no blurry or incomplete pages

**Subject:** Application Invitation – Digital Communications Innovation Square (DCIS) – Rolling Basis

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required per evidence. However, a detailed proposal document is mandatory. If a DPR is sought by the nodal officer, verify requirements directly.  
**Flag:** Verify with nodal officer whether a Detailed Project Report (DPR) is required beyond the proposal document.

### Application Form Filling Protocol
1. Access the portal at https://dot.gov.in/dcis and register as an innovator or startup.  
2. Fill all mandatory fields in the application form—leave no section blank.  
3. Upload documents in PDF format only, ensuring file names match the naming convention.  
4. Double-check that the proposal clearly outlines innovation objectives, expected outcomes, and alignment with 5G/6G or indigenous telecom priorities.  
5. Validate that PAN and Certificate of Incorporation details exactly match uploaded documents.  
6. Confirm that team qualifications are relevant to telecom innovation (e.g., RF engineering, software-defined networking, protocol development).  
7. Save a draft before final submission and review for completeness.  
8. Take a screenshot of the confirmation page after submission and save the application reference number.  

### Internal Review Gate
- ☐ All eligibility criteria met and verified  
- ☐ All universal and scheme-specific documents collected and quality-checked  
- ☐ Proposal document is clear, technically sound, and highlights innovation  
- ☐ Application form fields are fully and accurately filled  
- ☐ Documents are uploaded correctly and accessible  
- ☐ Declarations and undertakings are signed (if applicable)  
- ☐ Application reference number and submission screenshot saved  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via https://dot.gov.in/dcis after internal review approval  
- Capture a screenshot of the submission confirmation page showing the application reference number and timestamp  
- Store the reference number securely in the case file  
- Set a follow-up reminder for 15 days post-submission to check status

### Escalation Path
- Level 1: Portal helpdesk – Available via the DCIS portal at https://dot.gov.in/dcis (use contact form or email support)  
- Level 2: Nodal officer – ceo-dibd@digitalindia.gov.in (as per evidence)  
- Level 3: RTI filing if no response within statutory SLA (typically 30 days for government schemes)  

---

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- ☐ Receive and save the approval letter or selection notification from DoT  
- ☐ Verify sanctioned benefits: access to DCIS infrastructure, mentorship, networking opportunities, visibility  
- ☐ Note: DCIS does not provide direct financial grants; financial support must be sought via allied schemes (TDIP/PLI)  
- ☐ If applicable, coordinate utilization of testing infrastructure and mentorship sessions  
- ☐ Submit progress reports and outcomes as required by the scheme  
- ☐ Track utilization for potential linkage to TDIP or PLI schemes for financial incentives  
- ☐ Prepare and submit invoice for success fee upon realization of benefits (as per firm policy)
