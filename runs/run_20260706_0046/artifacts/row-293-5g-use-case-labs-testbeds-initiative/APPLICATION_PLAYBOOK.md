# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity is registered in India (Certificate of Incorporation/Registration)
- [ ] Entity is a startup, MSME, enterprise, or academic institution
- [ ] Entity has a clear 5G innovation proposal with potential for scalability and impact
- [ ] Proposal is focused on 5G use case development, testing, or validation
- [ ] Entity demonstrates capability to execute the proposed 5G solution
- [ ] No prior commercial deployment requirement (scheme supports prototype to testbed phase)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration
- PAN of the entity
- GST registration certificate
- Udyam Registration (for MSMEs)
- Audited financial statements / ITR of last 2 years
- Bank statements (last 6 months)
- Authorized signatory letter and board resolution

### Scheme-Specific Documents
- Detailed project proposal outlining 5G use case, objectives, and expected outcomes
- Technical specifications of the 5G use case
- Team credentials and expertise (CVs, roles, relevant experience)
- Budget utilization plan (itemized cost breakdown for prototype development, testing, validation)
- Any relevant certifications or approvals (if applicable to the 5G solution)

### Document Quality Check
- All documents must be legible scans or certified true copies
- File names must match document type (e.g., "PAN_Card.pdf", "Project_Proposal.pdf")
- PDF file size should not exceed 10 MB per document
- Documents in regional languages must be accompanied by certified English translations
- Undertaking on letterhead for self-declared information (if applicable)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a detailed project proposal is required. It should include:  
- Executive summary  
- Problem statement and 5G use case relevance  
- Objectives and expected outcomes  
- Methodology and work plan  
- Technical architecture and specifications  
- Team structure and expertise  
- Budget utilization plan  
- Scalability and impact assessment  
- Risk mitigation plan  
- Timeline for prototype development, testing, and validation  

### Application Form Filling Protocol
1. Access the portal at https://dot.gov.in/5g and review guidelines before starting.  
2. Ensure all mandatory fields are completed.  
3. Upload documents in PDF format only, with correct naming convention.  
4. Double-check that the project proposal clearly aligns with 5G innovation in sectors like healthcare, manufacturing, or agriculture.  
5. Confirm that the budget utilization plan is realistic and itemized.  
6. Validate that team credentials reflect expertise in 5G, IoT, AI, or related domains.  
7. Submit only after internal review gate clearance.  
8. Save a screenshot of the submission confirmation page with timestamp.  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] Project proposal is complete, coherent, and innovation-focused  
- [ ] Technical specifications are detailed and feasible  
- [ ] Team credentials and expertise are relevant and verifiable  
- [ ] Budget utilization plan is itemized and justified  
- [ ] All universal and scheme-specific documents are attached  
- [ ] Declarations and undertakings are signed and dated  
- [ ] Application form fields are fully and accurately filled  
- [ ] Submission screenshot and reference number saved  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit application via https://dot.gov.in/5g  
- Capture screenshot of submission confirmation with timestamp and application/reference number  
- Store reference number securely in case file  
- Set calendar reminder for follow-up at 15 and 30 days post-submission

### Escalation Path
- Level 1: Portal helpdesk – https://dot.gov.in/5g (use contact form or email ceo-dibd@digitalindia.gov.in)  
- Level 2: Nodal officer – Joint Secretary (Telecom), Department of Telecommunications, Ministry of Communications, Sanchar Bhawan, 20, Ashoka Road, New Delhi-110001 | Email: ceo-dibd@digitalindia.gov.in  
- Level 3: RTI filing if no response within 30 days (statutory SLA for government response)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Receive and verify approval letter/MoU from DOT  
- [ ] Confirm sanctioned amount and disbursement schedule (if financial support is granted)  
- [ ] Initiate prototype development as per approved work plan  
- [ ] Schedule and conduct testing/validation at 5G testbed facility  
- [ ] Maintain utilization records  
- [ ] Prepare and submit interim reports  
- [ ] Submit final report and outcomes for review  
-  
- [ ] Utilization certificate submission (if grant-based)  
- [ ] Invoice success fee as per engagement agreement  
- [ ] Explore pathways for commercial deployment or follow-on funding
