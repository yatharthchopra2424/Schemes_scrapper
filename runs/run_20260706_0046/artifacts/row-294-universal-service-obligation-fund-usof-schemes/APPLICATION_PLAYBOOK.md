# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] The applicant is a Telecom Service Provider (TSP) undertaking projects in areas where ICT services are not available due to commercial non-viability.
- [ ] The project area is determined by USOF/DBN as commercially non-viable on account of sparse population, remoteness, absence of supporting infrastructure, low income of inhabitants, or insurgency.
- [ ] The project aligns with USOF/DBN objectives: providing widespread and non-discriminatory access to quality ICT services at affordable prices in rural & remote areas, promoting universal access, facilitating R&D, supporting pilot projects, encouraging adoption of new telecom services, narrowing access gaps, reducing the digital divide, and mainstreaming underserved areas.
- [ ] The project adheres to the Telecommunications (Administration of Digital Bharat Nidhi) Rules, 2024.
- [ ] Financial support is contingent upon verification of progress and compliance with project milestones.
- [ ] The project falls under one of the ongoing USOF schemes: BharatNet Project, CTDP for NER, Uncovered Villages, LWE Affected Areas, or Others Projects (e.g., TTDF, International Bandwidth hiring, DSPTs).
- [ ] The applicant has the technical and financial capacity to execute the project as per USOF/DBN requirements.
- [ ] The project is not for profit-making in commercially viable areas; subsidy is exclusively for meeting Universal Service Obligation as per the Indian Telegraph Act, 1885 (as amended).

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration
- PAN Card
- GST Registration Certificate
- Audited Financial Statements (last 3 years)
- Income Tax Returns (last 3 years)
- Bank Statements (last 6 months)
- Udyam Registration (if applicable)
- Board Resolution authorizing application
- Authorized Signatory Details

### Scheme-Specific Documents
- Detailed Project Report (DPR) outlining project scope, objectives, methodology, timeline, and budget
- Agreement draft with USOF/DBN (if pre-negotiated)
- Land allotment documents or No Objection Certificate (NOC) for tower/sites (if applicable)
- Technical specifications of equipment to be deployed
- Survey reports confirming commercial non-viability of target area
- Implementation plan with milestones and timelines
- Environmental and safety clearances (if required)
- Details of proposed technology stack (e.g., 4G/5G, OFC, satellite)
- Proof of experience in similar telecom infrastructure projects
- Undertaking to share telecom network on open and non-discriminatory basis
- Utilization plan for funds disbursed

### Document Quality Check
- All documents must be legible, scanned in PDF format (max file size 10 MB per document unless specified otherwise)
- Document names must match the checklist (e.g., "PAN_Card.pdf", "GST_Registration.pdf")
- Certificates must be valid and not expired
- English language required; if in regional language, provide certified translation
- Financial documents must be audited and signed by Chartered Accountant
- Project reports must be signed and stamped by authorized signatory
- All declarations must be notarized where required

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. Standard sections include:
- Executive Summary
- Project Objectives aligned with USOF/DBN goals
- Area Description and Justification for Commercial Non-Viability
- Technical Architecture (technology stack, network design)
- Implementation Plan with Milestones and Timelines
- Budget Breakdown and Funding Request
- Sustainability and Operations & Maintenance Plan
- Risk Assessment and Mitigation Strategy
- Monitoring and Evaluation Framework
- Annexures: Survey Reports, Land Documents, Technical Specifications, Financial Projections

### Application Form Filling Protocol
1. Access the application portal at https://usof.gov.in and navigate to the relevant scheme section (e.g., BharatNet, CTDP, etc.).
2. Download the official application form or apply online if available.
3. Fill all fields accurately; leave no mandatory field blank.
4. Ensure consistency between information in the form and attached documents (e.g., project cost, timeline).
5. Use INR (₹) for all financial figures; avoid abbreviations.
6. Attach all required documents in the specified format (PDF, max size as per portal).
7. Verify that the Implementer details match the agreement signatory.
8. Confirm that the project adheres to Telecommunications (Administration of Digital Bharat Nidhi) Rules, 2024.
9. Save a draft before final submission and review thoroughly.
10. Take a screenshot of the completed form before submission.
11. Upon submission, note the Application Reference Number and timestamp.
12. Do not submit multiple applications for the same project without withdrawal of prior submission.

### Internal Review Gate
- [ ] All eligibility criteria verified and documented
- [ ] Universal and scheme-specific documents collected and quality-checked
- [ ] DPR completed and reviewed internally
- [ ] Application form filled completely and accurately
- [ ] All documents attached in correct format and size
- [ ] Declarations and undertakings signed and dated
- [ ] Application reference number noted post-submission
- [ ] Financials match between DPR, form, and audited statements
- [ ] Project timeline aligns with scheme guidelines (e.g., roll-out periods)
- [ ] Compliance with open-access and non-discriminatory network sharing confirmed

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the official portal: https://usof.gov.in
- Upon successful submission, take a screenshot of the confirmation page showing the Application Reference Number and timestamp.
- Save the reference number in the case file and set up automated reminders for follow-up at 15, 30, and 45 days.
- Store all submission records (screenshots, emails, PDFs) in a dedicated folder labeled with Case ID and scheme name.
- If submission fails, note the error and retry after resolving issues; contact portal helpdesk if persistent.

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the official approval letter from USOF/DBN
- [ ] Confirm the sanctioned amount and disbursement schedule as per approval
- [ ] Sign the formal agreement with USOF/DBN Administrator
- [ ] Set up dedicated bank account for fund receipt if required
- [ ] Initiate project execution as per approved timelines and milestones
- [ ] Monitor progress and submit periodic reports as stipulated in the agreement
- [ ] Ensure utilization of funds exclusively for meeting Universal Service Obligation
- [ ] Prepare and submit Utilization Certificates (UCs) as per schedule
- [ ] Maintain records for audit and verification by USOF/DBN or third-party agencies
- [ ] Coordinate with USOF/DBN for mid-term reviews and impact assessment
- [ ] Plan for project closure and handover procedures as per agreement terms
- [ ] Calculate and remit success fee as per engagement agreement with client (internal firm matter)
