# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Family is identified as "poorest of the poor" in the State of Haryana  
- [ ] Family resides in Haryana (geographic scope: Haryana only)  
- [ ] Family is economically disadvantaged (target beneficiary: economically disadvantaged families)  
- [ ] Family is targeted for a tailored package of measures from various welfare schemes (skill development, wage employment, self-employment, etc.)  
- [ ] Family's income level is below the threshold to be raised to a minimum economic threshold of Rs. 1 lakh initially and Rs. 1.80 lakh per annum subsequently  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Identity proof (Aadhaar, Voter ID, etc.)  
- Address proof (ration card, utility bill, etc.)  
- Bank account details (passbook or statement)  
- PAN card  
- Income Tax Returns (ITR) – if applicable  
- GST registration certificate – if applicable  
- Udyam Registration (for MSMEs) – if applicable  
- Caste certificate (if claiming benefits under reserved categories)  
- Income certificate  
- Family details (ration card or similar)  

### Scheme-Specific Documents
- Proof of identification as "poorest of the poor" family (issued by competent authority in Haryana)  
- Any existing welfare scheme benefits/documents currently availed by the family (to avoid duplication and enable tailoring of package)  

### Document Quality Check
- All documents must be legible and clear scans  
- File size should not exceed 5 MB per document  
- Document names must match the applicant's name as per official records  
- Self-attested copies are acceptable; gazetted officer attestation preferred where required  
- Documents must be in Hindi or English; if in another language, certified translation must be attached  
- No expired documents (validity > 6 months from date of application)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly mentioned in the evidence. Since MMAPUY is an umbrella mission tailoring existing welfare schemes, a detailed project report may not be required at the family level. However, **verify with the nodal officer** whether a DPR or family upliftment plan is needed for sanctioning the tailored package.  

### Application Form Filling Protocol
1. Use only the official portal designated by the Department of Information Technology Electronics & Communication, Haryana (confirm URL via nodal officer or website: https://haryanait.gov.in)  
2. Fill all fields accurately; leave no mandatory field blank  
3. Upload documents in PDF or JPEG format as specified  
4. Ensure the applicant’s name matches exactly across all documents and the form  
5. Select "Mukhya Mantri Antyodaya Parivar Utthan Yojana (MMAPUY)" from the scheme list  
6. Declare that the family is identified as "poorest of the poor" in Haryana  
7. Provide correct contact details (mobile, email) for follow-up  
8. Review the filled form before final submission to avoid errors  

### Internal Review Gate
- [ ] All applicant and family details correctly entered  
- [ ] All universal and scheme-specific documents uploaded  
- [ ] Declarations signed and dated  
- [ ] Application form reviewed for completeness and accuracy  
- [ ] Reference number noted after submission (to be captured post-submission)  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the confirmation page after final submission  
- Save the application reference number securely  
- Set a follow-up reminder for 15 days post-submission to check status  
- Store all application documents and screenshots in the case folder

- [ ] Track utilization and ensure compliance with scheme objectives (raising income to Rs. 1 lakh initially, Rs. 1.80 lakh per annum subsequently)
