# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a natural person, startup, small entity, educational institution, or other legal entity  
- [ ] Application is for one of the following IP types: patent, design, trademark, geographical indication, or copyright  
- [ ] Applicant meets the specific eligibility criteria for the chosen IP type as per the respective Acts and Rules  
- [ ] For startups and small entities: proper declaration and eligibility verification for fee concessions is completed  
- [ ] Application falls under the geographic scope of Pan-India  
- [ ] Applicant is not barred by any legal restriction from applying for IP protection  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation certificate (if applicable)  
- PAN card  
- ITR (last 2-3 years)  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam registration (for MSMEs/startups)  

### Scheme-Specific Documents
- Form 1 (Application for Grant of Patent)  
- Form 2 (Provisional/Complete Specification)  
- Form 3 (Statement and Undertaking under Section 8)  
- Form 5 (Declaration of Inventorship)  
- Power of Attorney (if applicable)  
- Priority documents (if claiming priority)  
- Sequence listing (if applicable)  
- Drawings (for patents and designs)  
- Statement of Case (for Geographical Indications)  
- Affidavit (for Geographical Indications)  
- Geographical maps (for Geographical Indications)  
- Trademark representation (for trademarks)  
- Description of goods/services (for trademarks)  
- User affidavit (for trademarks, if applicable)  

### Document Quality Check
- All documents must be legible and in English or Hindi  
- File size should not exceed portal limits (typically 5-10 MB per file)  
- File names must match the document type and applicant name  
- Scanned copies must be certified true copies where required  
- Signatures and dates must be present on all declarations and affidavits  
- Forms must be filled completely without overwriting or alteration

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required for IP registration under this scheme. Flag: "verify with nodal officer" if detailed project justification is needed for specific cases.  

### Application Form Filling Protocol
1. Confirm the correct form based on IP type (e.g., Form 1 for patents, Form TM-A for trademarks)  
2. Fill all applicant details accurately, including name, address, nationality, and contact information  
3. Select the correct applicant category (Natural Person, Startup, Small Entity, Educational Institution, etc.) to avail fee concessions  
4. Provide a clear and concise title of the invention, design, or mark  
5. Attach all required supporting documents as per the scheme-specific checklist  
6. Pay the prescribed fee based on applicant category (e.g., ₹800 for startups/small entities/natural persons vs. ₹4000 for others under Form 1)  
7. Verify OTP verification is completed for email and mobile number fields  
8. Retain a copy of the filled application and payment receipt before submission  

### Internal Review Gate
- [ ] All sections of the application form are completed  
- [ ] Correct applicant category selected for fee benefit eligibility  
- [ ] All scheme-specific documents are attached and properly named  
- [ ] Declarations and undertakings (Forms 3, 5) are signed and dated  
- [ ] Fee paid matches the applicant category (refer to First Schedule of Patents Rules 2003)  
- [ ] Application is ready for upload on https://ipindia.gov.in  

---

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the e-filing portal at https://ipindia.gov.in  
- Capture a screenshot of the confirmation page showing the application number and timestamp  
- Store the application reference number securely in the case file  
- Set follow-up reminders for 15 days post-submission to check status

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the approval/registration certificate from the portal  
- [ ] Confirm the sanctioned benefits (e.g., fee concession applied, certificate issued)  
- [ ] Monitor journal publication (Patents Journal, Design Journal, Trade Marks Journal, Geographical Indication Journal, Copyright Journal)  
- [ ] Prepare utilization certificate if required for any associated incentives  
- [ ] Track renewal dates and fee schedules (especially for patents, trademarks, and designs)  
- [ ] Invoice client for success fee upon successful registration  
- [ ] Advise client on maintenance requirements (e.g., patent renewal fees, trademark use affidavits)
