# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Corporate debtor is classified as a Micro, Small, or Medium Enterprise (MSME as per the Micro, Small and Medium Enterprises Development Act, 2006  
- [ ] Consent of not less than sixty-six percent of the financial creditors by value has been obtained  
- [ ] No pending application for insolvency resolution under section 7, 9 or 10 of the Insolvency and Bankruptcy Code, 2016  
- [ ] No order for liquidation has been passed  
- [ ] Corporate debtor has not undergone a PPIRP in the last three years  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of incorporation  
- PAN card  
- Latest audited financial statements  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam Registration (MSME certificate)  
- Income Tax Returns (last 3 years)  

### Scheme-Specific Documents
- Resolution Plan  
- Information Memorandum  
- Evaluation Matrix  
- Declaration under Section 29A of the Insolvency and Bankruptcy Code, 2016  
- Proof of consent of financial creditors (not less than 66% by value)  
- Details of claims of financial and operational creditors  
- Valuation reports (if any)  
- Performance guarantee (as per regulation 36B(4A) of CIRP Regulations)  

### Document Quality Check
- File size: Each document must be under 10 MB  
- File naming: Use format `SchemeName_DocumentType_CaseID.pdf`  
- All documents must be legible, scanned in color if originally colored  
- Declarations and affidavits must be notarized or digitally signed  
- Financial statements must be audited and certified by a CA  
- All documents must be in English or accompanied by a certified translation

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required for PPIRP. However, the Resolution Plan serves as the detailed project report. If additional detail is needed, verify with the nodal officer (IBBI) or Adjudicating Authority (NCLT).  

### Application Form Filling Protocol
1. Access the IBBI PPIRP application portal: https://ibbi.gov.in/intimation-applications/apply-iaaa  
2. Ensure all fields in the application form are completed accurately  
3. Attach all required documents in the specified order and format  
4. Upload the Resolution Plan as the primary document  
5. Include the Information Memorandum, Evaluation Matrix, and Section 29A declaration  
6. Attach proof of financial creditor consent (≥66% by value)  
7. Upload latest audited financial statements and certificate of incorporation  
8. Attach the performance guarantee document (if applicable)  
9. Verify that no conflicting insolvency application is pending under sections 7, 9, or 10  
10. Confirm that no liquidation order has been passed  
11. Declare that the corporate debtor has not undergone PPIRP in the last three years  
12. Submit the application and save the acknowledgment receipt with application number  

### Internal Review Gate
- [ ] All application form fields completed  
- [ ] All universal and scheme-specific documents attached  
- [ ] Resolution Plan, Information Memorandum, and Evaluation Matrix are present  
- [ ] Declaration under Section 29A is signed and notarized  
- [ ] Proof of ≥66% financial creditor consent is included  
- [ ] No pending CIRP under sections 7, 9, or 10  
- [ ] No liquidation order passed  
- [ ] No PPIRP in the last three years  
- [ ] Application submitted via https://ibbi.gov.in/intimation-applications/apply-iaaa  
- [ ] Application reference number saved and shared with client

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the submission confirmation page showing the application number and timestamp  
- Store the application reference number in the case file  
- Set a follow-up reminder for 7 days after submission  
- Notify the client of successful submission with the reference number

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and securely store the approval order from the Adjudicating Authority (NCLT)  
- [ ] Verify the sanctioned amount in the resolution plan against the approval order  
- [ ] Monitor the implementation timeline: resolution must be completed within 90 days from application date, extendable to 150 days  
- [ ] Ensure the resolution applicant infuses funds as per the approved plan (fresh equity, quasi-equity, or internal accruals)  
- [ ] Verify payment of performance guarantee (typically 10% of the resolution plan value)  
- [ ] Obtain utilization certificate from the resolution applicant  
- [ ] Confirm settlement of claims to financial and operational creditors as per the plan  
- [ ] Coordinate with the Monitoring Committee (if constituted) for supervision reports  
- [ ] Submit post-approval compliance documents to IBBI if required  
- [ ] Inform client of successful completion and next steps for business revival
