## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Permanent Account Number (PAN) of the business entity  
- Certificate of Incorporation or Registration (or equivalent based on entity type)  
- Goods and Services Tax Identification Number (GSTIN) — if applicable  
- Bank account details (cancelled cheque or bank statement)  
- Udyam Registration Number (if MSME; optional but recommended for MSME beneficiaries)  
- Identity proof of applicant (Aadhaar, PAN, passport, or voter ID)  
- Address proof of applicant (Aadhaar, utility bill, passport, or bank statement)  

### Scheme-Specific Documents
- Authorization letter from authorized signatory (on company letterhead, signed and stamped)  
- Business profile details (to be filled in the app: entity name, type, address, contact, etc.)  

### Document Quality Check
- All documents must be clear, legible scans or PDFs (no blurry or cropped images)  
- File size: each document < 5 MB; total upload size within portal limits  
- File names must match document type (e.g., `PAN_ABCCompany.pdf`, `AuthLetter_XYZ.pdf`)  
- PAN and GSTIN must be valid and active (verify via NSDL/GSTN portal if needed)  
- Authorization letter must specify the authorized person’s name, designation, and scope of authority  
- Identity and address proof must be current (not expired) and name must match PAN/business records  
- All documents must be in English or Hindi; if in another language, attach certified translation

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The BizReform App is a facilitation platform for submitting existing government service applications; it does not fund projects or require a Detailed Project Report (DPR).  
**Verification Note**: Confirm with the nodal officer if the specific underlying service (e.g., factory license, FSSAI registration) requires a DPR — this varies by service, not the BizReform App itself.  

### Application Form Filling Protocol
1. Download the BizReform App from the official portal (https://bizreform.eodb.gov.in) or authorized app stores (Google Play/Apple App Store)  
2. Register using a valid mobile number or email ID — verify OTP before proceeding  
3. Create a complete business profile: enter entity name, type, PAN, GSTIN (if applicable), registered address, and contact details accurately  
4. Select the exact government service or clearance required from the service catalog (verify service availability with your state/central department)  
5. Fill the application form for the selected service — all fields must be completed; mandatory fields are marked  
6. Upload documents in the specified format (PDF/JPEG, <5 MB per file) with correct file names  
7. Review the entire application before submission — ensure no blank mandatory fields or mismatched details (e.g., PAN name vs. certificate name)  
8. Submit and note the application reference number; enable push notifications for real-time status tracking  

> **Portal-Specific Note**: The app integrates with central and state portals — if redirected to an external site (e.g., MCA, GSTN, labour department), follow their specific form rules while retaining the BizReform tracking ID.
