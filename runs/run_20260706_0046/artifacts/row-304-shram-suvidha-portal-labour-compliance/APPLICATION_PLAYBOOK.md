# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Employer of an establishment that came into existence after the commencement of the Occupational Safety, Health and Working Conditions Code, 2020 and the Social Security Code, 2020  
- [ ] Application for registration must be completed within 60 days from the date of applicability of the Codes  
- [ ] For establishments already registered under other labour laws, registration details must be updated within six months from the date of commencement of these Rules  
- [ ] Establishment must be located in India (Pan-India geographic scope)  
- [ ] Employer must be able to provide proof of identity  
- [ ] Employer must have a valid PAN/TAN  
- [ ] Employer must provide address of the establishment  
- [ ] Information relating to employment of Inter-State migrant workers must be available (if applicable)  
- [ ] Certificate of Incorporation or Registration (for new establishments)  
- [ ] Existing registration details (for establishments updating registration)  
- [ ] Any other supporting documents as specified in Form-I  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Proof of identity of the employer  
- PAN/TAN of the employer  
- Address proof of the employer  
- Bank statements (last 3 months)  
- Udyam Registration Certificate (if applicable)  
- ITR (last 2 years)  
- GST Registration Certificate (if applicable)  

### Scheme-Specific Documents
- Certificate of Incorporation or Registration (for new establishments)  
- Existing registration details (for establishments updating registration)  
- Information relating to employment of Inter-State migrant workers  
- Any other supporting documents as specified in Form-I  

### Document Quality Check
- All documents must be legible scans or clear photographs  
- File size must not exceed 5 MB per document  
- File names must match the document type (e.g., PAN_Card.pdf, Address_Proof.jpg)  
- All documents must be in English or Hindi; if in another language, a certified translation must be attached  
- Photographs must be recent (not older than 3 months)  
- Signatures must be visible and match official records  
- Certificates must be issued by competent authorities and not expired

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The Shram Suvidha Portal registration process does not require a Detailed Project Report (DPR). Verify with the nodal officer if any additional documentation is sought for specific cases.

### Application Form Filling Protocol
1. Access the Shram Suvidha Portal at https://shramsuvidha.gov.in and click 'Sign up' to register as a user.  
2. Provide name, email ID, mobile number, and captcha code during sign-up.  
3. Verify registration via the link sent to the registered email ID.  
4. Set user ID and password after OTP verification.  
5. Log in using OTP or user ID/password.  
6. Navigate to the Registration module.  
7. Select 'Apply for New/Existing/Offline Registration'.  
8. Choose registration type: 'New Registration' or 'Existing with LIN'.  
9. Fill Form-I with establishment details, proof of identity, PAN/TAN, address, and Inter-State migrant worker information.  
10. Upload all supporting documents in the prescribed format.  
11. Apply e-sign using Aadhaar-based OTP verification.  
12. Submit the application.  
13. Certificate of Registration (Form-III) is auto-generated and issued immediately upon successful submission.  

### Internal Review Gate
- [ ] All fields in Form-I are complete and accurate  
- [ ] Proof of identity, PAN/TAN, and address documents are uploaded  
- [ ] Information on Inter-State migrant workers is included (if applicable)  
- [ ] Certificate of Incorporation/Registration or existing registration details are attached  
- [ ] All documents meet quality check criteria (legible, correct naming, within size limit)  
- [ ] E-sign has been applied using Aadhaar-based OTP  
- [ ] Application is submitted and reference number is recorded  
- [ ] Screenshot of submission confirmation is saved

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the application via the Shram Suvidha Portal after completing Form-I and uploading documents  
- Apply e-sign using Aadhaar-based OTP verification before final submission  
- Immediately after submission, take a screenshot of the confirmation page showing the application reference number  
- Store the reference number securely in the case file  
- Set a follow-up reminder for 7 days post-submission to check application status  
- Monitor the portal for auto-generation of Certificate of Registration (Form-III)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Download and verify the Certificate of Registration (Form-III) from the portal  
- [ ] Confirm that the Labour Identification Number (LIN) is correctly mentioned in the certificate  
- [ ] Quote the registration number on all documents, records, and correspondence related to the Code or Rules  
- [ ] Display the non-transferable Certificate of Registration at a conspicuous place in the establishment  
- [ ] Ensure compliance with all conditions of the Certificate of Registration  
- [ ] Update any changes in ownership, management, or registration details within thirty days via amendment on the portal  
- [ ] File annual returns (Form-XVII) on or before 1st February every year as required under the Occupational Safety, Health and Working Conditions Code, 2020  
- [ ] Monitor for any communication regarding cancellation of registration due to wrong information (opportunity to show cause within 30 days will be provided)  
- [ ] No utilization certificate or financial reporting is required as the scheme does not provide direct financial support  
- [ ] Invoice success fee as per the consultancy agreement with the client
