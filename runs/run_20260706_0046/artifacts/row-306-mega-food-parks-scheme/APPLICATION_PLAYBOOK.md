# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] The applicant is forming a Special Purpose Vehicle (SPV) as a Body Corporate registered under the Companies Act  
- [ ] OR the applicant is a State Government, State Government entity, or Cooperative (exempt from forming a separate SPV)  
- [ ] The SPV (if required) meets the conditions of the Scheme Guidelines  
- [ ] The project aims to link agricultural production to the market by bringing together farmers, processors, and retailers  
- [ ] The project includes development of supply chain infrastructure: collection centers, primary processing centers, central processing centers, cold chain  
- [ ] The project provides around 25-30 fully developed plots for entrepreneurs to set up food processing units  
- [ ] The project is located in a well-defined agri/horticultural zone  
- [ ] The project aims to maximize value addition, minimize wastage, increase farmers' income, and create employment opportunities in the rural sector  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN Card  
- GST Registration  
- Bank Statements (last 6 months)  
- Udyam Registration (if applicable)  
- Income Tax Returns (last 3 years)  
- Audited Financial Statements  
- Board Resolution authorizing application  

### Scheme-Specific Documents
- Detailed Project Report (DPR) outlining project components: collection centers, primary processing centers, central processing centers, cold chain, and 25-30 developed plots  
- Land documents (ownership/lease agreement) for the Mega Food Park site  
- SPV incorporation documents (if applicable)  
- Project layout plan showing agri/horticultural zone and infrastructure  
- Supply chain linkage plan connecting farmers, processors, and retailers  
- Employment generation projection (particularly rural)  
- Value addition and wastage reduction estimates  
- No Objection Certificate (NOC) from State Government (if required)  
- Environmental clearance (if applicable)  

### Document Quality Check
- All documents must be legible and in PDF format  
- File names must match the document type (e.g., "Incorporation_Certificate.pdf")  
- Scanned copies must be clear and certified where required  
- Documents must be in English or Hindi; if in another language, provide certified translation  
- Financial documents must be audited and signed by a Chartered Accountant  
- Project reports must be signed by the authorized signatory of the SPV

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. It must include:  
- Executive Summary  
- Project Objectives (linking farm to market, value addition, wastage reduction, farmer income, rural employment)  
- Project Components: Collection Centers, Primary Processing Centers, Central Processing Centers, Cold Chain, 25-30 developed plots  
- Agri/Horticultural Zone Description  
- Supply Chain Linkage Plan  
- Land Details and Site Layout  
- Financial Projections (cost, funding, revenue)  
- Employment Generation Estimates (rural focus)  
- Implementation Schedule  
- Risk Assessment and Mitigation Plan  
- Compliance with Scheme Guidelines  

### Application Form Filling Protocol
1. Verify scheme status with nodal officer before proceeding (discontinued since 01.04.2021)  
2. Confirm eligibility: SPV formation (unless State Govt./Entity/Cooperative)  
3. Fill all fields in the application form accurately; leave no blanks  
4. Attach all required documents as per checklist  
5. Ensure financial figures match audited statements and DPR  
6. Declarations must be signed by authorized signatory with date and seal  
7. Double-check SPV registration details (CIN, PAN, address)  
8. Confirm contact details match those in incorporation documents  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] Application form fully completed with no missing fields  
- [ ] All universal and scheme-specific documents attached  
- [ ] Documents meet quality check standards (format, size, certification)  
- [ ] Financial data consistent across DPR, application form, and audited statements  
- [ ] Declarations signed and dated  
- [ ] Reference to scheme portal and discontinuation status noted  
- [ ] Case ID assigned and recorded

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify approval letter from MoFPI  
- [ ] Confirm sanctioned amount matches application request  
- [ ] Set up utilization certificate tracking mechanism  
- [ ] Monitor fund release milestones as per Scheme Guidelines  
- [ ] Ensure SPV complies with reporting requirements  
- [ ] Verify invoice for success fee as per consultancy agreement  
- [ ] Maintain records for audit and compliance purposes  
- [ ] Note: Scheme discontinued since 01.04.2021; approvals only for committed liabilities of ongoing projects
