# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is an entrepreneur, MSME, agri-startup, farmer, or food processing unit
- [ ] Applicant seeks financial assistance for infrastructure projects under one of the seven component schemes of PMKSY
- [ ] Applicant meets specific eligibility criteria of the targeted component scheme (verify from individual scheme guidelines)
- [ ] Applicant has a viable project proposal for food processing infrastructure
- [ ] Applicant is registered as a legal entity (proprietorship, partnership, company, FPO, SHG, or cooperative)
- [ ] Applicant possesses necessary land (ownership or registered leasehold with minimum 15-year duration)
- [ ] Applicant has access to required technical and financial resources
- [ ] Applicant complies with statutory requirements (FSSAI, GST, Pollution Control Board NOC if applicable)
- [ ] Applicant is not a Central/State Government Department (Surety Bond not required for such entities)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/registration certificate
- PAN of the entity
- GST registration
- Bank account details
- Financial statements (ITR, audited accounts)
- Udyam Registration (for MSMEs)
- Promoter/director details
- Project report/DPR

### Scheme-Specific Documents
- Land documents (ownership/registered leasehold)
- Quotations for plant and machinery
- NOC from Pollution Control Board (if applicable)
- Architectural plan/layout of the project
- Details of technical civil work and furniture/fixture
- Self-attested English/Hindi version of land document
- Notarised Surety Bond (if applicable and not exempt)
- Utilization certificate of earlier grants (if any)
- Bank statements showing payments to suppliers

### Document Quality Check
- All documents must be legible and in PDF format
- File size should not exceed 5 MB per document unless specified
- Names on documents must match exactly with registration details
- Land documents must be self-attested in English or Hindi
- Surety Bond must be notarised if applicable
- Project report must include technical, financial, and market feasibility
- Bank statements must show transaction history for last 6 months
- All declarations must be signed and dated

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a detailed project report (DPR) is required. Standard sections include:  
- Project at a Glance  
- Introduction and Product Description  
- Process Flow Chart  
- Economics of the Project (basis, capacity utilization, production, sales, raw material cost)  
- Premises/Infrastructure  
- Machinery & Equipment details  
- Miscellaneous Fixed Assets  
- Total Cost of Project  
- Means of Finance (subsidy, promoter’s contribution, term loan, working capital)  
- Term Loan Repayment & Interest Schedule  
- Working Capital Calculations  
- Salary & Wages  
- Power Requirement  
- Depreciation Calculation  
- Repairs & Maintenance  
- Profitability Projections  
- Break-Even Point Analysis  
- Projected Balance Sheet  
- Cash Flow Statement  
- Debt Service Coverage Ratio (DSCR)  

### Application Form Filling Protocol
1. Access the PMKSY portal: https://mofpi.gov.in/en/Schemes/about-pmksy-scheme  
2. Select the relevant component scheme under SAMPADA (e.g., Mega Food Park, Cold Chain, Agro Processing Cluster, etc.)  
3. Read the specific guidelines and EOI notice for the chosen component  
4. Fill in all mandatory fields accurately; do not leave any section blank  
5. Upload documents in the prescribed format (PDF, max size as specified)  
6. Ensure promoter’s contribution meets the minimum threshold (typically 10–20% as per component)  
7. Verify that total project cost aligns with means of finance  
8. Confirm that all declarations are signed and uploaded  
9. Take a screenshot of the final submission page before final submit  
10. Note down the application/reference number immediately after submission

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Take a screenshot of the submission confirmation page showing application number and timestamp  
- Store the application/reference number in a secure, accessible location  
- Save all submitted documents in a dedicated case folder  
- Set follow-up reminders for:  
  - Scrutiny status (within 15–20 days)  
  - Technical Committee evaluation (typically 30–45 days)  
  - Project Approval Committee decision (within 60 days)  
- Mark calendar for pre-disbursement compliance (acceptance letter submission)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and review the approval letter from MoFPI  
- [ ] Verify the sanctioned amount against the project cost and means of finance  
- [ ] Fulfill pre-disbursement compliances:  
  - Submit acceptance letter  
  - Upload compliance documents (as specified in approval letter)  
  - Ensure bank account is PFMS-enabled for fund transfer  
- [ ] Track disbursement of first instalment (50%) upon acceptance and compliance  
- [ ] Monitor project implementation as per approved timeline  
- [ ] Prepare and submit utilization certificate, bank statements, and expenditure proof upon project completion  
- [ ] Follow up for second instalment (50%) after verification of utilization and completion  
- [ ] Maintain all records for audit and future reference  
- [ ] Calculate and invoice success fee as per consultancy agreement
