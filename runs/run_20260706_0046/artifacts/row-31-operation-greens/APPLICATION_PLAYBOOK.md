# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a Farmer Producers Organization (FPO), agri-logistics entity, or processing facility  
- [ ] Project is focused on the Tomato, Onion, and Potato (TOP) value chain  
- [ ] Project falls under either Long Term Intervention (Integrated Value Chain Development Projects) or Short Term Intervention component  
- [ ] Applicant is registered as a legal entity (FPO, company, cooperative, etc.)  
- [ ] Project aims to promote FPOs, develop agri-logistics, establish processing facilities, or promote professional management  
- [ ] Project objectives include stabilization of supply and prices of TOP crops and reduction of post-harvest losses  

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/Registration Certificate  
- PAN Card  
- Audited Financial Statements / ITR (last 2 years)  
- GST Registration Certificate  
- Bank Statements (last 6 months)  
- Udyam Registration (if applicable)  

### Scheme-Specific Documents
- Detailed Project Report (DPR) outlining the TOP value chain intervention  
- List of eligible production clusters (if applying under Long Term Intervention)  
- Trigger prices for TOP crops (for Short Term Intervention claims)  
- Affidavit (format available in guidelines)  
- For FPOs: Registration certificate and member details  
- For processing facilities: Factory layout, machinery details, and FSSAI license  
- For agri-logistics: Warehouse/cold chain facility details and operational plan  

### Document Quality Check
- All documents must be legible and in PDF format  
- File names must match the document type (e.g., "PAN_Card.pdf")  
- Scanned copies must be clear and certified where required  
- Documents must be in English or Hindi; vernacular documents require certified translation  
- Financial documents must be audited and signed by a Chartered Accountant

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. Standard sections include:  
- Project at a Glance  
- Introduction and Product Details  
- Process Flow Chart  
- Economics of the Project (Basis & Presumptions, Capacity Utilization, Raw Material Cost, Sales Projections)  
- Premises/Infrastructure  
- Machinery & Equipment  
- Miscellaneous Fixed Assets  
- Total Cost of Project  
- Means of Finance  
- Term Loan Repayment & Interest Schedule  
- Working Capital Calculations  
- Salary & Wages  
- Power Requirement  
- Depreciation Calculation  
- Repairs & Maintenance  
- Profitability Analysis  
- Break Even Point Analysis  
- Projected Balance Sheet  
- Cash Flow Statement  
- Debt-Service Coverage Ratio (DSCR)  

### Application Form Filling Protocol
1. Access the application portal via https://mofpi.gov.in/operation-greens  
2. Select the correct component: Long Term Intervention or Short Term Intervention  
3. Fill in all applicant details exactly as per registration documents  
4. Clearly specify the TOP crop focus (Tomato, Onion, Potato) and value chain activities  
5. Upload all documents in the prescribed format and size limits  
6. Ensure the DPR includes financial projections and DSCR > 1.5  
7. Double-check that the subsidy amount requested does not exceed permissible limits  
8. Save draft frequently and review before final submission  

### Internal Review Gate
- [ ] All applicant details match supporting documents  
- [ ] DPR is complete with all required sections  
- [ ] Financial projections are realistic and based on stated assumptions  
- [ ] DSCR is calculated and meets minimum viability threshold  
- [ ] All universal and scheme-specific documents are attached  
- [ ] Declarations and undertakings are signed  
- [ ] Application is submitted via the correct portal and component
