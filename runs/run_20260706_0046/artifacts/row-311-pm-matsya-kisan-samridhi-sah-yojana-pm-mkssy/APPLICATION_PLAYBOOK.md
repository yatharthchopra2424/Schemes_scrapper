# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] The applicant is a state or union territory (UT) government department or agency responsible for fisheries development.
- [ ] The applicant is proposing a fisheries project within the geographic scope of India (Pan-India).
- [ ] The project falls under the implementation period of FY 2023-24 to FY 2026-27.
- [ ] The project aligns with the objectives of PM-MKSSY: addressing sectoral weaknesses, enhancing sustainability, facilitating reforms, promoting private participation, developing value chains, strengthening socio-economic conditions, enhancing productivity, and improving post-harvest management.
- [ ] The project proposal is submitted through the respective State/UT fisheries department following guidelines issued under PMMSY and PM-MKSSY framework.
- [ ] The applicant has consulted the District Fisheries Officer of the district where the fisheries development activity is intended.
- [ ] The project is for beneficiaries such as fish farmers, fishermen, aquaculture entrepreneurs, coastal communities, or self-help groups engaged in fisheries and aquaculture activities requiring financial and technical support.
- [ ] The project is not dependent on individual beneficiary criteria (e.g., turnover, employee count, age of business) as eligibility is determined at the State/UT level based on notified guidelines under the PMMSY framework.

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration (for NGOs, cooperatives, SHGs)
- PAN Card of the applicant entity
- Audited Financial Statements / ITR for last 2-3 years
- GST Registration Certificate (if applicable)
- Bank Statements (last 6 months)
- Udyam Registration (for MSMEs)
- Authorization letter from State/UT Fisheries Department (if applying via nodal agency)

### Scheme-Specific Documents
- Detailed Project Report (DPR) outlining the fisheries project scope, objectives, budget, timeline, and expected outcomes
- Land possession documents or lease agreement for the project site (if infrastructure-based)
- No Objection Certificate (NOC) from relevant authorities (e.g., Coastal Zone Management Authority, Pollution Control Board)
- Technical feasibility report (if applicable)
- Endorsement letter from District Fisheries Officer
- State/UT Fisheries Department approval or forwarding letter
- Beneficiary list (if applicable for group projects like SHGs, cooperatives)
- Environmental and Social Impact Assessment (if required by State/UT guidelines)

### Document Quality Check
- All documents must be legible, scanned in PDF format, and clearly named (e.g., "DPR_PM-MKSSY_ProjectX.pdf")
- File size for each document should not exceed 10 MB
- Names on documents must match exactly with the applicant’s registered name
- Certificates must be valid and not expired
- Documents in regional languages must be accompanied by a certified Hindi/English translation
- All declarations must be signed and stamped by authorized signatories

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a Detailed Project Report (DPR) is required. Standard sections include:  
- Executive Summary  
- Project Background and Justification  
- Objectives (aligned with PM-MKSSY goals)  
- Technical Description (activities, technology, infrastructure)  
- Site Details (location, land details, maps)  
- Implementation Plan and Timeline (Bar Chart)  
- Budget Breakdown (capital and recurring costs)  
- Funding Sources and Financial Plan  
- Expected Outcomes (production, employment, income growth)  
- Risk Assessment and Mitigation Plan  
- Monitoring and Evaluation Framework  
- Annexures: Drawings, approvals, beneficiary list, NOCs  

### Application Form Filling Protocol
1. Access the application via the State/UT fisheries department portal (not a central online form; submission is offline/through department).  
2. Ensure all fields in the DPR and application form are filled accurately; leave no blanks.  
3. Use official letterhead for all documents submitted to the State/UT fisheries department.  
4. Attach self-attested copies of all supporting documents.  
5. Clearly mention the scheme name: **Pradhan Mantri Matsya Kisan Samridhi Sah-Yojana (PM-MKSSY)** in the cover letter and DPR.  
6. Specify the financial year of application (e.g., FY 2024-25) as per State/UT action plan.  
7. Declare that the project does not duplicate benefits from other central/state schemes for the same activity.  
8. Confirm compliance with State/UT-specific PM-MKSSY guidelines issued under the PMMSY framework.  

### Internal Review Gate
- [ ] All sections of the DPR are complete and internally consistent  
- [ ] Budget matches activity-wise cost estimates  
- [ ] All required documents are attached and properly labeled  
- [ ] Declarations are signed and dated  
- [ ] Scheme name and code (PM-MKSSY, row-311) are correctly mentioned  
- [ ] Reference to State/UT fisheries department guidelines is included  
- [ ] Contact details of applicant and nodal officer are accurate  
- [ ] Copy of submission receipt is obtained and stored

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the hard copy of the DPR and supporting documents to the District Fisheries Officer, who forwards it to the State/UT fisheries department.  
- Obtain a submission receipt or diary number from the District Fisheries Office.  
- Scan and store the receipt with the case file.  
- Set a follow-up reminder for 15 days after submission to check status.

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and verify the official approval letter from the State/UT fisheries department  
- [ ] Confirm the sanctioned amount and disbursement schedule  
- [ ] Ensure utilization certificate format is understood and timelines noted  
- [ ] Track fund utilization against approved budget  
- [ ] Maintain records of all invoices, bills, and payment proofs  
- [ ] Prepare and submit progress reports as required by the State/UT agency  
- [ ] Coordinate for third-party verification if mandated  
- [ ] Upon completion, submit final utilization certificate and project completion report  
- [ ] Follow up on success fee invoice (if applicable under consultancy agreement)  
- [ ] Document lessons learned and outcomes for future reference
