## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Beneficiary type: Individual farmer, livestock rearer, self-help group (SHG), joint liability group (JLG), cooperative, producer company, NGO, or MSME engaged in animal husbandry activities  
- [ ] Valid land records or lease agreement available (where applicable)  
- [ ] Compliance with state-specific implementation guidelines confirmed  
- [ ] Priority status verified (small/marginal farmer, SC/ST community, woman entrepreneur, or involvement in breed improvement, fodder production, poultry, piggery, goat/sheep rearing, or dairy entrepreneurship)  
- [ ] No prior availing of similar benefits for the same component from other central or state schemes  
- [ ] Project falls under eligible NLM components: poultry, piggery, goat and sheep rearing, dairy units, breed improvement, fodder production (block making, silage), or livestock insurance  
- [ ] Project size within prescribed unit limits for commercial livestock farming (to be verified with State Implementing Agency)  
- [ ] Applicant has valid Aadhaar-linked bank account for DBT  
- [ ] Category certificate (SC/ST/OBC) ready if claiming higher subsidy (75% for SC/SC/SC/ST, 90% for specific components)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
**Required**: Yes, a Detailed Project Report (DPR) is mandatory as per the Application Process and Required Documents in the evidence.  

**Standard Sections to Include**:  
- Executive Summary  
- Beneficiary Details (name, address, Aadhaar, category)  
- Project Location and Land Details (ownership/lease, map, survey number)  
- Component Selected (e.g., poultry unit, fodder block making, dairy farm)  
- Technical Details (species/breed, housing design, feed plan, veterinary care)  
- Cost Breakdown (capital expenditure, working capital, quotes from suppliers)  
- Means of Finance (subsidy expected, beneficiary contribution, loan if any)  
- Implementation Timeline (Gantt chart)  
- Manpower and Training Plan  
- Risk Assessment and Mitigation (disease, market, climate)  
- Expected Outcomes (production capacity, employment, income)  
- Environmental and Pollution Control Measures  
- Utilization Plan for Subsidy Installments  
- Annexures: Land documents, quotes, category certificate, affidavit  

### Application Form Filling Protocol
1. Use only the application form prescribed by the **State Implementing Agency (SIA)** — do not use generic templates.  
2. Fill all fields in block letters; leave no blank spaces (write “NA” if not applicable).  
3. Ensure beneficiary name matches exactly as per Aadhaar and PAN across all documents.  
4. Enter correct bank account details (account number, IFSC, bank name) for Direct Benefit Transfer (DBT).  
5. Specify the exact NLM component (e.g., “Poultry Rearing – 500 birds”) and unit size as per scheme guidelines.  
6. Declare clearly if availing benefits from other central/state schemes for the same component (must be “No” to be eligible).  
7. Attach self-attested copies of all documents; originals to be produced only if requested during verification.  
8. Get the form countersigned by the authorized signatory (for SHGs, cooperatives, etc.) and affix seal if applicable.  
9. Verify with the District Animal Husbandry Officer or SIA on any state-specific columns or annexures required in the form.  

> **Sources**: Application Process (Step 2, 3), Required Documents from Scheme Key Facts

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the hard copy application set to the **District Animal Husbandry Officer** or **State Nodal Agency** as advised by the State Implementing Agency.  
- Obtain a signed acknowledgment receipt with Inward Number and date.  
- Take a clear photograph or scan of the submitted application and acknowledgment for records.  
- Store the reference number (Inward No./Application ID) in the case file with date of submission.  
- Set calendar reminders for follow-up at 15, 30, and 45 days post-submission.  
- Monitor for field verification visit by officials; ensure beneficiary is available and documents are accessible.
