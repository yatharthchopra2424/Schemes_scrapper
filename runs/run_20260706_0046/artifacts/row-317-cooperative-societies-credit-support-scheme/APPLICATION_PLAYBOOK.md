# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] The applicant is a Credit Cooperative (as per scheme's target beneficiaries)
- [ ] The cooperative has been in operation for not less than 3 years
- [ ] The cooperative has positive net worth
- [ ] The cooperative's paid-up share capital has not been eroded (i.e., net worth is not less than 100% paid-up share capital)
- [ ] The cooperative is located in India (Pan-India geographic scope)
- [ ] The loan amount requested does not exceed Rs.20.00 crore per borrower (subject to availability of funds)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation/Registration Certificate
- PAN Card
- ITR (last 2-3 years)
- GST Registration Certificate (if applicable)
- Bank Statements (last 6 months)
- Udyam Registration (if applicable)
- Audited Financial Statements
- Board Resolution for loan application
- Authorization Letter for representative

### Scheme-Specific Documents
- Common Loan Application Form (downloaded from NCDC website)
- Supporting documents (as specified by NCDC for the loan type and activity)

### Document Quality Check
- All documents must be legible and clear scans
- File names must match the document type (e.g., PAN_Card.pdf)
- File size should not exceed 5 MB per document
- All certificates must be valid and not expired
- Documents must be in English or Hindi; if in another language, a certified translation must be attached
- Declarations and undertakings must be signed and stamped where required

**Subject:** Document Request for Cooperative Societies Credit Support Scheme Application

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly mentioned as required for this working capital loan scheme. However, for loan sanction, NCDC may require details on the purpose and utilization of funds. **Verify with nodal officer** if a detailed project report is needed based on the specific activity (e.g., working capital for marketing, processing, etc.).

### Application Form Filling Protocol
1. Download the Common Loan Application Form from the NCDC portal: https://ncdc.in/index.jsp?page=common-application%3Den  
2. Select the correct **Activity/Purpose** (e.g., Credit, Industrial Cooperative & Service Cooperative, Dairy Processing, Fisheries, etc.)  
3. Select the correct **Loan Type** (Term Loan or Working Capital / Margin money)  
4. Fill all applicant details accurately (name, address, registration number, contact details)  
5. Clearly state the loan amount requested (must not exceed Rs.20.00 crore)  
6. Specify the repayment preference (monthly, quarterly, semi-annual, or as agreed)  
7. Declare that the cooperative meets eligibility criteria: operational for ≥3 years, positive net worth, no erosion in paid-up share capital  
8. Attach all supporting documents as per the checklist  
9. Ensure the authorized signatory signs and dates the form  
10. Submit the completed form along with documents to the NCDC office (or as per portal instructions)

### Internal Review Gate
- [ ] All sections of the application form are fully completed  
- [ ] Correct activity and loan type selected  
- [ ] Loan amount requested is within Rs.20.00 crore limit  
- [ ] Eligibility criteria are clearly declared and supported  
- [ ] All universal and scheme-specific documents are attached  
- [ ] Document file names are appropriate and sizes are within limits  
- [ ] Declarations are signed and dated  
- [ ] Board resolution authorizing the loan application is attached  
- [ ] Application is ready for submission to NCDC office

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the completed application form and supporting documents to the NCDC office (address available on website) or as per portal instructions  
- Obtain and screenshot the submission acknowledgment (if online) or receipt (if physical)  
- Store the application reference number securely  
- Set follow-up reminders for Day 25 and Day 35
