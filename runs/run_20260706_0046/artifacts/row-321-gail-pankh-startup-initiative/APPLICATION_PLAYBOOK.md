### Scheme-Specific Documents
- Detailed Project Report (DPR) outlining innovation, technology, scalability, and alignment with GAIL’s focus areas  
- Proof of concept (PoC), prototype, or pilot project results (if available)  
- Intellectual Property (IP) details (patent filings, copyrights, trademarks) if applicable  
- Team profile with resumes of founders and key technical personnel  
- Letter of intent or endorsement from a recognized incubator, accelerator, or academic institution (if available)  
- Declaration that the startup has not availed similar support from any other PSU or government scheme in the last 12 months  

### Document Quality Check
- All documents must be legible, scanned in PDF format (max file size: 5 MB per document)  
- File names must follow the format: `SchemeName_DocumentType_VersionDate.pdf` (e.g., `GAIL_Pankh_IncorporationCert_20240515.pdf`)  
- All certificates must be valid and not expired (check expiry dates on GST, Udyam, etc.)  
- Financial documents must be certified by a Chartered Accountant (CA)  
- Documents in regional languages must be accompanied by a certified English/Hindi translation  
- DPR must include clear problem statement, solution, technology used, market potential, and financial projections
