# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Startup registered in India with a valid Certificate of Incorporation/Registration  
- [ ] Possession of a valid DPIIT Startup Recognition Certificate  
- [ ] Working on innovative products, services, or technologies in domains such as steel processing, automation, AI/IoT, sustainability, waste management, or related industrial applications  
- [ ] Prototype or Minimum Viable Product (MVP) ready for pilot testing  
- [ ] No fixed turnover, employee count, or age of business thresholds specified (case-by-case evaluation)  

> **Sources**:  
> - Eligibility criteria from KEY FACTS: Startups registered in India with valid DPIIT recognition certificate, working on innovative products/services/technologies in specified domains, must have prototype/MVP ready for pilot testing.  
> - Application Process: Step 2 mentions reviewing eligibility criteria and focus areas on SAIL website.  
> - Portal: https://sail.co.in (official SAIL website)

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN of the entity  
- Audited financial statements (if available)  
- Bank statements  
- Udyam Registration (MSME)  
- GST Registration Certificate  
- ITR of last 2–3 years  

### Scheme-Specific Documents
- DPIIT Startup Recognition Certificate  
- Detailed project proposal or pitch deck  
- Proof of concept or prototype details  
- Team details and resumes of key founders  
- Any existing partnerships or pilot project reports  

### Document Quality Check
- All documents must be self-certified (self-attested)  
- File size must not exceed 200 KB per document (as per SAIL Perks Guiding Steps document)  
- File names must match the document type and applicant name  
- Documents must be in English or Hindi; if in PDF format  
- Scanned copies must be legible and clear

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
A Detailed Project Report (DPR) is **not explicitly required**, but a **detailed project proposal or pitch deck** is mandatory.  
If a DPR is requested during review, standard sections should include:  
- Executive Summary  
- Startup Profile  
- Problem Statement  
- Solution Description  
- Stage of Development (TRL)  
- Market Analysis  
- Technical Approach  
- Pilot Plan with SAIL (objectives, duration, resources needed)  
- Expected Outcomes  
- Team Details  
- Financial Plan (if seeking support)  
- Risk Mitigation  
- Annexures (prototype photos, test results, IP details)  

> **Note**: Verify with nodal officer if DPR format is preferred over pitch deck.  

### Application Form Filling Protocol
1. Access the SAIL Startup & Innovation Policy section via https://sail.co.in  
2. Read eligibility criteria and focus areas carefully before drafting  
3. Prepare proposal as per guidelines: include startup profile, problem statement, solution, development stage, expected outcomes  
4. Ensure all claims are supported by prototype/test data  
5. Attach all scheme-specific documents in PDF format (<200 KB each)  
6. Self-certify all documents (sign and stamp if applicable)  
7. Submit via designated portal or email address provided on SAIL website  
8. Keep screenshot of submission and reference number  
9. Follow up after 15–20 days if no acknowledgment received  

> **Sources**:  
> - Application Process (Step 3): "Prepare a detailed proposal including startup profile, problem statement, solution description, stage of development, and expected outcomes." (KEY FACTS)  
> - Portal: https://sail.co.in (multiple crawls)  
> - Document specs: Perks Guiding Steps (self-certified, <200KB)

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit application via the designated portal or email address specified on the SAIL website under Startup & Innovation Policy section  
- Take screenshot of submission confirmation (if portal) or save sent email receipt  
- Store application reference number (if provided) in case tracker  
- Set calendar reminder for follow-up at Day 25  
- Save all submitted documents in case folder with proper indexing  

> **Sources**:  
> - Application Process (Step 4): "Submit the application via the designated portal or email address provided on the SAIL website." (KEY FACTS)  
> - Portal: https://sail.co.in (official site)

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and save approval letter/email from SAIL  
- [ ] Verify sanctioned support (financial, infrastructure access, mentorship, etc.) as per mutual agreement  
- [ ] Sign collaboration agreement with clear IPR, confidentiality, and milestone terms  
- [ ] Initiate pilot project at designated SAIL plant (Bhilai, Bokaro, Rourkela, etc.)  
- [ ] Maintain monthly progress reports as agreed  
- [ ] Submit utilization certificate (if financial support provided)  
- [ ] Track milestone completion for potential long-term collaboration  
- [ ] Prepare invoice for success fee (if applicable per engagement terms)  
- [ ] Ensure compliance with SAIL’s IPR and discontinuation clauses (if milestones not met)  

> **Sources**:  
> - Benefits: Access to manufacturing units, technical mentorship, leadership presentations, potential long-term collaboration, visibility, case-by-case financial support (KEY FACTS)  
> - Key Caveats: Financial support not guaranteed, IPR must be defined, SAIL may discontinue if milestones not met, no standard equity/debt funding (KEY FACTS)  
> - Application Process: Final selection leads to notification and guidance on next steps for collaboration (KEY FACTS)  
> - Objectives: Foster collaboration, provide access to plants/infrastructure, support innovation in steel manufacturing, digitalization, etc. (KEY FACTS)
