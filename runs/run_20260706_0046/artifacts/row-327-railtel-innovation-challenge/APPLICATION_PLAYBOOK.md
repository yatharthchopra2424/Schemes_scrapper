# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Firm type: Limited / Pvt. Limited / LLP / Startup / Proprietary (any firm eligible)
- [ ] Incorporation/registration date: At least 6 months old as on date of application submission
- [ ] Credential usage: May use credentials of Parent/Subsidiary/Holding Company subject to undertaking as per Annexure-7
- [ ] Target beneficiaries: Startups, technology providers, MSMEs, enterprises (no sector restriction)
- [ ] Geographic scope: Pan-India (no location restriction)
- [ ] Age of business: Minimum 6 months incorporation/registration
- [ ] Other conditions: No turnover threshold specified for startups; established firms must meet cumulative turnover > Rs. 7.5 Cr for last 5 financial years (as per CA Certificate requirement)

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Incorporation Certificate
- PAN Card
- GST Registration Certificate
- Bank Statements (last 6 months)
- ITR (last 3 years)
- Udyam Registration (if applicable)
- Digital Signature Certificate (DSC)

### Scheme-Specific Documents
- Covering Letter (as per Annexure-1)
- Empanelment Fee payment proof (UTR details)
- Supplier and Customer Form (as per Annexure-2a and 2b) with Excel sheet and cancelled cheque copy
- Power of Attorney (as per Annexure-3)
- Backlisting Certificate (as per Annexure-4)
- CA Certificate with valid UDIN (as per Annexure-5)
- HR Certificate (as per Annexure-6)
- Annexure-7 (if using credentials of Parent/Subsidiary/Holding Company)

### Document Quality Check
- All documents must be legible and in English or Hindi
- File size: Each PDF < 10 MB; Excel file < 5 MB
- File naming: Use format `[DocumentName]_[ClientName]_[Date].pdf` (e.g., `CoveringLetter_ABCPvtLtd_20240515.pdf`)
- Certificates must be issued on official letterhead with seal and signature
- CA Certificate must include valid UDIN
- Cancelled cheque must be clear and show account holder name matching applicant
- Excel file for Supplier/Customer form must be fully filled with no blank mandatory fields
- All declarations must be dated prior to application submission date

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not required. The scheme does not require a Detailed Project Report (DPR). Focus is on document compliance and empanelment fee payment. If in doubt, verify with nodal officer.

### Application Form Filling Protocol
1. **Use official annexure formats only** — do not recreate templates; use Annexures 1–7 as provided in the EOI document.
2. **Fill all mandatory fields** — especially in Supplier/Customer Form (Annexure-2a/b), CA Certificate (Annexure-5), and HR Certificate (Annexure-6); blank fields lead to rejection.
3. **Ensure date consistency** — Power of Attorney date must be prior to Covering Letter and other annexures.
4. **Attach UTR details clearly** — include UTR No., applicant name, date, bank name, branch, and IFSC Code in the payment proof.
5. **Provide cancelled cheque copy** — must be clear, show account holder name, and match bank details in forms.
6. **Validate UDIN in CA Certificate** — verify UDIN authenticity on MCA portal before submission.
7. **Use correct firm type** — specify accurately as Limited/Pvt. Limited/LLP/Startup/Proprietary in all documents.
8. **Single PDF for credentials** — combine Covering Letter, Fee proof, PoA, Backlisting Cert, CA Cert, HR Cert, and Annexure-7 (if applicable) into one PDF; submit to baapplications@railtelindia.com.

- [ ] Utilization Certificate: Not applicable (no fund disbursement); instead, prepare for project execution under revenue-sharing/service-based model
- [ ] Invoice success fee: Not applicable (no success fee charged by consultant for this scheme; fee is based on engagement model)
- [ ] Post-approval compliance: 
  - Inform RailTel proactively if bidding opportunities are identified
  - Abide by all terms and conditions for 3-year empanelment period
  - Prepare for re-application after expiry (validity: 3 years from LOE)
- [ ] Store LOE securely and set reminder for re-application 60 days before expiry
- [ ] Maintain records of all projects executed under empanelment for performance review
