- Team Structure and Roles  
- Sustainability and Commercialization Plan

### Application Form Filling Protocol
1. Access the official application portal for the Power Grid Innovation Challenge (refer to PGCIL or Invest India PSU innovation portal).  
2. Register or log in using the authorized signatory’s email and mobile number (verify OTP).  
3. Select “Power Grid Innovation Challenge” from the list of active schemes.

7. Upload all documents in the specified format and size limits (PDF, <10 MB).
