# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Startup incorporated in India  
- [ ] Working in agriculture and allied sectors (crop improvement, animal husbandry, fisheries, natural resource management, or agri-processing)  
- [ ] Has innovative ideas or prototypes  
- [ ] Recognized by DPIIT OR recommended by an ICAR institute/KVK  
- [ ] Has not received more than a specified limit of funding from other government sources  
- [ ] Preference given to startups led by women, SC/ST, or those working in aspirational districts  

---

## Stage icar.org.in
Application Portal URL: https://icar.org.in

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Registration  
- PAN card of the startup  
- ITR (Income Tax Returns)  
- GST registration certificate  
- Bank statements (last 6 months)  
- Udyam Registration (if applicable)  

### Scheme-Specific Documents
- DPIIT startup recognition certificate (if available)  
- Detailed project proposal  
- Budget breakdown and utilization plan  
- Proof of concept or prototype details  
- Authorization letter from the signatory  
- Any prior funding or award details  
- Recommendation letter from an ICAR institute or KVK (if applicable)  

### Document Quality Check
- File size: Each document must be under 5 MB unless otherwise specified  
- File name: Must match the document type (e.g., "Incorporation_Certificate.pdf")  
- All documents must be legible, certified (if applicable), and in English or Hindi  
- Scanned copies must be clear and not distorted

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Yes, a detailed project proposal is required. It must include:  
- Innovation description  
- Objectives  
- Methodology  
- Budget  
- Expected outcomes  

### Application Form Filling Protocol
1. Visit the official ICAR website or designated portal for agri-startup grants.  
2. Check eligibility and ensure the startup is DPIIT-recognized or endorsed by an ICAR institute.  
3. Prepare a detailed project proposal including innovation description, objectives, methodology, budget, and expected outcomes.  
4. Submit the application online along with required documents.  
5. Ensure all fields are filled accurately; leave no mandatory field blank.  
6. Attach all documents in the prescribed format and size limits.  
7. Double-check that the authorization letter is signed and dated.  
8. Confirm that the budget breakdown aligns with the project activities and milestones.  

### Internal Review Gate
- [ ] All eligibility criteria verified and documented  
- [ ] All universal and scheme-specific documents collected and quality-checked  
- [ ] Project proposal completed with all required sections  
- [ ] Application form filled completely and accurately  
- [ ] All documents attached and properly named  
- [ ] Declarations signed and dated  
- [ ] Reference number saved after submission

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and store the approval letter from ICAR  
- [ ] Verify the sanctioned amount against the approved proposal  
- [ ] Ensure funds are utilized strictly for the approved project objectives  
- [ ] Submit periodic progress reports and utilization certificates as required  
- [ ] Comply with ICAR’s IPR policy regarding any intellectual property arising from the project  
- [ ] Prepare for milestone-based disbursement upon achievement of predefined deliverables  
- [ ] Maintain records for audit and verification purposes  
- [ ] Coordinate with ICAR for access to research facilities, laboratories, and expert mentorship  
- [ ] Explore opportunities for collaboration with ICAR scientists and KVKs for validation  
- [ ] Seek assistance in IPR filing and technology commercialization as per scheme benefits  
- [ ] Engage with investors, incubators, and agri-industry partners through ICAR’s networking platforms  
- [ ] Participate in visibility events organized by ICAR for grantees
