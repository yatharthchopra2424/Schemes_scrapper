# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Applicant is a woman entrepreneur in India
- [ ] Applicant seeks to start, grow, or scale a venture
- [ ] Applicant is willing to complete OTP verification and profile registration on the WEP portal
- [ ] No specific turnover, employee count, sector, or age-of-business thresholds apply for platform access
- [ ] Applicant understands that WEP is a facilitation platform and does not directly provide financial support
- [ ] Applicant acknowledges that access to certain partner offers may require active WEP membership
- [ ] Applicant confirms they have not exceeded the 2 free pre-registration resource limit (if applicable)

> **Note**: Eligibility is based on the WEP portal registration process. No formal eligibility criteria (turnover, employees, etc.) are mandated for platform access per evidence. Verification focuses on willingness to register and engage with the platform.

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- PAN Card
- Aadhaar Card
- Bank account details (cancelled cheque or bank statement)
- Udyam Registration Certificate (if applicable)
- GSTIN (if registered)
- Latest ITR (if applicable)
- Business registration proof (if applicable)

### Scheme-Specific Documents
- No scheme-specific documents are required beyond universal documents for WEP platform registration.
- WEP registration requires only OTP verification and profile completion; no document upload is mandated during initial registration.
- For accessing linked schemes via WEP’s 'Access to Finance' section, clients must refer to the specific scheme’s document requirements (to be verified per target scheme).

### Document Quality Check
- All documents must be clear, legible scans or PDFs
- File names must match the applicant’s name as per government ID
- File size should not exceed 5 MB per document
- Documents must be in English or Hindi; if in regional language, a certified translation is required
- Self-attested copies are acceptable unless otherwise specified by a linked scheme
- PAN and Aadhaar numbers must be masked in shared copies (showing only last 4 digits for security)

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
- **Not required** for WEP platform registration.  
- WEP is a resource aggregation and facilitation platform; no project report or DPR is needed to register or access its core offerings (mentorship, schemes, networking, etc.).  
- **Verify with nodal officer** if applying for a specific scheme linked via WEP’s 'Access to Finance' section, as DPR requirements vary by scheme.

### Application Form Filling Protocol
1. Access the portal via the exact URL: https://wep.gov.in/register?page=register  
2. Ensure OTP is entered immediately upon receipt (valid for limited time)  
3. Use a valid, active mobile number for OTP delivery  
4. Create a strong password (min. 8 characters, mix of letters, numbers, symbols)  
5. Complete all profile fields accurately (name, contact details, business description, sector, stage of venture)  
6. Do not use special characters or emojis in name or business fields  
7. Verify email and mobile number before final submission  
8. Save a screenshot of the "Registration Successful" confirmation page  

### Internal Review Gate
- [ ] OTP verification completed successfully  
- [ ] Password set and confirmed  
- [ ] Profile fully completed (no blank mandatory fields)  
- [ ] Screenshot of registration confirmation saved  
- [ ] Reference number or user ID recorded  
- [ ] Client informed of next steps (using Smart Match, exploring schemes, etc.)  
- [ ] Data privacy notice acknowledged (cookies, data usage)

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit the registration form online via the WEP portal  
- Capture a screenshot of the "Registration Successful" confirmation page showing the user ID or success message  
- Store the reference number (if provided) in the case file  
- Set a follow-up reminder for Day 25 to prompt profile completion and exploration of resources  
- Advise client to check email/SMS for WEP onboarding communications

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Confirm successful login to WEP portal using registered credentials  
- [ ] Verify access to full suite of resources (mentorship, schemes, incubators, etc.)  
- [ ] Document the client’s use of Smart Match for partner recommendations  
- [ ] Track engagement with workshops, articles, or videos for skill development  
- [ ] Monitor access to 'Access to Finance' section and applications to linked schemes  
- [ ] Ensure client utilizes WEP offerings (discounts, courses, networking events)  
- [ ] Obtain feedback on user experience for continuous improvement  
- [ ] Prepare utilization report if required for any linked scheme availed via WEP  
- [ ] Follow up on any awarded benefits (e.g., WEP Awards, recognition programs)  

> **Note**: WEP does not sanction funds or issue approval letters. "Approval" in this context refers to successful registration and activation of platform access. Outcomes are measured by engagement with resources and downstream scheme applications.
