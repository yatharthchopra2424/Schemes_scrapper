# Application Playbook

## How to Use This File
For each new client case, assign it a Case ID, pick the target scheme, and follow the steps below.

---

## Stage 1: Eligibility Verification (Day 1–3)

### Checklist
- [ ] Entity type: Company, partnership, or other legal entity interested in joint venture with TIDCO
- [ ] Equity participation category determined:
  - Joint Sector: Equity participation above 11% and up to 50%
  - Associate Sector: Equity participation above 2% and up to 11%
  - Escort Sector: 1% equity participation
  - Escort Services: No equity participation
- [ ] Project location: Industrial development in Tamil Nadu only
- [ ] Sector alignment: Project must fall within TIDCO's promoted sectors (Chemicals, Fertilizers, Pharmaceuticals, Textiles, Iron and Steel, Auto Components, Food & Agro, Floriculture, Engineering, Petroleum and Petrochemicals, IT/ITES Parks, Bio-Tech Parks, SEZs, Road Development Projects, Agri Export Zones, or industrial corridor projects)
- [ ] Investment scale: Medium to large industry or infrastructure project (no specific turnover/employee thresholds stated, but targets medium and large industries)
- [ ] Business age: No minimum age specified; new and existing entities eligible
- [ ] Intent: Willingness to submit proposal for joint venture project with TIDCO as nodal agency

---

## Stage 2: Document Collection (Day 3–10)

### Universal Documents (always required)
- Certificate of Incorporation / Partnership Deed
- PAN Card of the entity
- GST Registration Certificate
- Udyam Registration (if applicable)
- Bank statements (last 6 months)
- ITR for last 2–3 years
- Audited financial statements
- Board resolution authorizing joint venture proposal
- KYC documents of authorized signatory

### Scheme-Specific Documents
- Detailed project proposal outlining joint venture opportunity with TIDCO
- Equity participation structure document specifying category (Joint/Associate/Escort/Escort Services)
- Land details (if applicable) for project site in Tamil Nadu
- Technology/process details for proposed industrial activity
- Employment generation projections
- Environmental clearance documents (if required for project type)
- MoU or letter of intent with TIDCO (if pre-existing)
- Project feasibility report

### Document Quality Check
- All documents must be legible scanned copies (PDF preferred)
- File names must match document type (e.g., "PAN_Card.pdf", "Proposal_TIDCO.pdf")
- File size under 10 MB per document
- Certifications must be valid and not expired
- Documents in English or Tamil; if other language, provide certified translation
- All financial documents must be certified by a Chartered Accountant
- Project proposal must be signed and stamped by authorized signatory

## Stage 3: Application Drafting (Day 10–18)

### Project Report / DPR (if required)
Not explicitly required for initial proposal submission. However, a detailed project report is recommended for evaluation. If required during verification phase, include: Executive Summary, Project Description, Technology Details, Market Analysis, Financial Projections, Employment Plan, Risk Assessment, Implementation Timeline, and Environmental Impact Summary.  
*Note: Verify with TIDCO nodal officer if DPR is mandated for your project type.*

### Application Form Filling Protocol
1. Access the TIDCO Startup Investment Application Form via https://tidco.com (click "Click here to apply" under What's New)
2. Fill all fields accurately; do not leave mandatory sections blank
3. Specify exact equity participation category (Joint/Associate/Escort/Escort Services) and percentage
4. Clearly state project location within the state, and the state is the state state is the state state state state state state state state state state: Tamil Nadu only
5. Attach all documents as per checklist in PDF format, named appropriately
6. Declare that the project promotes balanced industrial growth in Tamil Nadu (aligns with scheme objective)
7. Disclose any existing MoUs or prior engagements with TIDCO
8. Confirm that the project falls within TIDCO's promoted sectors (list in eligibility)
9. Authorized signatory must declare information is true and correct
10. Save draft before final submission; review for completeness

### Internal Review Gate
- [ ] All application form fields completed
- [ ] Equity participation category and percentage correctly specified
- [ ] Project location confirmed as Tamil Nadu
- [ ] All universal and scheme-specific documents attached
- [ ] Document file names match content and are under 10 MB
- [ ] Declarations signed and dated by authorized signatory
- [ ] No contradictory information in proposal vs. documents
- [ ] Application aligns with TIDCO's objectives: balanced industrial growth, joint venture promotion
- [ ] Reference number noted after submission (to be filled post-submission)

## Stage 4: Submission & Follow-Up (Day 18–30)

### Submission Protocol
- Submit via TIDCO website form or email to info@tidco.com
- Take screenshot of submission confirmation or save email sent receipt
- Store reference number (if provided via portal) or email timestamp as application ID
- Set follow-up reminder for 15 days post-submission
- Save all submitted documents in case folder with submission date label

## Stage 5: Post-Approval (Day 30–90+)

### Approval Actions
- [ ] Obtain and review approval letter from TIDCO specifying sanctioned equity participation
- [ ] Verify sanctioned amount/equity percentage matches approved terms
- [ ] Execute joint venture agreement as per TIDCO's format
- [ ] Fulfill any pre-compliance conditions (if specified in approval)
- [ ] Initiate project implementation per agreed timeline
- [ ] Prepare utilization certificate for any fund disbursement (if applicable)
- [ ] Track milestone progress for internal reporting and potential success fee invoicing
- [ ] Maintain records of all communications and approvals for audit purposes
- [ ] Coordinate with TIDCO project officers for ongoing facilitation (contacts available at https://tidco.com/projectofficers.php)
